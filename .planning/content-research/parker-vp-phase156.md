## summary

Parker VP（Very Personal）是 1962 年前后推出的旋转笔尖钢笔，以三角握位、可调整的尖／笔舌总成和可拆卸 Clean Filler 解决握姿与灌墨弄脏手指的问题。它与后来的 Parker 75 有明显技术血缘，但 VP 的填充器、尺寸和尖号不能直接套用 75 的规格。

## body_md

Parker VP 的“个人化”不是营销口号而已。Parker 在 1960 年代初试图让左手用户和握笔角度不同的人更容易找到稳定的书写面，于是把握位做成带平面的三角截面，再让笔尖和笔舌总成可以旋转。Parker Pens Penography、Richard’s Pens 和 Parker 75 Reference 的尖号档案都把 VP 视为后来 75 调角尖的先行者；这条血缘可以确认设计思路相近，但不意味着 VP 和 75 的部件、尺寸或转换器完全通用。

## 三角握位与旋转尖

握位的平面会引导手指落在较稳定的位置，使用者再通过握位环上的箭头和刻度微调尖／笔舌朝向。旋转动作应在笔尖未接触纸面时完成，并以小幅度寻找书写角度；不要在有阻力时用钳子硬拧。Richard’s Pens 记录 VP 曾提供多种可替换尖号，包含细、 中、粗、会计、速记、音乐、平尖和斜尖等美国市场代码。尖码是尖端当前零件的线索，不代表每支 VP 原厂都配同一组尖。

三角握位对某些人很舒服，对习惯圆握位的人却可能产生压迫感。选购时应试写而不是只看“人体工学”描述；左手拖墨问题也与墨水干燥速度、纸张和书写方向有关，旋转尖并不能自动解决所有左手书写困难。尖面磨损、供墨不均和握位裂纹会比设计本身更直接地影响体验。

## Clean Filler 与上墨

VP 的 Clean Filler 是可拆卸的挤压式转换器，目标是让笔尖和握位在装瓶装墨水时保持相对清洁。Parker 75 Reference 和独立维修档案描述了它的长颈、透明墨囊和外部金属护套；操作时通常将转换器从笔杆后方取出，先在瓶中吸墨，再装回。这个机构与普通 Parker 墨囊、75 转换器和现代活塞式转换器不能凭外形互换。

长颈和六角截面是 Clean Filler 的脆弱点。干墨堵塞或螺纹卡住时，应先浸泡和冲洗，再由维修者处理；旋转转换器本体可能折断细颈。二手笔如果缺少原装 Clean Filler，可以记录为“当前缺件”，不要把后来制作的替代件写成出厂规格。灌墨后擦净尖端、检查握位环和笔杆螺纹，确认没有墨水渗入三角握位内部。

## 版本、生产与关联

VP 常见蓝、黑等树脂笔身和金属帽盖，也有地区进口刻字。Parker 75 Reference 的 VP 尖号展板和 75 尖码对照表显示，75 后来扩充了 VP 没有的若干尖型并改变了部分命名；因此“VP 66”等代码要按 VP 资料解释，不能直接套用 75 目录。VP 与 Parker 75、Premier 有设计关系，但不是同一型号，也不应因为都能旋转尖就合并导航节点。

资料对生产年份和退场时间的表述有小幅差异。本页采用 1962 年前后上市、随后被 75 体系吸收的范围，不把某个销售地的库存日期当作全球统一停产日。具体帽环、夹子、尖刻字和 Clean Filler 版本需结合实物、地区与来源记录。

## 维护与选购

VP 的重点维护对象是旋转尖总成、三角握位螺纹和 Clean Filler。清洗时使用凉水，先确认转换器已拆下；不要用酒精、强溶剂或硬刷清理树脂和镀层。旋转尖如果松旷，可能是 O-ring、螺纹或固定环老化，继续拧动只会扩大损伤。保存时让尖端朝上、洗净并单独放置转换器，避免长颈长期受压。

购买二手 VP，至少要求拍尖端正面、旋转刻度、三角握位、转换器颈部、帽内衬和笔杆刻字。卖家写“Parker 75 的前身”只能作为引导，不能证明 Clean Filler、尖材或原装帽盖。真正适合日用的样本应能在多个角度稳定出墨，转换器没有裂纹，旋转机构没有卡滞；真正适合收藏的样本则要把缺件、替换尖和地区刻字单独记录。

试写 VP 时应先把刻度放在中间位置，再分别测试左、右手常用角度。若旋转后出现供墨中断，可能是尖／笔舌总成没有正确落位，而不是角度本身不兼容。尖码展板能帮助理解编号，却不能替代当前尖面的实际书写样张；长期使用后尖边可能已经重新打磨。对于 Clean Filler，装墨前先确认长颈和密封圈没有变形，拆下时沿螺纹轴向用力，不能斜拉细颈。

VP 的历史价值还在于它把“用户握姿”纳入笔尖工程。现代三角握位钢笔往往固定尖角，VP 则把握位和尖座拆成两个可调变量。阅读这支笔时，应把人体工学理念、具体机构和二手维修状态分开：前者属于历史，后两者决定今天能否安全书写。

如果只想体验旋转尖而不承担古董 Clean Filler 的维修风险，Parker 75 是更容易找到的替代路线，但替代体验不应回写成 VP 的规格。VP 页面保留独立节点，正是为了让读者看见设计继承与型号差异同时存在。
