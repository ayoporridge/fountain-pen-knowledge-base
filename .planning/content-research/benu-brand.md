### 先分清品牌、系列和颜色

BENU 的视觉辨识度来自高饱和树脂、金属粉或闪粉，以及容易在桌面上停住的切面或多面体轮廓。视觉相似并不等于结构相同。Briolette 是较小的切面笔；Talisman 是更有存在感、通常可 post 的笔型；Euphoria 体量和握感又不同。一个商品标题里出现 Ruby Forest、Island Breeze、Luminous Blue 或 Amethyst Tide，通常只是树脂配方和颜色，不应在知识图谱中复制成一串只有色名不同的“新型号”。品牌页应把这些名称放在系列或 variant 导航下，避免读者误以为每个色名有独立历史和独立供墨系统。

官方尺寸对比图比零售商的营销分类更适合做第一层身份依据。它把不同 collection 的轮廓并列，能看出 Briolette、Talisman 和 Euphoria 的长度、粗细和盖型并非同一笔体。对产品图片也要保持克制：手工浇注树脂每支的纹理、金属粉聚集位置和反光会不同，商品图只能代表一个样本，不宜把一张白底渲染图当成整个颜色的精确色票。本页使用本站原创 factual SVG 作为导航图，并明确标注它不是实物照片。

### 品牌起源和制造叙事

BENU 官方 About 资料把设计和手工制作地点放在亚美尼亚 Yerevan。这里的“手工”主要应该理解为树脂配方、浇注、打磨、抛光、装配和逐支检查的品牌制造叙事，而不是每一根金属尖都由 BENU 自己锻造。Briolette 等型号的公开实测普遍指向德国 Schmidt 钢尖；因此品牌页不应该写成“BENU 自制金尖”，也不应把某个颜色的装饰镀层扩大为全品牌工艺。不同批次会出现镀色尖、金银色饰件和独家树脂，这些都应在具体型号页说明来源和适用范围。

品牌资料还显示，BENU 把收藏属性和日常书写放在同一条产品线上：亮色树脂适合展示、礼赠和社群交换，国际规格墨囊／转换器又让多数型号不需要特殊耗材。读者若期待大容量活塞或真空系统，应被引导去比较其他品牌，而不是因为外观闪亮就把 BENU 所有系列描述成旗舰或高容量笔。品牌页应诚实说明它的强项是材料和视觉，以及容易选到明确尺寸、尖号和供墨结构的系列导航。

### 型号入口

当前本图谱为 BENU 建立两个可核实入口。**BENU Briolette** 连接切面树脂、小尺寸、#5 Schmidt 尖和国际墨囊／转换器；Ruby Forest、Luminous Blue、Island Breeze 等只作为颜色 siblings。**BENU Talisman True Unicorn** 单独连接 Gourmet Pens Exclusive 的限量联名树脂，不能把 True Unicorn 缩写成“BENU Unicorn”后再和普通 Talisman 合并。未来如果补充 Euphoria、AstroGem、Minima 或 Ambrosia，应先核对官方尺寸图和具体商品页，再确定是同一系列的新颜色还是确有不同结构的型号。

品牌反向链接的标准是：每个公开型号必须能回到 BENU；每个颜色 sibling 必须回到对应主型号；联名方的产品图要保留“零售商／联名方图片”身份。这样既能满足漫游，也不会让重复图片和机器翻译式标题把图谱变成库存表。

### 选购与维护的共通底线

多数 BENU 树脂笔可以使用标准国际墨囊或转换器，但具体随机附送内容随年代和零售商包装变化。清洗时用室温清水吸排，擦干笔尖外侧，等内部自然干燥后再换墨；不要用酒精、热水或研磨剂处理树脂和镀层。树脂笔不代表可以无条件 eyedropper 改装，必须先确认螺纹、密封和该商品的官方说明。飞机、高温车厢和笔尖朝下收纳会增加压力变化漏墨风险。

尖号页面应把 F、M、B 当作字宽选择，而不是把钢尖宣传成 flex。想写中文小字或普通复印纸，F 或 M 通常更容易控制；B 和 Flex 配置更适合展示线条，但出厂调校仍可能有个体差异。选择时优先看握段直径、能否 post、长度和供墨习惯，再看树脂颜色。以上边界会在各型号页展开，品牌页不替代型号页的规格和维护说明。

品牌页的内容边界还包括图片和关系维护。BENU 的树脂颜色常带闪片、切面或发光效果，商品摄影会随着曝光、背景和批次改变；因此一张 Ruby Forest 或 True Unicorn 的图不能自动代表 Briolette、Talisman、Euphoria 全部产品。型号页应保留自己的 primary asset，并在品牌页只做导航缩略，不重复复制同一图片。用户从品牌页进入型号页后，首先看到的应是系列身份、尖号与供墨，再看到颜色故事。

对于联名和零售商独家色，页面把联名方、检索日期、Sold out 或地区库存写成状态字段，不把营销词翻译成材料功效。未来如果 BENU 官方增加新的结构系列，应新增有独立来源的主型号页面；如果只是新色，则在现有系列下新增 variant。这个规则能避免品牌页随着颜色数量膨胀成一组互相重复的空壳。
