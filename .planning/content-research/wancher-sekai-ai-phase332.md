# Wancher Sekai Ai：橄榄木上的 Aizome 蓝染与 Dove Zogan

## summary

Wancher Sekai Ai（World Tree Ai）以 Olive Wood 为基材，经日本传统 Aizome 蓝染，并提供 Dove Zogan 与无夹/925 银夹选项；兼容国际墨胆或转换器，尖材和 feed 按 SKU 选择。

## body_md

Sekai Ai 是 Wancher 在 World Tree 木材路线上的工艺变体。官方商品页把它写作 `Sekai - Ai`，正文又称 `World Tree Ai`：笔身以 Olive Wood 为基础，不是把乌木或其他 World Tree 木材简单染成蓝色，而是将木材纹理保留在 Aizome 蓝染的颜色层次里。本页只描述这一具体 SKU，不把 World Tree Ebony、Teak、Sandalwood、Verawood 或 Dream Pen 的材料和规格拼接进来。

### Olive Wood 与 Aizome

官方说明 Sekai Ai 使用 Olive Wood，并以 Indigo Dyeing（Aizome）形成蓝色。每支笔分别染色，所以蓝色深浅、纹理显现和局部色调不会完全一致；这是手工工艺和天然材料共同造成的差异，不应拿商品图当成颜色校样。Aizome 的重点不是覆盖木纹的普通涂料，而是让蓝色进入木材表面，同时保留原有纹理。官方还将 World Tree Ai 的染色归于大分县中津的 Aizome 工匠合作，这说明工艺语境，不等于把整支笔或所有零件都宣称在中津制造。

这类木笔更适合在稳定、干燥、少摩擦的环境中使用。不要把它和钥匙、裸露金属笔尖或会掉色的皮件长期放在一起；不要留在车内高温处，也不要用酒精擦拭。官方明确提醒酒精或清洁剂可能移除最终涂层，并建议使用温和清洁方式或清水配软布。若出现掉色、明显裂线、表面发白或夹件松动，应先停止抛光和强拆，记录照片与购买信息，再联系 Wancher 或经销商。

### Dove Zogan、夹件与版本

当前页面的选项包括无夹、Zogan Dove、925 Matte Silver Clip 和 925 Silver Clip；页面还提示 Dove Zogan 当前有库存。Zogan Dove 是装饰与版本选项，不是每一支 Sekai Ai 自动附带的通用夹子。夹件会影响携带方式和重量，购买前应确认实际订单的版本；无夹版需要另行考虑笔袋收纳，银夹版也不能当作防跌落保险。页面主图里的蓝色尖并不自动包含，蓝色尖需要额外购买，因此不能由图片推断尖材。

### 供墨、尖材与包装

官方规格写明使用 European International Standard cartridge 或 converter。可选尖材包括 #6 JoWo stainless steel、Wancher 18K gold 与 KEIRYU/Kodachi，feed 则有 plastic、black ebonite、red ebonite。这里的选项是配置范围，不是同时装在同一支笔上的固定组合；实际购买应核对尖幅、feed、蓝色尖是否另购以及是否属于当前库存。商品包装包括传统日式木盒、墨胆、转换器和说明材料。木盒是包装，不应被误读为笔身产地或木材等级证明。

初次装墨时将标准国际墨胆或转换器平直推入握位，确认连接牢固后再让笔尖朝下等待供墨。换色或久置前清空旧墨，用清水冲洗转换器和尖部，待部件自然干燥后再装回。不要把 Aizome 表面当作可反复水洗的塑料外壳；清洁应短、轻、局部完成。若供墨处渗漏，优先检查墨胆/转换器是否坐牢，不要用工具撬动木制部件。

木材与蓝染表面也不适合长期承受帽盖反复磕碰；收纳时让笔尖朝上并避免重物压住笔盒。

### 尺寸语境与选购边界

Sekai Ai 商品页当前没有在文本规格中重复数值尺寸；World Tree collection 的系列参考值为直径 13.2 mm、闭帽 140.1 mm、插帽 164.4 mm，重量为含夹 27 g、无夹 21 g。它们可以帮助读者理解 Sekai 木笔的比例和夹件差异，但本页把它们标为 World Tree 家族参考，不声称每支 Ai 的实际手工尺寸和净重完全相同。若尺寸和重量对购买很关键，应向当前卖家索取具体 SKU 数据。

选购时，喜欢天然木纹、希望蓝色来自传统染色而不是均匀油漆的人，可以把 Sekai Ai 作为 World Tree 的工艺入口；如果更在意深色乌木、原木色或不同木材密度，应转到对应 World Tree SKU。若在意漆艺、贝雕或限定工艺，应查看 Sekai Aizu Urushi、Dream Pen 和其他具体页面。Sekai Ai 与 World Tree Ebony 共享 Wancher/World Tree 家族背景，但不共享材质、颜色、图片、库存或所有重量结论。
