# Ranga 与 Model 3：印度手工车削笔的基础档案

## 页面定位

Ranga Pens 是印度独立手工制笔品牌。官网把自己描述为制作 ebonite、acrylic 与 celluloid 钢笔的团队，并把 M. S. Pandurangan 的制笔经验写成约五十年。这个数字属于品牌当前自述，不能自动等同于公司注册年份，也不能推断每一支笔都由同一位工匠完成。Ranga 的公开目录以材料、笔形和可选笔尖组织，Model 3 是其中一支反复出现的长笔身型号。

Model 3 的外形会让人联想到老式 Parker Duofold。这里的“resemble”是设计观察，不是 Parker 授权、复刻或零件关系；Ranga 页面没有把它写成 Parker 产品。它更适合被理解为一支手工车削、可选颜色与笔尖的独立现代笔。Model 3、Model 3C、透明 acrylic 版本和 rollerball 版本要分开看：同名不代表相同上墨结构，rollerball 也不是本页的钢笔。

## 可核实规格

Ranga Model 3 官方商品页给出的常见尺寸是约 6 英寸有帽长度，帽盖直径 16 mm，笔杆直径 14 mm，握位最粗处约 12.5 mm、持握处约 11 mm。官网同时列出塑料 feed 与 Schmidt K5 converter；这些是公开页面给出的配置，不应把某位用户改装的 eyedropper 或第三方尖单元倒灌成统一标准。Model 3 可以选择 acrylic 颜色与 mirror／matte finish，斑纹会随每支材料坯料不同而变化，因此照片只代表一个样本。

官网还提供多种 nib selection。长期玩家评测记录过 Kanwrite #6 钢尖，也提到 Ranga 可按订单提供 Bock、JoWo 或 Schmidt 体系的 #6 单元；这是该评测样本和当时订单的交叉信息，实际线程、feed 和费用应以购买时的配置单为准。不能因为“#6”就保证所有品牌 #6 unit 可直接互换。

## 历史与版本边界

Ranga 的公开叙述重点是家族式手工制作与材料，而不是一张按年份排列的工业目录。Model 3 的 acrylic、ebonite、clear demonstrator、matte black 等更像材料／finish 选择；Model 3C 是另一个尾端圆润的型号，不能把 3C 的尺寸或照片挪到 Model 3。清晰透明版本的官网页面还说明可以观察墨水，并提到 eyedropper 可能性；若购买的是普通 Model 3 converter 版本，应先确认该 SKU 的密封和 barrel 设计。

## 使用、维护与选购

第一次使用先以室温清水冲洗 feed 与 converter，确认出墨连续，再装常规水性墨水。车削 acrylic 可用柔软布擦拭；有色 ebonite 应避开长时间强光、热水、酒精和强溶剂，避免表面颜色变化。不要用钳子硬拧 nib housing，也不要把不同厂商 #6 unit 当成必然兼容的耗材。长写时，约 11 mm 的持握处对多数手型较稳，但大手用户应实际试握；有帽长度接近 6 英寸，携带时要留意没有统一的防漏承诺。

购买前要向卖家确认：材料是 acrylic 还是 ebonite、finish 是 mirror 还是 matte、所选 nib／feed／thread 属于哪一套、是否含 Schmidt K5 converter，以及当前是否有现货。官网本次检索的 Model 3 页面显示缺货；这只说明该页面当时的库存状态，不代表 Ranga 永久停产。若商品图展示的是高饱和斑纹，仍应把它当作单支材料样本，而非固定色号保证。
