# Pilot Capless SE（大理石）FCSE-3MR

## summary

Pilot 官方 Web Catalog 将 Capless SE 以 FCSE-3MR 单列：氨基甲酸酯树脂大理石轴、18K F／M、CON-40、140 mm、14 mm、26 g，黑／蓝／绿／红／橙五种 marble 设计各有 F／M。

## body_md

## 身份：SE 是大理石树脂 Capless

本页对应 `キャップレスSE`，总型号 **FCSE-3MR**。官方说明 `SE` 来自法语 *Seul*（唯一），并强调大理石纹理每支不完全相同。当前 lineup 为 `MAB` 黑、`MAL` 蓝、`MAG` 绿、`MAR` 红、`MAO` 橙，各有 F／M，共十个原厂 SKU。

FCSE-3MR 不是普通 Capless、Capless 絣或 Heritage SE 的同名缩写。它的材料是氨基甲酸酯树脂，规格为 18K、CON-40、140 mm、14 mm、26 g；“SE”在这里是 Capless 商品命名与独特纹理边界，不能把 Pilot Custom Heritage SE 的 14K No.10 与大理石 Capless 混在一起。

## 大理石外观和按动机构

官方商品页把大理石图案作为外观特征，而不是天然石材或漆器。每支纹理不完全相同，因此合法商品图只能展示一个样本，不能当全库存色卡。轴为氨基甲酸酯树脂，head、clip 与按动结构属于 Capless 路线；不要把它写成木材、铑饰或螺鈿。

Capless 的动作是按键伸出和收回尖端，shutter 在收回后帮助减少干涸。官方列 18K F，lineup 另有 M；供墨为 CON-40。换墨前先收尖，用室温清水清洁笔舌和 converter，不要猛按、突然回弹或自行拆精密 head。

## 数字规格、价格和版本

官方字段给出全长 **140 mm**、最大径 **14 mm**、重量 **26 g**，使用盒 Z-CR-N3。当前商品页含税希望零售价为 **44,000 日元**；它是日本目录的日期快照，区域售价、库存和赠品另行核对。五种 marble 设计的 F／M 是同一型号 variant，店铺改磨和二手换尖不应冒充原厂版本。

黑、蓝、绿、红、橙之间主要是大理石 finish；正文不声称颜色比例、树脂配方或纹理走向完全一致。收货时看完整产品代码、纹理是否有裂纹／凹坑、尖面刻字、按键和 converter，不能只按颜色名判断身份。

## 维护与选购

氨基甲酸酯树脂和精密按动件都应避开酒精、丙酮、热水、研磨剂、直射日光和极端温度。长期不用先排空墨水，清水吸排数次并擦干；外部只用柔软布。出现树脂裂纹、发黏、按键卡涩、shutter 不闭或漏墨时停用，保存订单与照片，联系 Pilot 或专业维修方。

本站 SVG 只表现 FCSE-3MR 的大理石纹理、18K F／M、CON-40、按动与 140／14／26g，明确非产品照片、非 Logo、非比例图、非颜色校样。它不代表五种 finish 的真实色彩或任何一支笔的独有纹理。

## 为什么不能把 SE 写成“唯一颜色”

SE 的独特性来自 Pilot 公开说明的两层意思：名字来自 *Seul*，大理石纹理也被明确描述为每支不完全相同。第一层是型号命名背景，第二层是外观个体差异；它们都不等于稀有限量、天然石材或每支都有不同笔尖。五种颜色和 F／M 仍然是可以核对的产品菜单，纹理的细节则属于实物证据。

购买时把颜色代码和尖幅写进订单，收货后再记录纹理、按键、shutter 和 converter 状态。不要把一支红色样本的照片拿去证明蓝色或绿色的具体色泽，也不要把 Custom Heritage SE 的大理石树脂、14K No.10 或尺寸套给 FCSE-3MR。保养时同样不应使用家具抛光剂；树脂表面失光和机构漏墨是两种不同的维修问题。

## 版本与证据的分工

官方 exact page 支持五种 `MAB／MAL／MAG／MAR／MAO` 设计、F／M、18K、氨基甲酸酯树脂、CON-40、140 mm、14 mm 和 26 g；支持清单支持 FCSE-3MR 的独立身份。由于页面明确说每支 marble 不完全相同，商品图只能当设计参考，不能当颜色校样。价格表支持当期金额，专业 Capless 评测只支持共通按动机构的使用背景。

若零售商把“SE”写成 Heritage SE，先回到品号而不是凭缩写猜测。`FCSE-3MR` 的按动、26 g 和 CON-40 与 `FKVH-3MR` 的 Custom Heritage SE 不是同一组字段；即使两者都出现大理石外观，也应在品牌关系和媒体 attribution 中分开保存。

因此本页的选择建议很简单：把“每支纹理不完全相同”当作收货时需要记录的事实，把 F／M、CON-40、尺寸和重量当作可以在订单前核对的规格，二者不要互相替代。

这能让大理石 finish 的视觉差异和型号身份同时保持清楚。

实际使用中，大理石树脂的独特纹理不会改变 Capless 的收尖、清洁与航空气压注意事项；它也不能证明某支笔是限量版。页面只把官方公开的五种设计和 F／M 菜单写成 variant，未公开的批次、旧市场代码和店铺改色应留在待核实记录中，直到有新的来源或实物证据。
