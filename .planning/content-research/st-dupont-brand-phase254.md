# S.T. Dupont：从皮具工坊到 Line D Eternity

S.T. Dupont 的入口不只是奢侈品价格，而是一个把皮具、金属加工、漆艺和书写工具放在同一条工艺谱系里的法国品牌。官方 heritage 页把时间线的起点放在 1872 年：Simon Tissot Dupont 在巴黎开设皮具工坊；1924 年，家族把工坊迁到 Faverges。后来品牌又发展出打火机、皮具和书写工具，Line D Eternity 是当前钢笔目录中的一条路线。这里的品牌历史只说明资料语境，不把 1872 当作 Line D 的首发年份，也不把所有旧笔的故事拼成一条连续的型号史。

从品牌页进入 Line D Eternity 时，先区分三种书写模式。官方 Writing Instruments collection 同时列 fountain pen、rollerball 和 ballpoint；它们共享设计语言，却使用不同的前端、耗材和维护方法。本图谱把钢笔作为独立 pen 页面，圆珠笔与 rollerball 不占用这条型号的图片、笔尖或供墨字段。当前官方美国站的 420216L 黑色款写明 black Dupont lacquer、缎面黑色饰件、articulated sword clip、黑色 14K solid-gold Wings nib，并随附 plunger；法国 Faverges 工坊制造是同一商品页给出的制造信息。

品牌页还需要告诉读者如何读版本。Line D Eternity 的 Medium、Large、不同饰件与主题漆色是产品目录中的路线或 SKU；不能仅因“Eternity”或“Line D”字样相同，就把尺寸、重量、尖面颜色和包装互相移植。420216L 的官方商品摄影属于品牌版权，本页使用本站原创的结构事实图，图中只画出漆面笔身、剑形夹、金色 Wings nib 和 plunger 的关系，并明确它不是产品照片。

实际浏览时，建议先从型号页的来源卡核对参考号，再回到品牌官网确认地区、库存和售后条件。官方页面列出蓝、黑、红、绿和绿松石墨囊，以及多种瓶装墨水；这能帮助新手理解 Line D 的耗材路线，却不代表所有年份或地区都长期供应同一颜色。若手中是一支旧 Line D、Elysee、Olympio 或 Classique，应先拍下笔夹、尖面刻字、帽环和尾端，再按具体参考号判断，不要只凭黑色漆面或剑形夹进行归类。

## 资料边界

本页采用官方资料确认品牌沿革和产品目录，采用独立评测补充一支旧 Line D 样本的尺寸与使用观察。论坛讨论只用于提示帽盖密封、converter 和年代差异，不能替代制造商规格。没有可靠证据的首发年份、全系产地、统一重量、尖宽范围和售后承诺均不写死。这样读者可以沿着来源继续研究，而不会把一支 420216L 的商品说明误读成所有 S.T. Dupont 钢笔的永久标准。
