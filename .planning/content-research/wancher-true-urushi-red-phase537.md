# True Urushi - Red：朱色商品入口与 Aka Tamenuri 的身份边界

Wancher 官方页面标题使用 **True Urushi - 朱 - Red**，JSON 标题为 **True Urushi - Red**，handle 是 `dream-pen-true-urushi-red`。这支笔与 True Urushi - Aka Tamenuri 都有红色语义，却不是同一商品：product id、handle 和 SKU 系列均不同。本文只处理 Red exact product page，不把 Aka Tamenuri、Zogan Sakura River 或其他红色漆笔的资料拼进来。

## 记录时间、变体与价格

官方 product JSON 的 product id 是 `609189920812`，created_at 为 2018-02-27，published_at 为 2019-10-24。它们是商品系统字段，不等于正式发行年份。JSON 列出三个市场变体：`Without Clip` / `WF-UR-DREAM-RED` / US$500，`With Chrome-plating Clip +$30` / `WF-UR-DREAM-RED-CHCL` / US$530，以及 `With Gold-plating Clip +$30` / `WF-UR-DREAM-RED-GLCL` / US$530；2026-08-06 抓取时三项均为 `available=true`。价格、税费、库存和页面标签随时间与地区变化，不作永久现货承诺。

三个 clip SKU 是 Red 的商品版本差异，而不是三个不同颜色实体。二手验收应检查 clip 颜色、SKU 后缀、价格差和笔身是否确实属于 Red；不能用 Yellow、Black、Aka Tamenuri 或其他红色页面的主图替代。

## 朱、红色观感与 Urushi

Red exact 页面把 Material & art 写为 **Ebonite, Urushi**，标题使用朱。公开页面没有给出红色颜料配方、底色、透明层、漆层数量、颜色数值或光泽度测量；“朱”只作为官方名称的一部分，不能被扩写成固定色号或某一种矿物颜料。反光、拍摄白平衡和手工表面会改变照片观感，不能替代实物验色。

Wancher 说明每支 True Urushi 笔由日本工匠在轮岛手工上色，制作至少三个月或更久，并以 Natural Urushi 介绍系列。轮岛工艺资料说明底涂、研磨、复数上漆和干燥是相互衔接的专业工序；它能解释漆艺制作的时间成本，但不能证明 Red 的具体工坊、工匠、漆层数、漆树来源或固定交期。

## 规格、版本和包装

官方规格列出 **#6 Jowo stainless steel** 与 **Wancher 18K gold** nib，feed 为 **Plastic、ebonite black、ebonite red**，供墨为 **Converter or Cartridge (European International Standard)**，并写 compact air-tight cap 以减少墨水干涸。公开选项不是一支笔同时装多种尖和 feed，也不把个人加装的尖写成全体 Red 标准。

包装包括 Traditional Japanese Wooden Box、Pen Kimono、Instructional Materials、Certificate、Converter 和 Cartridge。页面的 Size & Shape 区域没有公开可复核长度、直径、握径或可靠成品重量；JSON 的 200 g 平台值不当作实测。官方手工说明允许笔与笔之间略有差异，但不能掩盖裂纹、翘漆、明显掉色、clip 变形或螺纹异常。

## 选购、二手与维护

要求完整标题 **True Urushi - 朱 - Red**、product id `609189920812`、handle 和 RED SKU。自然光检查笔帽、笔杆、杆尾、握位、尖、feed 与三个 clip 版本；核对木盒、Pen Kimono、说明、Certificate、converter 和 cartridge。若卖家把 Red 说成 Aka Tamenuri 或 Zogan 图案版，应要求相应 product id 和订单证据。

Wancher 护理指南要求 Ebonite 不要在水中浸泡超过一分钟，避免直晒、干燥环境和极端天气，不使用化学清洁剂，推荐略湿布。Urushi 漆面日常还应避开酒精、丙酮、漂白剂、金属抛光剂、粗研磨和骤冷骤热；换墨时只清洗 nib、feed、握位和 converter。出现发白、裂纹、起翘或 clip 松动，应停止擦拭和硬拧，保存 SKU、照片和购买记录后联系品牌或漆艺维修者。

## 结论

True Urushi - Red 的稳定身份是 product id `609189920812`、handle `dream-pen-true-urushi-red` 和 RED 三个 clip SKU。公开资料支持 Ebonite、Urushi、欧规供墨、#6 JoWo / Wancher 18K nib、三类 feed、compact air-tight cap 和官方包装；不支持固定朱色色号、漆层数量、具体工匠、永久库存或与 Aka Tamenuri 的同一身份。把商品标题、红色名称、clip SKU 和轮岛背景分层，才能避免红色型号混名。
