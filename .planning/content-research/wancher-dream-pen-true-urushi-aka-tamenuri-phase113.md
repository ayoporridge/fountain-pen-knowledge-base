# Wancher Dream Pen True Urushi Aka Tamenuri 来源化正文（Phase 113）

## summary

Wancher Dream Pen True Urushi Aka Tamenuri 的 current 官方配置、2019 量产订单证据与两支 2018 黑色 prototype 被分层记录，品牌漆艺主张和作者 hypothesis 均保留明确边界。

## body_md

Aka Tamenuri 最容易被一张图误导。深色底层、边缘透出的朱红，以及漆面在不同光线下的层次，本来就需要看实物、角度和使用痕迹；本站的主图只是证据边界示意，不复刻色泽，不声称漆层数量，也不是产品照片。把这支笔写清楚，第一步不是替读者描述“它到底有多红”，而是先分开三件事：Wancher 现在怎样介绍这款具体产品，2019 年一笔真实量产订单能证明什么，以及 2018 年两支黑色 prototype 又只能说明什么。

### 2026-07-21 的 exact current listing

Wancher 的 exact 页面标题对应 **Dream Pen True Urushi Aka Tamenuri**。截至 2026-07-21，页面把硬橡胶笔身与 urushi 漆面放在同一款具体商品下，并列出 European International cartridge/converter 供墨、#6 JoWo steel 与 Wancher 18K 笔尖选择、plastic／ebonite feed 选择，以及 clip options。这些内容可以进入当日 current configuration；它们不需要从别的漆色、2018 prototype 或 [Dream Pen 系列导航](/article/wancher-dream-pen) 借规格。

同一页面也写到 Wajima 的手工作业，并称流程至少需要三个月。这里的主语必须保留：这是 **Wancher 表示** 的工艺与流程。官方页面是判断当期产品选项的第一手来源，却不是独立第三方调查。2019 年某一订单附带的证书，也不能自动把这段品牌自述推广成“所有现售单元都已被独立证明来自同一工坊、经历同样层数”的结论。

检索当日页面可进入购买流程，这只是 2026-07-21 的 commerce snapshot。价格、库存数量、按钮状态和未来能否购买都会变化，因此不进入稳定 model specs，也不写成购买承诺。稳定页面只保存材料、供墨和页面明确列出的 nib／feed／clip options，并把 retrieval date 留在来源记录中。

### 2019：一笔 production order 能证明到哪里

The Pencilcase Blog 在 2019 年的 revisiting 文章里，把 prototype 阶段之后的真实订购经历写得很具体：作者与父亲订购的是 production pens，父亲选择 Aka-Tamenuri；文章还说明页面没有 affiliate links。这里的价值不是“另一篇评测也喜欢这支笔”，而是它提供了一个独立于品牌商品页的订单情境。

随单证书命名 Taya Shikkiten，这条线索可以支持的范围仍然有限：它证明作者所描述的那一笔 reviewed order 收到了怎样的证书归因。它不能单独证明 2026-07-21 页面上的每一个可售单元都由同一主体完成，也不能替 Wancher 的全部 current production 作普遍背书。订单证书与 current 官方工艺主张可以并列，但不能相互“抬轿”成为超过各自证据范围的结论。

作者还提出一个重要但容易被误写的判断：production pen 的漆层 **可能** 比此前 prototype 少。原文的“可能”不是语气装饰，而是证据等级。本站把它记录为 author hypothesis：它不是确定层数，不是对官方“至少三个月”流程的反证，也不是所有 Aka Tamenuri 单元的稳定事实。若未来出现工序记录、同批次截面证据或制造方的明确 revision 说明，才有条件进一步解释；现在最诚实的做法是保留问题，而不是替来源补完答案。

### 2018：两支黑色 prototype 只说明家族前史

2018 年 The Pencilcase Blog 的文章写的是一支 **loaned black prototype**。Ed Jelley 同年的文章写的是一支 **Wancher-supplied black prototype**。两篇材料都能帮助理解 Dream Pen／urushi 项目在早期评测阶段如何被外界看到，但两支样本都不是这里的 Aka Tamenuri production SKU。

因此，prototype 文章里的长度、重量、steel nib、是否适合后插、表面观感和个人写感，都留在各自 sample scope 内。即使其中某一项看起来与 current listing 相似，也不能仅凭相似就迁移到当前 Aka 的 model specs。尤其是 steel nib：current exact 页面已经给出 #6 JoWo steel 与 Wancher 18K 的当期选项，早期黑色 prototype 的笔尖只能描述那支样本，不能删改、补强或缩窄现在的选择。

两篇文章的样本来源也不能合并成一句模糊的“媒体测试”：loaned 与 Wancher-supplied 是不同 disclosure。保留这一区别，读者才能判断样本取得方式；保留 black／non-Aka 身份，读者才能知道早期照片和写感为何不能替代 Aka Tamenuri 的实物观察。

### 配置核对：只写 current 页面能够承载的项目

这页稳定规格只收录 exact current listing 能直接支持的字段：

- material：ebonite body with urushi，并明确这是 Aka Tamenuri 的具体 listing；
- filling：European International cartridge or converter；
- nib：#6 JoWo steel 或 Wancher 18K；
- feed：plastic 或 ebonite；
- clip：页面所列 clip options，但不推断未来供应；
- status：仅记录 2026-07-21 完成过 current listing 核对，不保存价格、库存或购买按钮。

Wajima hand-work 与至少三个月流程放在 qualified brand claim，而不是伪装成独立验证过的普遍产地事实。2019 证书放在 production-order scope；fewer-layers 放在 hypothesis；2018 两篇文章放在 historical prototype scopes。这样的拆分看似比一张“全参数表”麻烦，却能阻止最常见的内容拼接错误：拿早期黑色样本的数字填补当前 Aka 空白，再拿一笔订单的证书替所有现售产品背书。

### 它与 Dream Pen 导航、True Ebonite 和其它颜色的关系

Aka Tamenuri 在图谱中是一个 exact canonical pen，只通过 made_by 指向既有 Wancher brand。它不会新建一个含义模糊的 generic True Urushi series，也不会把其它漆色合并成自己的 alias 或 variant。已有 True Ebonite 是另一支具体 SKU，其内容与 topology 均不由本页改写。

想比较 Dream Pen 的材料分支与具体产品，应回到 [Wancher Dream Pen 系列导航](/article/wancher-dream-pen)。这个链接只是正文导航：不会把 article 变成产品，不会给 article 制造 made_by／reverse，也不会把 article 中曾引用的 exact 商品 URL 当成可以复用的 SKU identity。系列页负责“从哪里继续逛”，本页负责“这一支具体 Aka 的证据到哪里为止”。

最终，这页没有声称解决漆层数量、所有单元的工坊归属或未来供应。它交付的是更可靠的东西：一个不会与文章、True Ebonite、prototype 或其它颜色混在一起的身份；一组带日期的 current 配置；一笔有证书线索但范围明确的 production order；以及两支只属于家族前史的黑色 prototype。
