# Platinum Izumo PIZ-80000N 八云涂：两款现行变体与五层证据

PIZ-80000N 是 Izumo 系列中的一个具体产品身份，不等于所有 Izumo。它在 Platinum 日文产品页 `https://www.platinum-pen.co.jp/products/fountain-pen/2064/` 与英文产品页 `https://www.platinum-pen.co.jp/en/products/detail/?pid=2064` 上都以 code 2064 对应。本文只把两页能共同或分别定位的 current facts 写入稳定规格，并把旧目录、维护说明、专业个人文章与社区样本放在各自 scope。系列导航见 [Platinum Izumo 系列](/article/platinum-izumo)。

## 当前身份与两个 variants

retrieved 2026-07-22 的日文页 locator 包括 breadcrumb、产品 code `PIZ-80000N`、价格与说明段，以及 `ペン先／ペン種／仕様／サイズ／付属品／化粧箱` 字段。页面 variation code table 只列两项：`#91 Ginsen Yakumo` 与 `#92 Togi Yakumo`。英文页 locator 包括 descriptive paragraph、`Nib／Base Material／Surface Finish／Size／Weight` 字段和同一组 #91/#92 code table。因此数据库 current variants 精确且仅有这两项，不把其它 Izumo sibling、旧样笔或相似漆饰变成第三款。

日文产品页在检索日标价 ¥165,000。这个金额只能写成 2026-07-22 JP product-page snapshot；英文页没有因此获得相同价格声明，未来价格、税费、地区供货和库存也不能由这次检索永久保证。

两款共用的官方稳定字段是：大型 18K（18-21）笔尖，two-tone，并有选择性 rhodium treatment；尖幅 F、M、B；硬橡胶基材；Yakumonuri 表面语境；全长约 154 mm、最大径约 18 mm、重量约 33 g；随附 pen kimono、Converter-800A、blue-black cartridge 与 Izumo paulownia box。供墨因此是 Platinum cartridge/converter 系统，而不是 piston 或 eyedropper。

`#92 Togi Yakumo` 才承接产品说明中的 togidashi／polished 边界：表层经研磨显出纹样。这里不把这一加工步骤自动写给 `#91 Ginsen Yakumo`，也不以网页照片承诺实物色差、银色纹样位置、光泽或每支手工作品完全一致。`#91` 与 `#92` 是明确变体，不是两种笔尖尖幅。

## 使用与辨认建议

核对实物时，先找 PIZ-80000N code 与 #91/#92 标识，再检查 nib width、converter/cartridge 与包装。看到 polished/togidashi 描述时确认它是否明确指向 #92；只写“Yakumo”或“Ginsen”而没有 code 的二手页面，应保留不确定性。价格与配件以购买时产品页和包装为准。

清洗时按 Platinum maintenance 文档执行温和冲洗，不凭网络拆解帖强行拆卸漆艺笔。若漆面、螺纹或笔尖出现问题，应联系官方维修；本文没有进行亲测，也不作耐久或售后承诺。
