Tsugaru Urushi - Kobai-iro 是 Wancher Dream Pen 中一支以红梅色和多层漆色为主题的独立钢笔。官方 product JSON 的产品编号为 `8930611953879`，handle 为 `tsugaru-urushi-kobai-iro`，商品记录时间为 2025-06-11，页面于 2025-06-13 发布。当前有 Pen Only `WF-TGUR-DR-KOB`（US$600）和 Pen Pillow Set + $60 `WF-TGUR-DR-KOB-PP-SET`（US$660）两种市场变体，检索时均显示可购。Pen Pillow 是包装/携带选项，不是另一种漆色或另一个型号。

### Kobai-iro 与季节色彩

Kobai-iro 可理解为“红梅色”。品牌把它和日本文化中对色名的重视联系起来，并借 Heian 时期多层和服的色彩关系解释为什么同一个红色会有不同深浅。色名不是严格的现代色票：漆面、光线和层次会改变观感，实际笔身可能在暗红、珊瑚或更暖的红之间呈现差异。商品页的文化叙事可说明设计灵感，不能直接证明这支钢笔复制某套宫廷服饰或具有历史文物身份。

独立的 Aomori Lacquerware Federation 资料说明，津轻塗是青森津轻地区的传统漆器，技法有 Kara-nuri、Nanako-nuri、Monsha-nuri 和 Nishiki-nuri。Kara-nuri 通过带孔刮刀形成斑点，再把不同颜色的漆反复上涂、干燥和研磨；完整工艺的步骤可能达到 48 道。这个区域性来源用于解释名称和工艺术语，不替 Wancher 公布本支笔的工匠履历、每道漆的数量、完成日期或认证编号。

### 维护、选购和身份核对

津轻塗官方护理资料建议避免极端干燥、直射光、紫外线、摩擦、骤变温度和研磨性布料，漆面长期接触水也可能留下痕迹。日常钢笔清洗先排空墨水，只处理 nib、feed、握段和 converter；笔身用拧干的柔软布轻拭，随后自然干燥，不用吹风机、炉具、酒精、丙酮、漂白剂或整支浸水。若漆层裂纹、掉片、失光或表面粘连，应停止使用并联系品牌或漆器维修者，不能自行抛光成“统一红梅色”。

二手核对要保存 product id `8930611953879`、handle、两个 SKU、Ebonite、Tsugaru Urushi、Kara-nuri、红梅色叠漆描述、所选 nib/feed、欧规 cartridge、木盒、certificate 和 pen pillow（如订单包含）。不要把 Kobai-iro 与 Anzu、Tsugaru Urushi 其他颜色或 Kyoto Yukinoshita 合并；即使都使用红色/粉色叙事，也应以 exact handle 与 SKU 维持独立身份。价格和可购状态只反映检索窗口。

Pen Pillow Set 的配件会影响运输和收纳方式，但不会改变笔本身的尺寸、尖面或漆艺。若选择套装，收货时应把枕垫 SKU 与笔的 SKU 分开记录，并检查包装运输是否让夹子或漆面受压。红梅色在不同显示器上容易与粉色或橙色混淆，二手交易应要求完整笔身自然光照片和订单证据。页面没有公开正式首发年份、限量数量、单支工匠签名或尺寸重量，因此这些字段不能从名称和价格推算。
