# S.T. Dupont：从皮具工坊到 Line D Eternity

S.T. Dupont 的入口不只是奢侈品价格，而是一个把皮具、金属加工、漆艺和书写工具放在同一条工艺谱系里的法国品牌。官方 heritage 页把时间线的起点放在 1872 年：Simon Tissot Dupont 在巴黎开设皮具工坊；1924 年，家族把工坊迁到 Faverges。后来品牌又发展出打火机、皮具和书写工具，Line D Eternity 是当前钢笔目录中的一条路线。这里的品牌历史只说明资料语境，不把 1872 当作 Line D 的首发年份，也不把所有旧笔的故事拼成一条连续的型号史。

从品牌页进入 Line D Eternity 时，先区分三种书写模式。官方 Writing Instruments collection 同时列 fountain pen、rollerball 和 ballpoint；它们共享设计语言，却使用不同的前端、耗材和维护方法。本图谱把钢笔作为独立 pen 页面，圆珠笔与 rollerball 不占用这条型号的图片、笔尖或供墨字段。当前官方美国站的 420216L 黑色款写明 black Dupont lacquer、缎面黑色饰件、articulated sword clip、黑色 14K solid-gold Wings nib，并随附 plunger；法国 Faverges 工坊制造是同一商品页给出的制造信息。

品牌页还需要告诉读者如何读版本。Line D Eternity 的 Medium、Large、不同饰件与主题漆色是产品目录中的路线或 SKU；不能仅因“Eternity”或“Line D”字样相同，就把尺寸、重量、尖面颜色和包装互相移植。420216L 的官方商品摄影属于品牌版权，本页使用本站原创的结构事实图，图中只画出漆面笔身、剑形夹、金色 Wings nib 和 plunger 的关系，并明确它不是产品照片。

实际浏览时，建议先从型号页的来源卡核对参考号，再回到品牌官网确认地区、库存和售后条件。官方页面列出蓝、黑、红、绿和绿松石墨囊，以及多种瓶装墨水；这能帮助新手理解 Line D 的耗材路线，却不代表所有年份或地区都长期供应同一颜色。若手中是一支旧 Line D、Elysee、Olympio 或 Classique，应先拍下笔夹、尖面刻字、帽环和尾端，再按具体参考号判断，不要只凭黑色漆面或剑形夹进行归类。

## Line D 的身份与版本边界

Line D Eternity 的参考号比颜色名更适合做身份锚点。官方美国站的 420216L 黑色款同时给出 black Dupont lacquer、缎面黑色饰件、剑形夹、黑色 14K solid-gold Wings nib 和 plunger；这些信息只属于该商品页的范围。Medium、Large、不同漆色和饰件可以共享设计语言，却不应互相继承笔尖颜色、重量、长度或包装。购买二手笔时，先拍帽环、笔夹、笔尖刻字、尾端与盒标，再把参考号与当地区域页面对照。

品牌页不把 Line D Eternity 当作 S.T. Dupont 的全部钢笔史。Elysee、Olympio、Classique 以及旧 Line D 可能拥有不同代际和供墨系统；相似的剑形夹、黑色漆面或金色装饰只能作为线索，不能单独完成归类。官方 Writing Instruments 页面把 fountain pen、rollerball 和 ballpoint 并列展示，本站因此将三个前端分别建档，避免把滚珠笔 refill 或圆珠笔耗材写进钢笔页。

## 选购、书写与维护

选择 Line D 时，先确认你要的是钢笔还是其它书写模式，再确认尖幅、尺寸和地区库存。黑色款的 14K Wings nib 是具体配置，不是所有 Eternity 的统一标准；颜色和限量主题也可能改变饰件、包装或现货。官方页面列出的墨囊颜色与瓶装墨水能帮助使用者理解耗材路线，但不代表每个年份、每个市场都长期供应。收到笔后先用少量兼容墨水测试起笔、转弯、合帽和倒置状态，保留参考号与售后凭证。

漆面、金属饰件和镀层不适合用粗糙布料或抛光剂反复摩擦；清洗以常温清水和自然晾干为原则，不要把酒精或强溶剂带到漆面、密封件或笔尖上。若 converter、plunger 或笔帽密封出现异常，不要按旧型号经验强拆，先确认具体代际，再找官方售后或熟悉 S.T. Dupont 的维修人员。评测中的重量、长度和书写感都应标注样本与日期，不能替代制造商的当前规格。

本站结构图只画漆面笔身、剑形夹、Wings nib 和 plunger 的关系，明确标注“示意图，非产品照片”。真实图片必须与参考号和版本一起核对；一张黑色 Line D 的宣传图不能拿来代表红色、蓝色、Large 或旧款。这样品牌页既能提供历史脉络，也不会把奢侈品广告语误当作每一支钢笔的可验证性能。

二手交易时尤其要把参考号和实物刻字放在一起保存。只有颜色名、剑形夹或“Eternity”字样的照片，最多说明设计语系，不能证明代际、尖材质和内部上墨器。若来源之间出现地区页面差异，记录访问地区和日期，并把冲突留在型号页；不要用一条较新的商品说明覆盖旧笔，也不要用旧评测替当前在售 SKU 背书。

对收藏者来说，品牌历史与型号鉴定是两条相互支撑、但不能互相替代的线。1872 年巴黎皮具工坊和 1924 年 Faverges 迁址属于 heritage 叙事；420216L 的 Wings nib、漆面和 plunger 属于商品规格。把两种资料并列，读者既能知道这支笔身处怎样的工艺谱系，也能在维修或转售时拿出更精确的参考号和实物证据。

因此，品牌页只把历史作为时间坐标，把当前商品作为可核对的型号入口。任何“限量”“纪念版”“某年停产”的说法，若没有参考号、官方目录或可靠档案支持，都继续留在待核区，不用营销标题填补。
