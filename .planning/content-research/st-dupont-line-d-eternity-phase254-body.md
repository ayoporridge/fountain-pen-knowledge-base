# S.T. Dupont Line D Eternity：黑漆、剑形夹与 14K Wings nib

Line D Eternity 是 S.T. Dupont 当前书写工具目录中的一条现代钢笔路线。它最容易被误写成“所有 Line D 的总称”，或被圆珠笔、rollerball 的资料占据。这里锁定的是官方美国站参考号 **420216L**：一支黑色 Large fountain pen。页面没有把颜色、饰件和书写模式拆成互相替代的型号；它只作为 Line D Eternity 家族中一个可核对的当代 SKU 入口。若你手中的笔是旧款 Line D、Elysee、Olympio、Atelier 或其他限量款，应以参考号、尖面刻字、帽环和完整实物照片重新判断。

## 官方 420216L 写了什么

S.T. Dupont 官方商品页把 420216L 描述为 black Dupont lacquer 与 satin-finish black 的组合。漆面是识别这支当前黑色款的视觉线索，但不应被写成所有年份均相同的配方；黑色缎面饰件也不能替代另一款金色或钯色版本的规格。剑形 articulated clip 是 Line D Eternity 的醒目结构，夹片的活动方式和帽盖配合属于产品设计的一部分，购买二手笔时应该拍清楚夹片、夹根和帽内的状态，而不是只看远景。

官方商品页同时注明这支 420216L 在法国 Faverges 工坊制造。这里的产地信息绑定当前参考号，不应倒推旧 Line D 或其他书写模式都在同一时间、同一工坊生产。

该 SKU 使用黑色 **14-carat solid-gold Wings nib**。这里的 14K 是合金成色信息，不是柔软、flex 或某个固定线宽的保证；官网商品页没有因此承诺每个地区都有相同的 EF、F、M、B 选项。页面还写有 plunger included。这个词应按原文保留为随笔配件／上墨工具的商品信息，不能擅自改写成整支笔使用内置活塞，也不能凭它推算墨仓容量。官方页同时列相关墨囊和瓶装墨水，说明品牌存在 C/C 消耗品路线；实际包装是否含 converter、具体接口和替换件，仍要按参考号与地区商品页确认。

## 尺寸与写感：分清 SKU 与样本

420216L 官方页没有给出一套可供所有 Line D Eternity 复制的长度、直径和重量。可靠的 SBRE Brown 评测曾测量一支较早的黑金 Line D：合帽约 146.6 mm、开帽约 134.6 mm、后插约 166.4 mm，总重约 48 g，其中帽约 16 g、笔身约 32 g。这些数字属于 2017 年评测样本，不应直接填入 420216L 的固定规格；它们的价值在于提醒购买者，Line D 的帽盖和金属装饰可能明显影响平衡。大手用户可以比较不后插与后插的握持，手小或长时间写小字的人则应在购买前实际试握。

独立评测也记录过一支 Line D 的 C/C 使用与书写体验，但个体调校、墨水和纸张会改变出墨。正文不把“滑、湿、耐放置”写成全系承诺。新笔到手后，先用清水缓慢吸排，再以自己的常用墨水试写起笔、连续线和停放后的再启动；若出现持续断墨、漏墨或笔尖错位，保留参考号和开箱照片，优先使用官方或销售方的售后渠道，而不是自行撬动 14K 尖和帽内结构。

## 版本边界

官方欧洲目录把 Line D Eternity 分为 Medium 与 Large，并持续展示不同颜色、饰件和主题版本。420216L 只是黑色 Large 的明确参考号。Medium 版本、蓝色/金色或钯色饰件、Popoté、Atelier、动物主题以及更早的 Line D 旧款，都需要独立商品页或目录证据。不能用 420216L 的黑色 Wings nib 证明所有 Eternity 都使用同样的尖面外观，也不能用旧黑金样本的重量替当前大号或限量版背书。

尤其要把三种书写模式分开：fountain pen 依靠笔尖和墨水，rollerball 使用替芯，ballpoint 使用圆珠油墨。官方 Writing Instruments collection 将它们并列展示，恰好说明“同一个设计系列”不等于“同一支笔”。二手交易中看到 Line D 字样时，应先确认是钢笔而非 rollerball；没有尖面、握位和上墨接口近照，就不应根据盒子或笔夹做型号结论。

## 维护与选购

换墨前，用室温清水反复吸排，直到排出液体基本澄清；拆下墨囊或 converter 后让前端自然干燥。不要用热水、酒精、超声波、金属抛光剂或强溶剂处理漆面、镀层和 14K 尖。剑形夹、帽盖卡合和内部 plunger 都是精密结构，遇到卡滞应先停止施力，记录发生条件并咨询售后。若长期不用，清空墨水、擦干握位与帽口，避免把残墨留在漆面沟槽和夹片附近。

选购 420216L 时，先确认商品号 420216L、fountain pen 书写模式和黑色 lacquer/satin finish，再核对尖面是否为 Wings nib、是否有原配 plunger、墨囊或 converter。想要较轻的日用笔、明确的细尖或不同尺寸时，应该把 Line D Eternity Medium、D-Initial 或其他品牌放入比较，而不是把价格、金色饰件或“luxury”营销词当成写感结论。Line D 的价值在工艺与设计取向；是否适合你，仍取决于握持、帽重、墨水和售后条件。
