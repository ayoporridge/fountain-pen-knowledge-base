## summary

The Security Pen 是 1920 年代美国把支票保护器装进钢笔的复合工具，常见编号包括 300、400、600 与 Giant 800。其尾部旋钮驱动墨囊和独立保护器帽是型号识别线索；广告中的价格、尖幅和短长款选项随阶段变化，不能拼成统一现代规格。

## body_md

### 型号身份：钢笔与支票保护器的组合

The Security Pen 的“Security”不是泛称，而是与 Kritikson 兄弟公司和 Securograph 机构相连的一组历史产品。Richard’s Pens 的档案显示，John H. Kritikson 和 George Kritikson 1919 年建立 Securograph Pen Company，后在芝加哥以 Kritikson Bros. Inc. 经营，再以 Security Pen Corporation 名义扩展。笔的尾部可以装下支票保护器：滚轮在收款人姓名或金额上切出细孔并同时带入红色印台墨水，让后续涂改留下明显痕迹。

因此本页不能把一支普通的 Security 夹子钢笔、单独售卖的 Securograph 小工具和完整防伪钢笔混成同一型号。可靠的识别组合是：Security／Securograph 刻字或广告语境、尾部保护器帽、支票保护轮、Kritikson 弹簧夹，以及与之配套的旋转上墨机构。缺少其中多数线索的商品，应保留“待核”而不凭卖家标题认定。

### 保护器和上墨机构

美国专利 US1480690 记录 Stanley E. Peters 的支票保护器：带齿滚轮在纸面留下切痕，后方的红色墨垫把颜色压入纸纤维。它解释了为什么保护器帽、滚轮和红色残留是关键部件。US1339359 的弹簧夹专利则说明夹子不是普通装饰件；其枢轴和隐藏弹簧是 Kritikson 设计的一部分。

钢笔本身的尾部旋钮也不能当成活塞。US1482568 描述的机制用旋钮带动直角摇臂，压缩橡胶墨囊；反向转动让墨囊恢复并吸墨。若保护器帽或尾钮已经腐蚀，机构可能无法正常回程。未经检查不要反复拧动，也不要往尾部注入溶剂或强力润滑油。

### 编号、版本和笔尖

1923 年广告曾列出 200、300、400、500、600，另有短款和长款；女款 300A 以环顶形式出现。公司重组前后又出现 300、400、600 和 800 “Giant”。这些编号是历史产品线证据，不应被解释为同一笔只换尺寸。Giant 可能使用红色斑纹硬橡胶并带金环保护器帽，后期也有黑色和赛璐珞样本；颜色和材质应按实物及广告日期记录。

当时广告还提供 Fine、Medium、Coarse、Medium Stub、Broad Stub、Steno 和 Posting 等尖幅，部分选项分弹性与 stiff。笔尖可被更换，广告选项也不一定覆盖每一支存世笔，所以正文不把“Security 笔都是软尖”或“300 必然配某尖”写成事实。购买者应拍摄尖刻字、feed、section 和是否有重磨痕迹。

### 维护与安全

老 Security 的风险集中在三处：硬橡胶或赛璐珞脆裂、旋转上墨器连杆腐蚀、支票保护器内部红色墨垫干结。Richard’s Pens 建议把故障样本交给有经验的修复者，因为保护器帽可能卡死，强拆会同时损伤笔杆和机械件。清洁时先取下可安全拆除的外帽，使用常温水和低压检查墨囊；不要把保护器当作可以用针刮通的普通笔尖，也不要在未知材质上使用热水、酒精或超声波。

若目标是收藏，原装保护器、旧广告对应的编号和清晰刻字比“翻新得很亮”更重要。若目标是写字，先确认尾钮、墨囊、feed 和保护器帽都不会漏墨，再以少量温和染料墨水试写；把修复、换 sac、换夹子和保护器是否缺件写进交易记录。现代支票已不再需要这种工具，Security 的价值主要在防伪史、机械设计和当时的商业想象。

### 版本判断的实际顺序

拿到一支 Security 时，可以先从外到内记录：笔帽和尾部保护器帽是否同一材质，尾钮是否有 Security 或 Securograph 刻字，滚轮能否在不施力的情况下转动，夹子枢轴是否完整，最后才观察笔尖和 feed。编号刻字与广告日期若互相矛盾，应保留矛盾并标注待核，而不是用价格或颜色替其中一项“纠正”另一项。300、600 和 Giant 的名字在二手市场经常被简化，照片、广告和专利三者必须分开引用。

书写测试也应分成机构测试与笔尖测试。先在没有墨水的状态下确认尾钮和保护器没有卡死，再用少量温和墨水检查墨囊回弹、section 渗漏和 feed 连续性；最后才评价尖幅和弹性。支票保护器即使看似完整，也不应在真实票据上试滚。保护器的历史意义可以通过纸张样本和专利图理解，收藏笔本身应保持可逆、低风险的操作。任何拆换都要记录日期和零件来源。

本站图为原创剖面示意，不是某支 Security 的实拍，不能用于证明编号、价格、比例或部件原装。历史广告只用于解释产品线，不替代每支笔的状态鉴定。
