## body_md

长江 ZhangJiang 品牌页要先承认一个事实：中文“长江”在不同年代、不同收藏者和不同平台上可能对应不完全相同的英文转写与产品线。白丁 Alan 的 ZhangJiang 988 评测提供了一个具体型号入口，但它并不自动等于所有写着“长江”的旧钢笔。品牌页因此把 988 作为当前唯一完成来源化的代表，并把其他名称相近的笔保留为研究线索。

## 名称、别名与不能越过的线

ZhangJiang 是评测标题使用的拉丁字母写法，中文页名为长江。Fountain Pen Network 的中国品牌名录则使用 Changjiang 的转写，并讨论过一类经典 Type 28 设计；这对检索很有帮助，却不足以证明 ZhangJiang 988、Changjiang Type 28、长江 28 或带有其他地区品牌名的笔由同一主体生产。搜索别名可以帮助读者找到资料，身份合并必须另外有刻字、目录或包装证据。

公开资料没有为当前页面提供足以确认的成立年份、法人主体、工厂地址、迁厂过程、销售数量或完整产品目录。名录中关于 Chongqing、Type 28 或多个品牌名的讨论属于历史线索和收藏者整理，不能直接回填 988 的产地、年代、笔尖或上墨。品牌页用“可辨认的旧笔品牌线索”描述范围，避免把名称解释写成企业档案。

## 当前导航：ZhangJiang 988

988 的身份应从实物刻字开始：帽环、笔身、笔尖正面和尾端至少要有可读照片，并且这些部件的形状能彼此对应。卖家只写“长江牌 988”、使用另一支黑色国产笔的照片，或把数字 988 当作商品库存号，都不能替代型号证据。若笔尖、帽盖或尾件经过更换，页面仍可保留型号入口，但要把替换件和维修时间标成样本状态。

现有 988 正文只把评测视频中的那一支当作观察样本。线宽、反馈、流量、长度、重量、材质和上墨方式都没有被外推成全批次规格。买到实物后先记录原状，常温清水短暂吸排，再用普通染料墨做短写与隔夜测试；强溶剂、热水、强超声波和硬拧未知尾端都应避免。出现漏墨、歪尖或脆裂时，先停止施力并交给熟悉国产旧笔的维修者。

## Changjiang 与长江 28：作为研究线索而非 988 规格

Fountain Pen Network 名录把 Changjiang 作为一个资料稀疏的中文品牌条目，并提到 Type 28 设计；Reddit 上的收藏者问答也讨论过刻有“长江”的旧笔和可能的 28 型号。两类资料都说明名称在海外收藏语境中有流通，但它们没有给 ZhangJiang 988 提供可直接套用的尺寸、材料、上墨或生产年份。页面保留这些链接，是为了帮助读者理解命名混淆，而不是把 28、988 或其他编号拼成一个系列。

如果将来出现同一纸盒、同一刻字格式或同一结构的多支样本，先把 Changjiang、ZhangJiang 和其他转写分别记录，再建立“可能同名”的研究关系。只有来源明确说明它们是同一品牌或同一生产线时，才可升级为别名或历史关系。一个论坛回复、一张二手图或英文转写习惯本身都不够完成这个动作。

## 状态核验与维修

老笔的实际价值通常取决于完整度。购买前应要求自然光下的刻字近照、帽口、螺纹、笔夹根部、笔尖和尾端照片，询问是否原配尖、是否能吸清水、是否有裂纹和粘接痕迹。闭帽是否稳固、笔帽内是否积墨、笔杆是否变形，会直接影响日用和维修预算。冷门或“老厂”说法不能代替这些可观察事实。

维护应从可逆步骤开始。清水吸排到基本清澈后，记录第一笔、连续书写、隔夜起笔和帽内状态；未知材质不要先用酒精、热水、强力超声波或研磨剂。若必须调尖、换囊或更换尾件，保存维修前后的照片、日期、零件来源和维修者判断。这样后来新增样本时，编辑能区分原厂配置与后期修复，而不会把一支修过的 988 当成统一标准。

## 选购与品牌页导航

ZhangJiang 988 更适合愿意做身份核验、清洗和记录的收藏者。需要稳定通勤、容易找到耗材和明确售后的读者，选择现代规格公开的入门笔通常更省心。价格应由刻字清楚度、帽盖完整度、笔尖状态、上墨件和维修预算共同决定；“稀有”“绝版”“同款”都不能单独支撑溢价。

品牌页当前只反向链接 ZhangJiang 988。新的长江编号或 Changjiang 线索必须先做 exact name、alias、旧路由、图片与关系预检，确认不是 988 重复实体，也不是 Type 28 或其他品牌的错名。未完成研究的型号可以写进研究清单，但不发布只有标题和一张示意图的空白页面。

未来最有价值的补证包括旧目录、包装、广告、完整刻字、多支同号样本和维修前后记录。每条资料都应注明覆盖的转写、编号、年份或单支样本；价格、库存、颜色和卖家口述只作时间点信息。只有多个独立证据互相印证，才把字段从样本备注提升到型号级事实。

## 读者可以先做的四个动作

如果你手里已有一支写着长江的笔，先不要从搜索结果挑一个最像的名字。把笔身、帽环、笔尖正面和尾端的刻字完整抄下，拍摄同一光线下的近照；再测量闭帽、开帽和套帽长度，称量未装墨的重量。接着拍出握位与上墨件，记录清水能否顺利吸排。最后把测试日期、清洗过程、首笔和隔夜表现写在同一页上。这样即使后来发现它更接近另一条 Changjiang 线，也有足够证据重新分组。

这套方法同时适用于购买前和维修后。卖家无法提供刻字、尾端和上墨照片时，应按待核验物处理；维修者更换尖、囊、夹或尾件时，应保留原件照片和零件来源。品牌页不替读者选择最有故事的版本，而是把能被下一位收藏者复查的字段优先留下。
