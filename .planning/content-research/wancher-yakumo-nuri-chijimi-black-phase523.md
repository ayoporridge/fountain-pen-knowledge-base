Yakumo-nuri Chijimi - Black 是 Wancher Dream Pen 中一支以“收缩漆”形成深纹理的黑色漆艺钢笔。官方 product JSON 的产品编号为 `9174850044119`，handle 为 `yakumo-nuri-chijimi-black`，商品记录时间为 2026-02-04，页面于 2026-02-05 发布。它不是一个只有颜色选择的普通版本：官方 JSON 列出 Solid Gold 与 Rhodium-plated 两组 Shogun 18K 尖面，并为 Extra Fine、Fine、Medium Fine、Medium、Broad、Kodachi Fine/Medium/Broad 分别设置 SKU。

### Chijimi-nuri 的收缩纹理

品牌把 Chijimi-nuri 解释为一种会在干燥和成熟过程中收缩的 Urushi。先在 Ebonite 基材上涂两层 Urushi，再加入特殊 Chijimi 漆；在受控环境中干燥后，笔身会形成深线和旋涡，触感像橡树树皮。每支笔的纹理方向、深浅和密度都不可复制，图像只能展示原型或当时的实物，不能成为每支黑色版本的纹理模板。

官方把本款与 Yakumo-nuri 以及工艺师 Nagaya Momoko 联系起来。她出生于松江市，毕业于 Kanagawa College of Art，并在出云设立工作室，目标是保存和发展当地传统技法。岛根县立美术馆的地方工艺资料记载，明治时期坂田平一开始八雲塗；出云市名录也把八雲塗列为地方传统工艺。独立资料用于区域背景，不替本款证明具体漆液来源、每层厚度、工匠逐支签名或认证编号。

### 16 个市场变体和供墨

官方规格列 Base material: Ebonite，Art: Yakumo-nuri、Chijimi。尖面是 18K Solid Gold Shogun，页面另说明可选 Rhodium-plated form；feed 只有 Plastic。供墨写为 Converter 或 Cartridge（Sailor Standard），这与多数 Dream Pen 页面所写的 European International Standard 不同，不能直接套用旧条目。帽子带 compact air-tight cap，包装列 Traditional Japanese Wooden Box、Pen Kimono、Instructional Materials、Converter 与 Cartridge。

### 维护、选择和身份核对

深纹理表面容易积尘，清洁仍应先排空墨水，只处理 nib、feed、握段和 converter；笔身用柔软布沿纹理轻拭后自然干燥，不要把整支笔浸水，也不要用牙刷、研磨剂、酒精、丙酮、漂白剂、超声波或热风。京都国立博物馆说明 Urushi 会受紫外线和木胎湿度变化影响，出云和岛根资料提供 Yakumo-nuri 的区域背景；若出现裂纹、脱层、纹理崩落或握段松动，应停用并联系品牌或漆器维修者。

选购时先确定 Solid Gold 或 Rhodium-plated，再选择普通 Shogun 尖面或 Kodachi、尖幅和完整 SKU；不要只说“黑色 Chijimi”而省略 18K/铑饰差异。二手核对要保存 product id `9174850044119`、handle、变体 SKU、Ebonite、Yakumo-nuri、Chijimi、Plastic feed、Sailor Standard 供墨、木盒和 pen kimono。不要把 Chijimi Black 与 Phase 517 的 Chijimi Aodaisho、Nishikihebi、Shirohebi 合并，它们是同技法下的不同商品记录。

Chijimi 的深纹理是这支笔的主要识别线索，但不应拿纹理方向来强行判断某个 SKU；同一尖面、同一饰面也不会拥有相同的线条。收货时应把完整变体标题与 SKU 记录在照片旁边，检查尖面刻字、feed、帽口和纹理是否匹配。若需要旅行携带，先确认收纳槽不会压住凸起的漆纹；出现掉片或边缘起翘时不要用胶水固定，因为这会遮盖后续维修需要的证据。
