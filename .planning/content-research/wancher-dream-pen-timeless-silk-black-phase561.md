## 先读完整名称：Timeless 不是普通 True Ebonite Silk Black 的短版别名

Wancher 的 Dream Pen 既是系列名称，也是一个容易被电商标签压缩的入口。**Dream Pen Timeless – Silk Black** 在官方英文产品页上以完整商品名出现；它保留 Dream Pen 的雪茄形轮廓和乌木路线，却使用更紧凑的尺寸、#5 螺纹不锈钢尖以及 Fine、Medium 两种订单尖幅。站内还存在 **Dream Pen True Ebonite – Silk Black**，那是另一张产品页、另一套商品身份。两者都叫 Silk Black，不能因此合并成一个“黑色乌木款”，也不能把一个型号的笔尖、尺寸或 SKU 复制给另一个。

这一区分不是编辑部为了增加页面数量。Timeless 官方产品 JSON 的 `handle` 是 `dream-pen-timeless-silk-black`，商品标题也保留 Timeless；当前 JSON 变体 SKU 以 `WF-EB-DREAM-SKBK-JR-` 开头，后接 `F` 或 `M`。JSON 的 tags 里还出现 `dream pen junior`、`true ebonite junior` 等目录标签，但标签没有把官方商品标题改成 Junior，也不足以证明它是另一个公开型号。较稳妥的记录方式是：型号身份以 exact product title 和 handle 为主，Junior 只作为电商元数据观察，不将其写进正式名称。

官方英文页面在本次核验时显示 `$140.00 USD` 与 Sold out。售罄只能说明访问时不能直接购买，不能单独推出停产、限量数量、绝版或二手价格。产品 JSON 的 `created_at` 为 2023-02-14，`published_at` 为 2023-02-16（日本标准时间），这是一段电商目录元数据，不等于全球首发日，也不能替代完整的生产史。Wancher 2024 年的官方文章把 Timeless – Silk Black 列为适合手较小读者的紧凑款，说明它在品牌当前的推荐语境中被当作独立选择，而不是普通 True Ebonite 的颜色页。

## “Timeless”讲的是尺寸与使用取向，不是复古年代的生产证明

官方产品说明从所谓钢笔“黄金时代”讲起：1920 至 1950 年代的钢笔常被视为兼具实用性和奢华感的日用品，合盖长度约 5 至 5.5 英寸。Timeless 的命名是 Wancher 对这种尺寸和使用感觉的当代转译。这个品牌叙述可以解释设计意图，却不能证明本型号复刻了某一支历史钢笔、使用了某个 1920 年代的模具，或在那个年代已经生产。正文因此用“参考黄金时代的紧凑尺寸”和“品牌的设计叙事”，不写成历史复刻或老款再版。

Wancher 日本官方 Timeless 系列页用日文写明，Timeless 延续 Dream Pen 的简洁雪茄形，但做成更容易握持的尺寸；同页列出的规格为 **材质：Ebonite，重量：16 g，长度：135 mm**。这里的长度和重量属于该系列页的规格表，正文保留来源口径，不把 135 mm 改写成合盖、未合盖或插帽后的所有长度，也不声称 16 g 一定是裸笔、含帽或含转换器的哪一种称量条件。实际购买时，若重量对手感重要，应向卖家确认是否含帽、转换器和墨水，并用同一口径复核。

官方 2024 文章的推荐语境很具体：对常规 Dream Pen 觉得尺寸偏大的读者，可以考虑 Timeless – Silk Black，因为它保留黑色光泽和 Dream Pen 形状，却更紧凑。这个建议不是对所有人的书写结论，也不是实测人体工学报告。手掌大小只是一个筛选线索；握笔角度、笔尖粗细、纸张、墨水和是否插帽都会改变体验。

## 乌木笔身：温暖、会随使用变化，但不要把营销语句当成护理豁免

英文产品页将材料写作 `Ebonite from Nikko EBONITE in Tokyo`，并把手工“雕刻—研磨—抛光”的过程与日本刀研磨所用的 `Togi` 美学联系起来。它还描述乌木表面略具多孔性，接触皮肤时可能带来温润感，长期使用会形成个人痕迹。这里要把三层信息分开：Nikko EBONITE 是品牌列出的材料来源；Togi 是品牌对加工与抛光方式的叙述；“温暖”“随时间变好”是官方使用语境，不是编辑部对所有温度、汗液和年份的实验结论。

乌木不应被写成“永不变色”的塑料，也不应因为材料有孔隙就长时间浸水。官方产品护理页对乌木及其他材质的清洁、墨水和保存提供通用建议；本页采用保守做法：日常用柔软干布轻拭，避免酸性或研磨性清洁剂、含溶剂产品、粗糙纸巾和长时间日晒。若表面出现泛黄、发白、裂纹、黏腻或明显划痕，先拍照并向 Wancher 或卖家确认，不要用家具蜡、金属抛光膏或强力溶剂自行“恢复光泽”。一次个人经验不能变成所有乌木钢笔的普遍护理规则。

Timeless 的 Silk Black 是黑色表面与乌木材质的组合，不等于已有 True Ebonite Silk Black 的同一生产批次。尤其要注意，当前产品 JSON 的图片文件名里有 `true-ebonite-junior` 字样，页面 tags 也包含 `true ebonite junior`；这些是商品后台为关联搜索留下的标签或资源命名，不能推断两个页面应合并。购买时应看完整标题、页面 handle、尖幅和 SKU，而不是只看“True Ebonite”“Silk Black”四个词。

## 笔尖：#5 螺纹不锈钢，Fine 与 Medium 是同一型号的两个市场 SKU

官方英文产品页的 Important Note 写得很明确：本笔配备 **Stainless steel #5 (screw type) nib**，可选 Fine 和 Medium。它不是 #6 JoWo 尖，也不是金尖；页面用 `Proprietary Stainless Steel Nib` 描述规格，不能从其他 Dream Pen 或 JoWo 产品页借入品牌、尖片厚度或调校结论。笔尖是螺纹安装，意味着更换时应以当前尖座、帽内间隙和品牌兼容信息为准，不要把“#5”当作所有第三方 #5 单元都能无损互换的承诺。

官方 product JSON 列出两个变体：

- `WF-EB-DREAM-SKBK-JR-F`：Fine；
- `WF-EB-DREAM-SKBK-JR-M`：Medium。

这两个 SKU 属于同一 Timeless – Silk Black 型号的 `market_sku` 变体，不应该拆成两张型号页。Fine 和 Medium 是订单选项名称，不是统一的毫米线宽，也不保证在不同国家、纸张或墨水上呈现相同的粗细。当前资料没有给出线宽公差、出厂调校、铱粒尺寸、弹性、干湿度或书写角度。到手后可以记录真实线条，但那应标为这支笔的用户观察，不回填为全系列规则。

这里也有一个值得保留的历史边界：较早或相邻 Dream Pen 页面可能使用 #6、JoWo 或其他 feed 说法，但 Timeless exact page 当前写的是 #5 螺纹不锈钢尖。不能因为它们都属于 Dream Pen，就把 #6 规格搬到 Timeless；也不能因 JSON 的 `JR` SKU 后缀，就猜测尖座、笔身或系列有一个未公布的“Junior”正式版本。若将来官方维修页明确解释 `JR`，再按新的来源更新变体备注。

## 供墨与 feed：Mini Converter／欧规墨囊，塑料 feed 是当前页面的范围

官方规格给出的供墨路径是 **Mini Converter or Cartridge (European International Standard)**，feed 则写为 **Plastic only**。这两条信息对于购买很实用：需要换色的人可以使用小型转换器，想少清洗的人可以选择欧规标准墨囊；但页面没有授权把笔身当作 eyedropper 使用，也没有说明其他品牌转换器在每个批次都能顺利安装。应先确认随笔附带的转换器和墨囊，遇到阻力不要用力旋紧。

换墨或长期收纳时，可以先取下墨囊或 Mini Converter，用室温清水短时吸排，待水色明显变淡后让握位、feed 和尖部自然干燥。清洗供墨系统不等于把乌木笔身浸在水里；乌木与螺纹、内帽都不适合反复长时间泡洗。若出现启动慢、漏墨或干尖，先检查墨囊／转换器是否坐稳、尖部是否有干墨、帽是否旋紧，再按 Wancher Product Care 的通用路径处理。Compact air-tight cap 的设计目标是帮助减少干墨，不是“永远不会干”的保证。
