# Magna Carta Mag 600：把现代弹性尖放进大号树脂笔

## 型号定位

Magna Carta 的 Mag 600 是一个独立的现代钢笔型号，不是品牌名，也不应与 Mag 600 S、Mag 650 或 Mag 1000 合并。官方商店把 Mag 600、Mag 600 S、Mag 1000 与 Trilli 分成不同导航，说明它们是不同的产品路线。Mag 600 的识别重点是大尺寸树脂笔身、#6 弹性尖和 cartridge/converter 上墨；颜色、饰件和尖的材质是具体 SKU 的版本层。

“True Flex”是 Magna Carta 对笔尖的商品命名。它可以解释为什么这支笔适合想尝试线条变化的人，但不能写成所有压力、纸张、墨水下都能达到同一线宽，也不能与 vintage flex 或其他品牌的 FA、柔尖直接等同。官网 Blue Opal 商品页把 SKU 写为 FP-MG600BO-TF，并列出 14K True Flex；这是一个可追溯的当代商品配置。

## 规格与结构

官方 Blue Opal 页给出 artisan resin 笔身、24K PVD gold plated trim、#6 14K Gold True Flex、ebonite feed 和 cartridge/converter filling system。尺寸包括帽盖直径 16.40 mm、笔杆直径 15.00 mm、握位直径约 10.70 mm、有帽长度 146.00 mm。这个尺寸组合使 Mag 600 属于明显偏大的正装笔；专业评测对另一支样本测得 149.7 mm 有帽、约 27 g，但样本、年份和颜色不同，不能覆盖官方 SKU 的固定规格。

官方页没有把所有 Mag 600 写成同一颜色或同一 nib；Blue Opal、Sky Blush、Faux Pixel、Black、Rustic Red 等出现在不同商店或时期，可能对应不同 trim、树脂坯料和尖配置。颜色与表面变化应归入 variant，只有 Mag 600 S 这类官方独立命名、结构或尖路线才另建型号。购买时保存 SKU、nib 选项和商店日期。

## 弹性尖的使用边界

14K True Flex 的目标是低压线条变化，但“flex”不等于可以像普通 F 尖一样随意快速书写。首次使用先用轻压力在普通纸上画短线，确认 feed 能持续供墨，再逐步增加压力；不要把笔尖压到两叉完全张开，也不要在干墨或高阻力纸上强行拉大字幅。专业评测记录过 Mag 600 样本的 flex 感受、轻重量和 converter 路线；这些观察应该归因到具体样本，不能变成“每支都 wet noodle”或“绝不 railroading”的承诺。

如果主要写小字、会议笔记或细线速记，普通硬尖或较轻压力的写法可能比 True Flex 更合适；如果想练英文花体或需要标题中的粗细变化，则应准备低速、较湿的水性墨水和吸水性适中的纸张。弹性尖在压力释放时会回到较细线，但回弹速度和供墨取决于尖、feed、墨水和手法。

## 上墨、维护与选购

Mag 600 使用 cartridge/converter。装墨前冲洗原装 feed，安装 converter 时只需旋入到位，不要过度拧紧。弹性尖对供墨稳定性更敏感，清洗应比普通硬尖更彻底：用室温清水反复吸排，直到水基本清澈；若要更换 nib unit，先确认螺纹和 feed 兼容，不要把 #6 外径相同误解为无条件可换。ebonite feed 避免长时间热水、酒精和强溶剂，PVD 饰件用软布擦拭。

大号笔身和不贴合的帽盖会影响长写姿势。专业样本中有人觉得 section 长且舒适，也有人不习惯不能稳固 post；这些应作为带来源的个体体验。下单前确认是否能 post、所选 nib 是 14K True Flex 还是其他选项、是否随附 converter、当前颜色是否有库存。官方商品页显示某些颜色会 sold out，库存和售价是动态信息，不能当成停产结论。
