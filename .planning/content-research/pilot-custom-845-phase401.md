# 百乐 Pilot Custom 845：No.15 蝋色漆与 FKV-5MR 的完整边界

## summary

Pilot Custom 845 是 FKV-5MR 漆饰钢笔：切削硬橡胶、蝋色漆、18K No.15 金尖与 Pilot C/C 供墨构成独立型号。官方当前目录列出漆黑、朱、紺青三色与 F/M/B/BB；可复核的 FKV-5MR-B-F 为 147 mm、28 g、含税 ¥132,000。

## 先把 845 认清：一个型号，很多 SKU

Custom 845 的名字很容易被写成「Pilot 的漆笔」，但这样的说法太宽。官方支持页把这支笔写作「カスタム 845」，产品族写作 FKV-5MR；当前日本 Web Catalog 的精确商品页则把一个可购买 SKU 写成 FKV-5MR-B-F。这里的 FKV-5MR 是平台级产品号，B 是漆黑颜色组，F 是尖幅。读者在目录、包装、笔尖或二手交易页面看到的完整产品号，才足以把颜色和尖幅落到具体版本。

这不是为了制造繁琐的编号游戏。845 的同一型号下面同时存在漆黑、朱、紺青，以及 F、M、B、BB 四种尖幅；如果只写「黑色 845」而不写尖号，就无法判断笔尖、原始价格和替换件是否相符。反过来，某个卖家把一支黑色 Pilot 称作「845 Urushi」，也不能单凭漆面颜色完成身份认定。应当把笔尖刻字、帽环或包装上的 CUSTOM 845/URUSHI 字样、产品号和清晰的实物照片放在一起核对。

本页的范围是 FKV-5MR 这条 845 钢笔产品线。市场上可能还有油性笔、套装、地区包装或二手商家自行使用的简称；这些不自动成为新的钢笔型号。后配转换器、改尖、调尖、重涂和用别的笔帽替换，也不改变出厂型号，更不能让一支改装笔获得原厂版本的规格。

## 2002 年的 CUSTOM 位置：漆工艺不是后加的装饰

Pilot 的 CUSTOM 官方历史把 CUSTOM845 放在 2002 年，并给出 FKV-5MR。官方叙述的重点不是一个「豪华版」营销标签，而是它帮助公司延续早期开发的 Luccanite 漆工艺：把漆施在加工成形的 ebonite 上，让硬橡胶的圆杆表面得到黑色高光和不同于普通树脂的触感。这里的历史时间来自 Pilot 自己的产品年表，和当前目录上的 SKU 状态属于两个层次；不能因为 2002 年的型号节点，就把每一支后来生产的具体批次、漆层次数或手工师傅写成同一件事。

官方 CUSTOM 专题把 845 与 Custom URUSHI 放在同一「蝋色漆／硬橡胶」最高级路线中，却仍然分别列为两个型号。845 的产品号是 FKV-5MR，采用 No.15 金尖；URUSHI 的产品号是 FKV-88SR，采用 No.30 金尖。两支笔都有漆面，不代表可以把 URUSHI 的 30 号笔尖、体量、价格或写感移到 845。对版本研究来说，这个边界比「谁更高级」更有用。

「845」也不应被解释成 Custom 系列的通用等级。Pilot 的历史说明，CUSTOM 的数字常常与推出时的周年或型号节点有关，但有例外。2002 年的 845 是一个具体产品家族；它的编号不是笔身长度、笔尖尺寸或漆层厚度的单位。书写者在不同市场看到的 FKV-5MR、Custom 845、Custom 845 Urushi 等名称，应该先映射回官方产品号，再讨论颜色和尖幅。

## 硬橡胶、蝋色漆与金色饰件

日本官方当前 SKU 页明确写出「エボナイトを削り出し蝋色漆で仕上げ」，也就是把 ebonite 加工成笔身与笔帽，再以蝋色漆完成表面。硬橡胶并不是「黑色树脂」的同义词；它是一个需要在保存和清洁时被认真对待的材料。漆层把颜色、光泽和触感带到手中，也使强溶剂、研磨和高温变得更不合适。

845 的外形是平顶、平尾、圆杆的 CUSTOM 轮廓，金色饰件把帽环、夹和笔尖连接成一个完整的视觉系统。图片中的金色反光、朱色深浅和蝋色漆的光泽会随光线、白平衡和使用痕迹改变；不能用网络照片的一处亮斑判断真伪，也不能把所有朱色都当作同一生产批次。漆面有自然差异，不等于每种差异都是「手工限量」或瑕疵。

蝋色漆适合被当作一种需要温和接触的工作表面，而不是一层可以反复抛光的汽车漆。日常书写后的指纹，用干净柔软的布轻轻带走即可；不要用酒精湿巾、含溶剂的清洁剂、金属抛光膏、研磨布或魔术海绵。若笔帽外表沾到墨水，先用微湿软布局部处理，随后擦干，避免液体沿帽口或螺纹进入内部。

蝋色漆也不意味着笔必须被供在玻璃柜里。Pilot 官方说明的实际边界是避免直射日光、高温、低温和强烈冲击。只要使用者把它放进有缓冲的笔袋，避免和钥匙、裸露金属笔夹长时间摩擦，就可以把 845 当作日常书写工具。若发现漆面起泡、深划痕、裂纹或不明溶剂痕迹，先停止继续擦拭，拍照记录并咨询品牌或熟悉漆笔的维修人员。

## No.15 笔尖：大号不等于可以随意压弯

官方当前目录把 FKV-5MR 的笔尖列为 18K 15 号。日本目录的 lineup 区域列出 F、M、B、BB 四个尖幅，并把每个颜色组的完整产品号展开。No.15 是 Pilot 的笔尖规格名称，不是「任何较大的钢笔尖」的通称；因此不能用 823、743 或 URUSHI 的笔尖照片和尺寸替代 845 的证据。

F、M、B、BB 之间首先是线宽和出墨需求的差别。F 往往更容易适应小字和窄行距，M 作为日常笔记的折中，B 和 BB 则更需要较宽的纸面与更充足的干燥时间；这些是选购方向，不是对每支笔的写感承诺。实际线条还会受到纸张涂层、墨水黏度、握笔角度、供墨状态和单支调校影响。专业评测可以记录某一支笔的反馈，但不能替代官方尖号。

「No.15 很软」或「845 一定有弹性」都不是可靠的统一结论。即使同一尖幅，笔舌状态、调校历史和使用者施力也会改变书写感觉。Pilot 的产品定位和专业资料可以帮助理解大型金尖的方向，却不应被翻译成允许用力压弯的承诺。金尖出现异常阻力、起笔断墨、单边刮纸或尖缝变形时，应停止加压；不要用网上的压力测试把漆杆和笔尖一起置于风险中。

买二手笔时，先看笔尖正面、尖缝、鼻尖和刻字，再看笔杆和帽环。产品号中的最后一个字母是尖幅线索，但一个被改尖的 FKV-5MR 仍然应标注为「后配／改尖」，不能当作原装 BB。若笔尖刻字模糊，宁可把尖号记为待核对，也不要根据卖家标题猜测。

## C/C 供墨：CON-40 和 CON-70N 是 845 的结构线索

Custom 845 走 Pilot 墨囊／转换器（cartridge/converter，通常简称 c/c）路线。官方支持页逐步说明了 Pilot 墨囊、旋转式 CON-40 和推式 CON-70N 的装配与吸墨。当前 FKV-5MR-B-F 的 Web Catalog 写明兼容 CON-40、CON-70N，并标注随附 CON-70N。它不是 Custom 823 的真空／活塞式吸墨结构；清洗方式、携带姿势和一次可装的墨量都不应混写。

CON-40 的体积较小，适合希望保持轻巧、频繁换色或不需要大容量的使用者；CON-70N 可以提供更大的储墨量，官方说明中也给出了推压吸墨的步骤。实际容量、残余墨水和吸入次数以转换器本身和正确操作为准，不把零售商的「约多少毫升」写成 FKV-5MR 的固定规格。无论使用哪一种，先确认转换器与握位连接牢靠，再让笔尖浸入墨水，避免把鼻尖磕到瓶底。

使用墨囊时，应把笔尖朝上、直插到位，不要边旋边用力扭动。更换转换器时，先把余墨排出，再轻轻退出；Pilot 的支持页还提醒，转换器应清洗并干燥后再存放。新买的 845 如果出墨慢，不要立刻拆笔尖；先检查转换器是否完全推入、吸墨时笔尖是否浸到正确位置，以及墨水是否太久未用。

845 的 C/C 结构是它与 823、Vac 系列最清楚的身份差异之一。把 823 的真空尾杆或大容量数据写进 845，会让读者误以为可以通过旋转尾杆排墨；反过来，拿 845 的 CON-70N 去解释 823，也会使清洗与维修建议失真。页面中所有供墨数字和配件名称都只在 FKV-5MR 的范围内使用。

## 当前颜色与尖幅：三组 edition、十二个市场 SKU

Pilot 当前 Web Catalog 在 FKV-5MR 页面中列出三组颜色：漆黑（B）、朱（R）、紺青（L）。每组有 F、M、B、BB 四种尖幅，产品号可按下表读取。颜色组是同一型号下的 edition group，具体产品号是 market SKU；它们不是要新建的三个或十二个钢笔实体。

这张表表达的是当前日本官方页面的产品号边界，不是对所有国家库存的承诺。其他地区可能以不同包装、不同价格或不同运输状态销售同一平台；若某地区页面只展示黑色或只提供 F/M，不能反推 Pilot 在全球停产了其他 SKU。产品号中的 B、R、L 是颜色组线索，最后的 F/M/B/BB 才是尖幅；其中同一字母在中间和末尾的含义不同，书写时应完整保留连字符。

当前 FKV-5MR-B-F 页面给出的是漆黑 F 尖的精确 SKU 数据：18K No.15、最大径 φ15.9 mm、全长 147 mm、重量 28 g、含税建议零售价 132,000 日元（税前 120,000 日元）。这些数字属于这一个当前目录页，不能未经说明就延伸到朱色、紺青或 BB。颜色和尖幅大多共享同一平台，但帽环电镀、附件、批次和地区价格仍需以实际商品页为准。

紺青在一些海外评测或零售页面中也被写成 Prussian blue。英文名称、日文「紺青」和中文「深蓝」是颜色称呼的对应关系，不代表第三个型号。若收藏记录要长期可读，建议保存官方日文产品号、颜色原文和取得地区，不只保存一个翻译后的颜色名。

## 尺寸、重量与价格：把 SKU 作用域写清楚

845 的官方当前 FKV-5MR-B-F 页面给出全长 147 mm、最大径 φ15.9 mm、重量 28 g。目录没有把这些数字写成所有颜色与尖幅版本的独立测量；因此本文将它们标记为当前漆黑 F 尖 SKU 的数值。帽是否旋紧、是否含转换器、手工测量的误差和二手加装附件，都会影响读者用自己的秤或尺子复核时的结果。

同一页面列出含税建议零售价 ¥132,000、税前 ¥120,000。价格是日本官方当前目录的建议值，不是全球成交价，也不等于二手笔的保值金额。汇率、进口税、经销商折扣、库存和颜色尖幅都可能改变买家最后支付的金额。若网页上出现很低或很高的价格，先核对产品号、尖幅、附件和笔况，再讨论「便宜」或「溢价」。

对 845 来说，重量不是单独的购买理由。硬橡胶和漆面带来的触感、No.15 笔尖、帽的长度、笔夹位置以及是否长时间握持，都会影响一支笔的实际负担。有人喜欢不戴帽书写，有人会把帽旋在尾端；这类体验属于个人使用记录，不应从一个 28 g 的数字推导出所有人都能舒适书写。

## 和相邻 Pilot 型号怎么分

### Custom URUSHI

URUSHI 的官方产品号是 FKV-88SR，18K No.30，体量明显大于 845，当前产品组列出 FM、M、B。两者都采用硬橡胶与漆面，也都使用 Pilot 的 C/C 路线，所以很容易在零售标题中被混称。真正的区分点是产品号、笔尖编号和尺寸；不要把 URUSHI 的 No.30 弹性、155 mm 或 44 g 复制到 845。

### Custom 823

823 是 FKK-3MRP，官方历史明确它采用可吸入较大墨量的 plunger／vacuum 机制。它和 845 都常被放在「大型 Custom」的购买比较中，但 823 的透明或半透明树脂筒身、尾杆和吸墨结构是一套不同身份。想减少补墨次数可研究 823；想要漆杆质感和 c/c 的快速换墨，845 才是本页讨论的路线。

### Custom 743

743 使用 No.15 尖，但官方产品线将它作为树脂杆的 C/C 型号单独列出。No.15 这个共同点只能说明笔尖规格相近，不能说明漆面、颜色、重量或价格相同。将 743 的普通树脂杆和 845 的蝋色漆硬橡胶写成同一笔的不同配色，是最常见的身份错误之一。

### Custom 742 与 Custom Heritage 912

742 采用 No.10 路线，912 是 Custom Heritage 外形和产品号体系中的独立型号。二者都可以作为较轻或较窄的试写参照，却不应成为 845 的「变体」或笔尖替换清单。尤其是把 912 的尖号、树脂材质和价格抄到 845 页面，会掩盖 845 真正需要核对的漆面与产品号。

这几支笔可以放在同一张选购表里，但表格应把品牌、系列、产品号、笔尖规格、供墨和材质分成独立列。相似的「Custom」名字只建立导航关系，不改变每支笔的身份。用户从品牌页跳到 845 时，看到的应是一个完整型号页，而不是一段把五支笔压缩成同一件商品的综述。

## 第一次上墨与日常书写

新笔到手时，先检查笔尖是否有运输保护、转换器是否在盒内、帽螺纹和夹子有没有明显磕碰。用清水短暂冲洗或吸排，确认内部没有可见杂质，再装 Pilot 墨囊或 CON-40/CON-70N。让墨水沿供墨路径自然到达笔尖，避免一开始就用力挤压转换器或在纸面上反复刮擦尖端。

845 的 F、M、B、BB 需要不同的书写节奏。F 在干燥较慢或吸水强的纸上比较容易控制；B、BB 在日记、签名和展示字迹中更有存在感，却可能在薄纸背面洇开。选墨时先看纸张和干燥环境，再考虑颜色。漆面本身不要求特殊墨水，但 Pilot 的官方支持明确给出品牌墨水与颜料墨水的边界；漆制品不能使用 Pilot 颜料墨水「强色」。不要把「防水」需求放在漆面安全之前。

笔帽是否后戴属于个人习惯。若后戴时笔身变得过长或平衡点向后移动，可以不后戴；如果一定要后戴，确认帽口没有砂粒，避免旋紧过度。漆面与金属件都不适合和钥匙、硬笔夹放在同一裸露口袋中。短途携带时，笔尖向上、转换器连接牢固、帽子完全旋紧，能降低渗漏风险；飞机或剧烈气压变化场景应遵照 Pilot 的支持说明。

## 清洗、停用和维修边界

换色或长期停用前，先排尽墨水。Pilot 官方支持页建议用清水多次吸入和排出，直到流出的水基本清澈，再自然干燥。清洗重点是笔尖、笔舌和握位内部的墨水通路；硬橡胶笔身、漆面笔帽和轴不应为了「彻底」而浸在水里。页面还特别提醒，不要清洗帽与轴，不要自行修理精密部件。

清水应接近室温。热水、酒精、强碱或强酸清洁剂、超声波和尖锐工具都可能让漆层、硬橡胶、密封件或金属饰件承受不必要的风险。遇到干涸墨水，先让握位短时接触清水并重复吸排；不要把整支笔泡在溶液里，也不要用针戳笔舌。清洗后让笔尖向下或水平短暂沥干，再在通风处自然阴干，避免热风直吹。

如果出墨异常，按由低风险到高风险的顺序排查：墨囊或转换器是否安装到位，是否有足够余墨，笔尖是否因纸屑堵塞，清水吸排是否完成，帽和握位是否有裂纹。每一步都应记录现象，而不是连续拆卸。持续漏墨、吸墨时阻力异常、笔尖刮纸或漆面开裂，应停止继续施力，联系 Pilot 售后或熟悉 Pilot C/C 与漆笔的维修人员。

官方支持还提醒，溶剂可能引起裂纹或变色，强烈冲击会造成故障。二手笔上发现不明清洁剂、残留胶水或重新上漆痕迹时，先把它当作维修史的一部分记录，不要因为想恢复光泽而立即抛光。漆层少一点光亮，比不可逆地磨掉原有表面更容易被接受。

## 选购：先决定结构，再决定颜色

845 适合把蝋色漆的手感、No.15 金尖和可换墨的 C/C 结构放在同一优先级的人。若首要目标是大容量、少补墨，823 的真空结构更直接；若想要更大的 No.30 笔尖和厚重笔身，应该试写 Custom URUSHI；若更在意尖幅选择而不需要漆面，743 或 742 的价格和树脂杆可能更合理。不要只因为一个型号数字听起来更高，就把选购顺序倒过来。

颜色选择也不应脱离握持。漆黑最容易在不同光线下保持中性，朱色的反光和深浅更容易受照片影响，紺青在不同市场的名称可能是 Prussian blue 或其他译法。若购买的是 F 或 BB，先确定自己的纸张和字幅；如果只是想拥有某一种漆色而尖号没有明确记录，建议要求卖家补拍笔尖刻字和产品号。

新笔和二手笔都应核对四件事：完整产品号、尖幅刻字、供墨附件、漆面和帽口状态。当前官方 FKV-5MR-B-F 页随附 CON-70N，但其他颜色、海外套装或二手交易不应默认附件完全相同。没有产品号的宣传图可以作为兴趣线索，不能作为版本证据。

「限量」「停产」「绝版」「保值」属于市场或销售判断，必须另找时间、地区和库存证据。官方当前页面能证明的是产品族、SKU、规格和当期建议价格；它不能单独证明一支二手笔的生产年份、保存方式或未来价格。把这些信息分别记录，才能避免把稀缺营销词写进百科事实。

## 二手到手核对清单

第一步拍照：笔尖正面、笔尖侧面、握位、帽环、笔尾、产品号或包装标签、转换器。第二步记录颜色和尖号，不要只写「黑色 845」。第三步在清水状态下检查转换器能否安装和吸排，确认笔帽能顺畅旋合，不要用蛮力校正螺纹。第四步再决定是否装墨水试写。

漆面小的色差、反光不均和正常使用痕迹需要放在光线和年代背景下判断；起泡、裂纹、严重划痕、露出底材、明显溶剂痕迹和帽口变形则应在交易前明确。若卖家把 845 与 Custom URUSHI、823 或 743 的照片混用，要求补充实物细节；不能用官方宣传图替代手中那支笔的身份。

试写记录要注明墨水、纸张、尖幅、是否戴帽和清洗状态。「顺滑」「有反馈」「偏湿」都是某一次使用的观察，不应抹掉条件后写成所有 845 的承诺。对收藏者，记录购买日期、地区、附件和笔尖刻字；对日用者，优先确认售后、常用墨水和便携保护。昂贵漆面不能代替适合自己的握持。

## 给使用者的一句话

Custom 845 的价值不在于把它说成「小一号的 URUSHI」，而在于它独立完成了一个很清楚的组合：FKV-5MR、No.15、硬橡胶蝋色漆和 Pilot C/C。先把这个组合核对清楚，再按纸张、尖幅、颜色和预算选择；清洗时尊重漆面和硬橡胶，维修时尊重不可逆的边界。这样，845 才既是一件有历史位置的 Pilot 产品，也是一支可以稳定使用的钢笔。
