# Namiki Aya

## summary

Namiki Aya 以硬橡胶胎、彩漆和研出莳绘组成四个图案，配 18K No.30 笔尖；图案是系列版本，品牌关系仍归 Namiki。

# Namiki Aya：先看“彩”如何成为一个系列

Namiki 官网对 Aya 的解释不是简单的颜色名。“Aya”可以指色彩、光泽、闪耀与纹样；系列用多层彩漆形成变化，再以 Togidashi Maki-e，也就是研出莳绘，让图案在打磨后的漆层中显现。官网当前列 Daybreak（Akatsuki）、Gale（Hayate）、Limpid Stream（Seiryu）与 Evergreen（Tokiwa）四个图案。它们共同组成 Aya，不应拆成四个互不相干的基础型号。

品牌关系也需要写准。Aya 挂在 **Namiki**，不是把 Namiki 仅仅当作 Pilot 普通量产钢笔的一个颜色标签。Namiki 与 Pilot 有公司和技术渊源，但官网为 Namiki 建立了独立 collection、工艺叙述与商品身份。知识图谱中，Aya 的 made_by 指向 Namiki；Pilot 的墨囊和 converter 兼容性则写在供墨规格里，两种关系不能混用。

## 四个图案，共用哪些事实

Aya collection 页面说明系列使用 No.30 笔尖，并把四个图案并列。Daybreak 的 exact 页面进一步给出 FNA-30M-AKA、Kokkokai、Togidashi Maki-e、18K No.30 与 FM／M／B。这些是最坚实的锚点：Daybreak 的货号和尖幅属于这个 exact page；不能只因同属 Aya，就假定所有市场、所有图案当下都有完全相同库存。

专业零售商 Stilo e Stile 的 Evergreen 页面记录硬橡胶胎、18K No.30、Pilot cartridge／converter、随附 CON-70N、螺纹帽、约 164 mm 收帽和 44 g。尺寸与重量明确来自 Evergreen SKU，适合帮助理解 Aya 的体量，却不应伪装成 Namiki 对全系列公布的零误差通用值。漆层、金属件、包装和尖幅库存都应回到具体 SKU 核对。

Daybreak、Gale、Limpid Stream、Evergreen 的英文名与日文罗马字，是图案名称的对应表达，不是八个版本。颜色在不同光源、漆层厚度和屏幕上会有变化；官网图只能用于辨认设计，不能作为颜色校样。手工漆艺也意味着细微差异不必然是瑕疵，但任何明显裂纹、脱漆或维修痕迹仍应在二手交易中说明。

## No.30 笔尖意味着什么

No.30 是 Namiki／Pilot 体系里的大型笔尖规格名称，不是“30 毫米尖”的简单尺寸承诺。Daybreak 官网列 18K 和 FM、M、B。较大的金尖会给视觉和落笔带来不同感受，但页面没有承诺 flex；选购时不应以重压测试所谓弹性。金尖同样可能因摔落而错位，软一些也不等于能承受书法尖的压力变化。

FM、M、B 的实际线宽会受到墨水、纸张、角度和调校影响。若日常写较小汉字，先找相同 No.30 尖试写比套用其他 Pilot 型号的尖幅印象更可靠。二手笔尤其要看尖铱是否磨偏、两片是否平齐、笔舌是否归中；只凭一张正面照片无法判断出墨稳定性。

供墨方面，Evergreen 零售页以 CON-70N 为当前样本配置。安装时让 converter 直向到位，不要斜拧；吸墨后擦净握段螺纹和笔尖背面。更换墨水时，用室温清水反复吸排，直到出水基本透明。若使用高饱和、亮粉或防水墨水，应缩短清洗间隔，并先确认它适合钢笔。

## 漆面维护比“抛光”更重要

漆艺笔身的维护核心是少摩擦、避强光、远离溶剂。日常只需用干净柔软布轻拭指纹；不要用酒精、金属抛光剂、研磨膏或家用清洁剂。长时间暴晒、高温车厢与极端干湿变化都没有必要。收纳时让笔与钥匙、拉链和其他金属笔分开，最好使用单独软袋或有隔断的笔盒。

清洗墨路时，只让水经过笔尖、笔舌、握段内部和 converter，不把整支漆面笔长时间浸泡。擦拭笔尖周围残墨时让布保持干净，避免带着微粒反复摩擦。套帽书写可能让帽内金属或尘粒接触漆面；在没有 exact 官方许可和自身确认前，保守做法是不 post。

螺纹帽要沿轴线旋开、旋紧，感觉异常阻力时先退回检查，不要强拧。若漆面已经出现结构性损伤、笔尖需要校正或内部密封异常，应交给品牌服务或熟悉漆艺钢笔的维修人员，不要自行打磨补漆。

## 谁适合买 Aya

Aya 适合希望把大型 No.30 金尖与当代彩漆、研出莳绘放在同一支日用或收藏笔上的人。选购顺序可以是：先确认图案，再确认尖幅和 exact 货号，最后确认随附 converter、包装、保卡与售后地区。只比较“哪个颜色更稀有”容易忽略真正影响使用的尖幅与握持体量。

线上购买应要求自然光实拍，分别看笔杆、帽、螺纹、笔尖正反面和货号。二手还应问是否长期装墨、是否维修、是否用研磨剂处理过漆面。44 g 与 164 mm 是 Evergreen SKU 的参考；手小、偏好轻笔或习惯套帽的人，最好先实际握持。

如果只是想体验 Pilot/Namiki 大型金尖，也应与其他 No.30 型号比较；如果最重视复杂的高蒔绘题材，则 Aya 的彩漆抽象纹样也未必是目标。Aya 的身份很清楚：它不是所有 Namiki 漆笔的总称，而是四个当前图案组成的具体 collection。

## 型号边界

- made_by：Namiki；不要把 Pilot 配件兼容误写成 Pilot 普通品牌型号。
- 四个当前图案是 Aya variant，不建立四个基础型号。
- Daybreak exact page 的 FNA-30M-AKA、FM/M/B 只直接覆盖该页面。
- Evergreen 的 164 mm、44 g 与 CON-70N 是该零售 SKU 证据，其他图案按 exact 页复核。
- 不并入 Yukari、Emperor、Chinkin、Urushi Collection 或 Pilot Custom Urushi。
