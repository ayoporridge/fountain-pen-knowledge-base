# Pineider Millenium：先核对 PP4801／945，再处理那个多出来的 n

## 身份：当前官网的单 n 是 canonical

Pineider 当前美国商品页标题明确写 **Millenium Fountain Pen**，Model 是 **PP4801／945**。本站以这两个同时出现的身份点建立型号页，并采用官网当前的单 n 拼写 `Millenium`。Pineider 2024 年 5 月 22 日的 Collector’s Jewel Pens 文章在 Masterpiece Collection 段落写成 `Millennium`，Chatterley 的标题也使用双 n，但正文又回到单 n。双 n 因此是可检索、有来源的拼写别名，不建立第二支笔，也不据此推断一个不同年代或不同配置。

“250 years of Pineider”解释的是这支笔的纪念语境。官网正文说它为品牌 250 周年而作、限量 **88 pieces**，但页面没有给出精确发布日期。2024 官方文章能证明那一年已经有双 n 的家族记录，不能替代 launch date。本站不把“1774＋250”算术结果写成未经页面明示的产品发布日期，也不把网页库存或促销价格当作历史节点。

## 五个 current child SKU：尖幅与代码必须成对

当前商品页 HTML 的 variant 区可直接回读五个完整子 SKU。Fine 对应 **SSPFXPP4801G20**，Medium 对应 **SSPMXPP4801G20**，Stub 对应 **SSPSXPP4801G20**，Broad 对应 **SSPBXPP4801G20**，Extra Fine 对应 **SSPEXPP4801G20**。它们共同归在 PP4801／945、NERO 与 current PP4801G20 scope 下；F／M／S／B／EF 是销售尖幅，不是五个独立型号。

官网描述把这支 current product 的笔尖写成 **14 kt hyperflex gold nib**。因此 14K 与五尖幅可以进入 PP4801G20 current 子 SKU 范围，但不能扩成“所有 Pineider 的 F／M／S／B／EF 都是 14K”。Avatar、Rock、Mystery Fast Filler 的不同版本各有自己的尖材质证据。`hyperflex` 也不是允许重压的操作承诺；先以轻压、正常回弹和持续供墨为准，过度劈叉可能造成尖齿错位或供墨中断。

## 当前能确认的材料、闭合与上墨

商品页 DESCRIPTION 直接写 **aluminum and black PVD**、耐用的 **marine steel clip**、**Twist Magnetic Lock** 与 **Piston Filler**，DETAILS 写 Origin **Italy**。Pen Savings 的 Millenium Stealth Black 商品档案逐项重复 88、aluminum／black PVD、14 kt hyperflex、marine steel clip、Twist Magnetic Lock 和 piston；Chatterley 的 PP4801 档案也把 Millenium 与 88 支纪念版绑定。它们提供专业零售交叉，但 exact current 身份仍由 Pineider 的 PP4801／945 页面决定。

官网没有公布 current PP4801／945 的长度、直径或重量。零售标题中看见“oversize”“metal”或某个运输重量，都不能补进产品尺寸。尤其不能拿 Arman Trilogy 的 156.8 mm、68.32 g 或开孔结构来填；那些数字和结构属于另一组具名零售记录。本站 current spec 因而如实写“官方未公布尺寸与重量”，而不是用相似代码制造精确感。

## PP4801G20／Arman 同码冲突：保留，不合并

同一个基础码出现了必须正面处理的旧档案。Truphae 把 **PP4801G20-EF／F／M／B／S** 列为 `Pineider Arman Black Aluminum Limited Edition Fountain Pen`；ItalianPens 的 **PP4801G20-M** 页面标题是 `Arman Black PVD LE`，正文又叙述 Arman、Trilogy、Doppler 的开孔与重复切割语言。Pen Savings 的品牌列表还出现 `Arman Trilogy ... Aluminum`。这些页面说明市场资料确实把 PP4801G20 与 Arman 名称连在一起，不能静默删除。

但它们也不能自动成为 Millenium alias。当前 Pineider 官网同一 PP4801G20 组合明确生成 Millenium child SKU，当前 collection 同样展示 Millenium；现有资料中没有 Pineider 官方 rename、continuity 或“Arman 改名 Millenium”的说明。本站的结论是：**canonical current identity 为 Millenium PP4801／945；Arman Black Aluminum／Black PVD／Trilogy 是 historical／ambiguous same-code evidence**。只有 single／double n 拼写进入 alias，Arman 名称不进入 alias。

这个处理同时隔离结构与规格。Arman 页面里的连续开孔、三等分切割、Doppler 图案、68 g 级样本、其他限量数或展台包装，都不授权 Millenium current field。即使二手实物贴有 PP4801G20 标签，也要继续比对盒证标题、完整尖幅后缀、笔身结构和购买日期；同码冲突不是让两个记录互相补规格的许可。

## 上墨、清洁与日常使用

Millenium current 是内置 Piston Filler，使用瓶装墨水。上墨前让笔尖和 feed 的进墨位置完全浸入墨水，缓慢驱动尾端，接近阻力点就停止；不要把尾端当作可拔 converter，也不要为了追求储墨量强拧越过终点。吸墨后擦净握位和笔尖，确认尾端回位、帽盖沿轴线让磁体定位。Twist Magnetic Lock 不是螺纹硬锁，开合时避免横向掰动或让帽口刮过笔尖。

换墨只用常温清水缓慢吸排，直到排水基本清澈，再让笔尖朝下排水并充分阴干。aluminum、black PVD、磁体和镀层不适合酒精、丙酮、漂白剂、热水或研磨膏；外部用柔软微湿布擦过后立即擦干。若活塞空转、行程突然变重、尾端渗墨或磁吸明显变弱，应停止操作并联系熟悉 Pineider 机构的售后，不从尾端强拆。

## 购买核验：六项同时成立

购买新笔依次核对：**Millenium 单 n 商品名、PP4801／945、完整 SSP…PP4801G20 child SKU、14K hyperflex 与尖幅、aluminum／black PVD、Piston Filler／Twist Magnetic Lock**。限量品还应核对编号与盒证。官网的 current 尖幅有五种，Pen Savings 当前档案只展示其中部分可售选择；库存差异不表示另外两种尖幅不存在，也不应把价格写进永久资料。

二手页面若写 `Millennium` 双 n，可以通过 PP4801／945 和完整配置收敛；若写 `Arman`，则不能仅凭 PP4801G20 强行改名。要求卖家展示标签、盒证、笔尖刻字、尾端、整体结构和编号。看见开孔笔杆、Trilogy 或 Doppler 叙述时，应先按 Arman 冲突成员处理，而不是把这些特征当成 Millenium 的“隐藏版本”。
