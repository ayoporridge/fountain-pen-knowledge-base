## summary

Opus 88 是以台湾制造和日式滴入式止墨结构见长的钢笔品牌；Demonstrator、Koloro、Jazz、Omar 与 Premium Opera 使用不同的笔尖平台、外形和版本边界。

## body_md

Opus 88 的资料最容易被一句“台湾滴入式钢笔”带过，但这会把品牌背景和型号结构都说得过于粗。Jin Gi Industrial 的品牌资料与台湾渠道导航把 Opus 88 放在台湾制造语境中；不同经销商的年份叙述并不完全一致，因此本文不把某一个年份写成未经核实的唯一成立年。更稳妥的读法是：品牌以 OEM/ODM 制造经验为背景，后来形成自有 Opus 88 钢笔路线，长期把树脂加工、装饰帽和大容量日式滴入式结构放在产品中心。

Opus 88 的核心技术语言是 Japanese-style eyedropper。笔身内部就是墨仓，尾端 blind cap 推动 shut-off rod 或 ebonite piston；尾帽旋紧时，墨水通往 feed 的通道被关闭，写字时需回旋几圈让墨水进入笔舌。这和普通无阀 eyedropper 不一样，也不是 Pelikan 或 Leonardo 那种把墨水吸进独立活塞腔的 piston filler。止墨阀能减少携带时的漏墨、温差喷墨和 burping 风险，却不是“永不漏墨”的保险。螺纹、O-ring、阀杆和 section 仍要保持干净，笔杆出现裂纹或密封老化时，任何型号都可能渗墨。

型号导航必须从结构和笔尖尺寸开始。Demonstrator 是透明或半透明的大型展示路线，常见 JoWo #6；Koloro 是扁平端盖和双色树脂路线，常见 JoWo #5；Jazz 是更圆润、可倒插的日用外形，走大号 JoWo 路线；Omar 是大容量、较传统的滴入式造型。**Premium Opera 是独立的装饰路线**：Brown/Blue/Green/Grey Dot 属于颜色或帽面变体，使用 Bock Type 250（No. 250）钢尖。颜色、PVD 饰件、节日限量和树脂批次属于 variant，而不是应当单独建页的型号。旧库存里写作“Kolora”的条目应以 Koloro 为规范拼写，Kolora 只保留为 alias，不能继续让 Demo 和 Koloro 共用一张规格表或一张主图。

共同的维护门槛也要在品牌页说清。灌墨前拆下 section/nib unit，用附带玻璃滴管或钝头注射器把瓶装钢笔墨加入笔身；不要把墨水转换器、墨囊或尾部旋钮误写成全线通用配置。灌好后重新装回 section，打开止墨阀，让墨水缓慢进入 feed。携带、收纳或乘飞机前要关紧阀门，长途航空最好清空墨仓并套密封袋。换色时用清水或 bulb syringe 冲洗笔身与 feed，完全干燥后再装回；India ink、丙烯墨和颜料墨会给树脂、阀杆和 feed 带来不必要的堵塞风险。O-ring 需要薄涂硅脂时也应遵循说明书，不能用厚硅脂掩盖错牙、裂纹或磨损。

Opus 88 适合喜欢一次灌满、连续写几页、观察墨水流动，并愿意接受拆洗步骤的人。它不适合需要一支很短、可以随时换色、完全依赖墨囊的便携笔。品牌页的价值不在于重复型号页的数字，而在于建立可点击的判断路径：透明展示感对应 Demonstrator，双色扁平端盖对应 Koloro，圆头日用和可倒插对应 Jazz，大容量传统外形对应 Omar，装饰树脂与 Bock #250 对应 Premium Opera。后续 Fantasia、Bela、Flora、Flow、Mini Pocket、Harmony 与 Shell 等系列应继续独立补证，不能因为同样有止墨阀就把它们压进一个“Opus 88 滴入式”空壳页。

### 型号之间如何建立可读的分流

Opus 88 的型号比较应同时看外形、尖平台和墨仓操作。Demonstrator 的透明笔杆让墨量和气泡可见，适合把“止墨阀—墨仓—笔舌”三段关系讲清；Koloro 的双色树脂和扁平端盖更强调外观与手持；Jazz 的圆头和可倒插帽盖更接近日用；Omar 的尺寸和传统轮廓强调大容量；Premium Opera 则把 Dot 帽面、装饰树脂与 Bock Type 250 组合在一起。它们共享品牌技术方向，却不是同一款笔换颜色。

把这些型号放在一个品牌页时，颜色、帽面、树脂批次、PVD 五金和节日限定都应挂到具体型号或 variant。JoWo #5、JoWo #6 与 Bock 250 不能只写成“Opus 88 钢尖”；尖号、供墨口径和 section 直径会影响替换件。零售商写的“large nib”或“premium”是销售语言，只有产品页、随笔说明或实物刻字能支持准确平台。

### 止墨阀的使用路径

第一次灌墨时先确认尾帽、O-ring 和 section 没有裂纹，再用滴管慢慢加入瓶装墨水，避免把墨水灌到螺纹外。装回 section 后只打开少量阀门，让 feed 逐渐润湿；如果一开阀就大幅出墨，先收回阀门并检查温度、气泡和密封，不要用摇晃或挤压强行“排气”。收纳和携带时关闭阀门，航空旅行前清空墨仓，因为空气膨胀仍可能把墨水推向笔尖。

清洗不只是把笔尖放在水下。拆下 section 后分别冲洗墨仓、止墨杆周围和 feed，直到水基本清澈，再让各部件充分干燥。O-ring 只在需要时使用适量兼容硅脂；错牙、断裂、磨损和阀杆弯曲不能靠增加润滑解决。出现墨仓渗漏、尾帽空转、阀门不能闭合或笔舌持续干涸时，应保留墨水和拆洗记录，交由熟悉 Opus 88 结构的维修者判断。

### 购买时要保存哪些证据

二手 Opus 88 应同时拍摄笔帽、尾端、section、笔尖正面、笔身透明度和包装标签。透明树脂会受灯光与墨水残留影响，不能用一张偏色照片确认 Clear、Blue 或 Dot 名称；“Kolora”也可能只是旧拼写或卖家标签。要确认 Premium Opera，至少需要装饰帽面、Bock 尖平台和对应页面三项线索；只看到大笔身或金属环，不足以完成身份判断。

这条记录方法让品牌页可以继续吸收 Fantasia、Bela、Flora、Flow、Mini Pocket、Harmony、Shell 等新路线，而不必重复定义日式滴入式。新增型号时，先建立独立来源和主图，再连接到 Opus 88，并明确它的尖平台、尾端结构和版本范围。
