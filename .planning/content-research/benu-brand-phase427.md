# BENU

## summary

BENU 是在亚美尼亚 Yerevan 设计和制作树脂钢笔的独立品牌，以高饱和颜色、闪粉和切面树脂建立辨识度。品牌页把 Briolette、Talisman、Euphoria、AstroGem、Minima 与 Ambrosia 分开导航，颜色和联名不冒充新型号。

## 先分清品牌、系列和颜色

BENU 的视觉吸引力来自高饱和树脂、金属粉、闪粉和切面或多面体轮廓，但“看起来很像”不等于“结构相同”。Briolette 是较小的切面笔；Talisman 通常有更有存在感的笔身并可以 post；Euphoria、AstroGem、Minima 和 Ambrosia 又有自己的长度、粗细、帽盖和树脂路线。Ruby Forest、Island Breeze、Luminous Blue、Amethyst Tide 与 True Unicorn 这些名字通常描述配方、颜色或联名，应放到具体系列的 variant，而不是复制成一串只有颜色不同的基础型号。

BENU 官方尺寸对比图适合用作第一层身份依据。它把不同 collection 的轮廓并列，让读者先看到长度、直径和盖型差异，再进入商品页核对尖号、供墨和随附配件。手工浇注树脂每支的纹理、金属粉聚集位置和反光都会不同，商品照片只能代表一个样本，不应当成整批颜色的精确色票。品牌页使用原创 factual SVG 作为路线图，并明确它不是实物照片。

## 亚美尼亚制造与材料叙事

BENU 官方 About 资料把设计和手工制作地点放在 Yerevan。这里的“手工”应理解为树脂配方、浇注、打磨、抛光、装配和逐支检查的品牌制造叙事，不应推导每一根金属尖都是 BENU 自行锻造。Briolette 等公开规格普遍使用德国 Schmidt 钢尖；因此品牌页不写成 BENU 自制金尖，也不把某个颜色的镀色尖、银色饰件或独家树脂扩大到全品牌。

BENU 把收藏属性和日常书写放在同一条产品线上。亮色树脂适合展示、礼赠和社群交换，国际规格墨囊／转换器又让许多型号不需要特殊耗材；但这不等于所有 BENU 都是大容量活塞或真空笔。品牌页应诚实说明它的优势是材料、视觉和容易辨认的系列轮廓，型号页再决定是否能 post、使用何种尖和如何补墨。

## 当前型号入口

BENU Briolette 连接切面树脂、小尺寸、#5 Schmidt 尖和标准国际墨囊／转换器；Ruby Forest、Luminous Blue、Island Breeze 等只作为颜色 sibling。BENU Talisman True Unicorn 则连接 Gourmet Pens Exclusive 的限量联名树脂，不能缩写成“BENU Unicorn”后与普通 Talisman 合并。联名方对植物粉末、魔法保护等叙事只能作为营销语境，不当作材料功效；Sold out、库存和地区售价要带检索日期。

未来补充 Euphoria、AstroGem、Minima 或 Ambrosia 时，先核对官方尺寸图、具体商品页、尖号和供墨，判断是同一系列新色还是确有不同结构。每个公开型号必须能回到 BENU；每个颜色 sibling 必须回到主型号；联名方图片保留来源与许可身份。品牌反向链接不是把所有颜色都列成型号，而是把每个可核实入口连接起来。

## 选购和维护的共通底线

多数 BENU 树脂笔可以使用标准国际墨囊或 converter，但随机附送内容会随年代和零售商包装变化。清洗时用室温清水吸排、擦干笔尖外侧，等内部自然干燥后换墨；不要用酒精、热水、研磨剂或抛光剂处理树脂和镀层。树脂笔不代表可以无条件 eyedropper 改装，必须先确认螺纹、密封和该商品的说明。飞机、高温车厢和笔尖朝下收纳会增加压力变化漏墨风险。

尖号页面应把 F、M、B 当作字宽选择，而不是把钢尖宣传成 flex。中文小字或普通复印纸通常先比较 F／M；B 和 Flex 配置更适合展示线条，出厂调校仍可能有个体差异。选择时优先看握段直径、能否 post、长度和供墨习惯，再看树脂颜色。个人评测中的湿度、阻尼和握感属于单支体验，要和官方规格分开。

如果读者在 Briolette 与 Talisman 之间犹豫，可以先比较尺寸和握位，而不是先看闪粉多少。Briolette 的小尺寸和 #5 尖更适合短时间、随身和细字；Talisman 的体量、可 post 方式和 #6 尖更适合喜欢有存在感的握持。这个判断只说明产品任务，不承诺每个颜色或每支树脂的相同重量。购买时仍需回到具体商品页确认长度、直径、尖幅和包装。

手工树脂的纹理也有自己的记录方式。商品图片应说明拍摄条件、是否为一支实物、颜色名称和来源；不能把摄影曝光、闪粉反光或发光效果写成稳定的色卡。颜色 sibling 共享主型号的结构事实，但不共享每支的纹理、重量和库存。若联名方提供独家配方，应保留联名方、产品号、授权与 Sold out 状态，避免把营销故事扩大成材料或健康功效。

联名和零售商独家色也需要自己的证据范围。页面记录联名方、检索日期、Sold out 或地区库存，不把营销词翻译成材料功效；一张 Ruby Forest 或 True Unicorn 的照片不能代表 Briolette、Talisman、Euphoria 全部产品。型号页保留自己的 primary asset，品牌页只做导航，不复制同一图片填补其它页面。

常见国际墨囊与 converter 的适配性也要按型号核对。不同零售商可能把备用墨囊、转换器或 eyedropper 改装建议放在套装说明里；这些内容不能替代 BENU 官方螺纹与密封信息。长途运输或飞机旅行时，减少满墨状态、保持笔尖朝上并遵守商品说明，比事后用溶剂清理树脂更安全。出现漏墨时记录温度、方向、墨水和装配状态，便于售后判断。

品牌页的系列列表不追求把每个色名都公开成一个节点。更可靠的做法是让读者从 Briolette、Talisman、Euphoria 等主型号进入颜色和联名 variant，再回到来源和图片。这样既保留 BENU 的材料乐趣，也能让图谱的实体数、链接数和图片数反映真实产品结构，而不是反映一次零售上架。

当官方尺寸图、商品页和实物照片彼此一致时，颜色故事才有资格进入公开页面；其余名称先保留为研究别名。

这也是把收藏趣味和事实边界同时保留下来的办法。

本站 BENU 品牌图只表现 Yerevan 制造语境、Briolette、Talisman、Euphoria 与其它 collection 的路线，**示意图，非产品照片**；不表现真实比例、颜色、Logo、闪粉分布或具体 SKU。新增系列前先查 canonical identity、别名和品牌归属，颜色使用 variant，尖号或供墨改变才建立 sibling。这样品牌页可以持续扩展，而不会随着颜色数量膨胀成互相重复的空壳。
