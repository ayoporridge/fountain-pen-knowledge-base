# LAMY dialog cc

## summary

LAMY dialog cc 是 Franco Clivio 设计、2021 年推出的无笔夹旋转伸缩尖钢笔；当前蓝色 SKU 为 14K 金尖、T10／Z27、125 mm、44 g，缩短笔身、止滚件和配色使它成为 dialog 的独立 sibling。

# LAMY dialog cc：缩短、去夹之后，成为另一支伸缩尖钢笔

LAMY dialog cc 与现有 [LAMY dialog](/pen/lamy-dialog) 共用“旋转出尖、关闭时由球阀保护笔尖”的技术思路，却不是 dialog 的颜色或简称。LAMY 官方直接称它为 dialog 的 shorter and more compact sibling：笔身更短，取消了会随机构升降的笔夹，改用侧面的 Logo 止滚件。尺寸、重量、饰面、尖幅和使用动作都有自己的资料，因此本站建立独立 `/pen/lamy-dialog-cc`，不把它重定向到 `/pen/lamy-dialog`，也不把 dialog 的 140 mm、48 g 抄过来。

“cc”页面的核心是一支无帽钢笔。旋转笔身后，14K 金尖从前端伸出；反向旋回，笔尖缩入，球阀挡在开口前，降低干燥和碰伤风险。没有可丢失的帽，也没有可以夹进口袋的笔夹。侧面的止滚件既帮助辨认方向，也防止圆柱笔身在桌面滚动。它带来的便利和限制是同一件事：拿起即可旋转书写，但携带方式要靠笔套或包内固定位置解决。

## 2021 年的独立发布

LAMY 2021 年 7 月官方新闻稿以 “The new LAMY dialog cc” 发布该型号，并写明 **2021 年 9 月起供应**。首发资料列出哑光深蓝和高光白两种版本，端部与侧面止滚件采用玫瑰金色细节；14K 金尖带铂与玫瑰金处理。新闻稿多次把它与原 dialog 比较，强调显著缩短、无夹和便携格式，这正是独立身份的原始证据。

当前美国官网仍列 blue、white 两种 standard 配色。英国地区页另列 all-black，并把它标为 Special Edition：深黑哑光漆面、黑色 PVD 细节和黑色 PVD 处理金尖。all-black 改变的是颜色、镀层与具体 SKU，不改变 dialog cc 的机构和型号身份；也不能把 all-black 的尖面处理或商品号写成蓝、白版本的共同字段。

设计者是 **Franco Clivio**。官方商品页同时列出他与 LAMY pico、dialog 3 的关系。这里可以说明设计谱系，却不能把 dialog 3 的升降笔夹视为 cc 的缺失零件；cc 从一开始就用止滚件取代笔夹。二手商品若带有传统笔夹，应先怀疑卖家把 dialog／dialog 3 与 dialog cc 混名。

## 当前蓝色 SKU 的规格边界

2026 年 8 月 11 日复核的美国官方蓝色页面，尖幅选项为 EF、F、M、B。配置文字写：旋转机构、哑光深蓝漆面、玫瑰金色细节、部分镀铂的玫瑰金双色 **14 ct 金尖**，随附 T10 蓝色墨囊与 Z27 上墨器，并配皮套礼盒。数据区给出 **13 × 13 × 125 mm、44 g、商品号 1234402**。

这组数据只绑定当前所选蓝色 SKU。白色页面可有另一个商品号，all-black 又有自己的地区编号；库存和价格也会变化。把它写成“dialog cc 当前官方蓝色配置为 125 mm、44 g”比“所有 dialog cc 永远完全相同”更准确。Stephen Brown 2022 年借测的 Broad 样笔测得约 123.7 mm、45.0 g，恰好说明实测口径与官方商品数据不必强行合并。

金尖是当前 dialog cc 的核心配置，但尖幅仍需按市场选择器确认。EF、F、M、B 的线条和供墨不应由一个 Broad 样本代表。官方笔尖资料说明 14K 金尖相对钢尖更具弹性和耐腐蚀性，不等于柔性书法尖；不要靠加压追求大幅线差。新笔若某一方向刮纸、持续断墨或起笔困难，应先清洗和更换常规纸墨，再检查尖齿与售后，而不是自行弯尖。

## 旋转、球阀和止滚件怎么用

使用时握住规定部位，平稳旋转到笔尖完全伸出的机械终点即可。关闭时反向旋回，确认笔尖完全收入且前端球阀闭合。不要越过终点继续拧；如果阻力突然增大、笔尖只伸出一部分、球阀关不严或上下段开始意外松脱，应停止操作，排空墨水后交由 LAMY 服务检查。

cc 没有 dialog 那套随出尖下降的笔夹，动作更纯粹，却也失去口袋夹持。止滚件能阻止桌面滚动，并可作为手指方向参照；它的位置是否碰手取决于握法。44 g、约 13 mm 的圆柱体仍属于偏重、偏粗的钢笔，不能因“compact”就理解为轻笔或细笔。购买前应至少连续写一页，确认止滚件、接缝、直径与重量都可接受。

Stephen Brown 的 2022 年评测披露样笔由 Appelboom 借出，记录一支 Broad 样本的尺寸和重量。它能帮助读者想象实物体量，却不能证明所有笔尖同样湿润，也不能替代长期耐用性数据。高价机械钢笔最重要的不是一段开箱顺滑，而是机构闭合、售后渠道和自己是否真的需要无帽旋转动作。

## T10、Z27 与清洁边界

当前蓝色官方配置随附 T10 墨囊和 Z27 上墨器。换墨只拆官方允许的供墨部分，不拆旋转传动、球阀、止滚件或外壳。使用 Z27 时平稳吸墨，擦净握位外露区域再装回；使用墨囊时直压到位。若内部出现异常墨迹，先停用并确认墨囊口／上墨器密封，不把泄漏归咎于球阀，也不向机构内灌清洁液。

换色或久置后，用室温清水缓慢冲洗笔尖、导墨器和上墨器，直至排水基本清澈，随后自然阴干。LAMY 官方护理页为 dialog 提供专门清洁入口，并把 converter filling 与 cleaning 分开。不要将整支 dialog cc 长时间浸水，不用酒精、洗洁精、漂白剂、热水、超声波或家用润滑油。前端若有可见干墨，只用微湿无绒布轻触外露表面，不把针、纸片或棉签塞进球阀。

长期停用前应清空墨水、完成清洗并确认机构干燥。日常收纳时让笔尖完全缩回，放入随附皮套或独立笔位，避免无夹圆柱体与钥匙碰撞。球阀用于降低干燥风险，不是绝对防漏承诺；飞行或剧烈气压变化时仍应收尖、妥善放置，并避免满墨后在包内承受挤压。

## 新笔与二手购买

新笔先核对五项：完整名称必须是 dialog cc；颜色与商品号对应；14K 尖幅正确；盒内是否包含 Z27 和皮套；当地授权渠道能否提供机构售后。只写“LAMY dialog”或“Dialog 3”的商品链接不能证明卖的是 cc。蓝、白与 all-black 的金属细节不同，照片、标题和配置段必须互相吻合。

二手检查应录一段完整开合视频：笔尖能否平稳伸出和完全缩回；球阀能否闭合；笔身是否在终点继续空转或松脱；止滚件是否牢固；14K 尖是否偏斜；接缝和漆面是否有拆修、磕伤或墨水侵入。无笔夹是 cc 的正常设计，不是缺件。卖家宣称“永不干”“免维护”或“与 Pilot Capless 尖单元通用”，都应视为无官方依据。

想要伸缩尖但重视口袋夹和较长笔身，可比较现有 dialog；想要按压而非旋转、可拆尖单元，应看 Pilot Capless 家族；只想要 LAMY 14K 尖而不需要复杂机构，也可比较 Studio、scala 等具体金尖配置。dialog cc 的价值在无夹紧凑外形与机械体验，若这两点不是需求，高价与维护复杂度就不会自动转化为更好的书写。
