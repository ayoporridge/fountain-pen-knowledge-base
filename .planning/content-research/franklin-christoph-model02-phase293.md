# Franklin-Christoph Model 02 Intrinsic：中段收腰与深插帽的独立笔形

## summary

Model 02 Intrinsic 是 Franklin-Christoph 2011 年推出的旗舰笔形，以中段收腰让笔帽深插固定；硬质 acrylic、#6 笔尖、国际墨囊／转换器与约 3.8 ml 滴入容量构成其可核实边界。

## 先确认它是哪一支 Model 02

Franklin-Christoph 的型号页常常和颜色、树脂批次、笔尖研磨一起出现。Model 02 Intrinsic 需要先按“笔形”识别，再把具体颜色或尖型当作版本信息。它不是 Model 20 Marietta 的长版，也不是 pocket 20 的短版，更不是 Model 31 Omnis 的另一个名字。三者都可能使用 #6 笔尖，不能因此共享尺寸、图片或供墨说明。本页对应官方产品页所称的 “Model 02 Intrinsic Fountain Pen”，示例产品是 Solid Black；官方当前页面显示该 SKU sold out，所以这里写“仍在官方目录中的型号／当前示例缺货”，不把某一次缺货当成整条产品线停产。

Model 02 最容易被忽略的识别点在笔身中央。上段、下段之间有明显的中心收腰，帽盖可以越过这段收腰深深套入；套帽后笔的重心和握位关系与普通圆柱笔不同。官方产品页把深插帽和 taper 作为设计说明，而不是单纯的外观形容。购买二手笔时，应该同时拍摄合帽、无帽和套帽三种状态，确认帽口确实越过中段收腰，并核对笔尖单元是否是 #6 路线。只有看到“Model 02”字样或能与官方结构匹配，才把它放到本页；一支只标有树脂名、没有笔形证据的 Franklin-Christoph 不能凭颜色接入。

## 历史位置：2011 年的旗舰，但不是品牌创立年份

Franklin-Christoph 官方 History 将早期 Franklin Co. 的陶瓷业务、2001 年 Franklin-Christoph／IPO Fountain Pen 的品牌转型，以及之后的制造设施变迁分开叙述。该页明确把 Model 02 Intrinsic 作为 2011 年推出的新旗舰。这个年份只用于 Model 02 的型号时间线，不能倒推品牌成立于 2011 年，也不能把 2011 年移植给 Model 20、pocket 20 或 Model 31。当前官网仍保留 Model 02 的独立产品页，Solid Black 页面显示 sold out；这说明型号身份仍可核对，但库存和树脂批次需要按日期记录。

“Solid Black”也不等于“所有 02 都是纯黑”。官方说明纯黑版本属于较少见的生产，而通常的黑色 02 可能带 maroon finial；其他硬质 acrylic 颜色和限量树脂会随批次变化。颜色、端饰和树脂纹理是版本线索，不是新的机械笔形。正文因此采用“固态黑色示例”和“常见黑色／其他材料批次”的分层写法，并不把一张黑色实物图拿来代表所有 02。资料缺少准确批次时，页面宁可使用本站原创事实示意图，也不借用 Model 20 或 Model 31 的产品照片。

## 官方规格与结构

官方 Model 02 页面给出的尺寸口径为：合帽约 5.750 英寸（约 146.05 mm），套帽约 5.850 英寸（约 148.59 mm），含笔尖的笔身约 5.150 英寸（约 130.81 mm）。帽径约 0.610 英寸（15.49 mm），上段笔杆约 0.550 英寸（13.97 mm），下段约 0.445 英寸（11.30 mm），握位最细处约 0.44 英寸（11.18 mm）。无墨重量约 0.73 oz（20.71 g）。这些数值是官方当前示例页的规格锚点；不同树脂、笔尖、配件和测量方法可能带来小幅差异，不应把卖家自测值当作所有年份的工厂公差。

材质方面，官方写作 durable hard acrylic。这里的 acrylic 是硬质树脂语境，不应简化成“金属笔”或把所有黑色都描述成同一种树脂配方。Model 02 的中心收腰为深插帽服务，帽可以稳固越过中段；它既可以合帽书写，也可以套帽书写，官方强调两种状态都能保持平衡。深插帽并不意味着可以把帽用力拧过阻力点：合帽、开帽应保持轴向平稳，发现裂纹、异常松动或刮擦时停止强行旋转，先按品牌保修或专业维修路线处理。

## 笔尖、上墨与容量

Model 02 使用 #6 笔尖单元。Franklin-Christoph 的官方笔尖资料按 #5、#6 等单元分组，并提供 factory 或 custom tip 选项；实际尖材、尖宽、研磨和库存随订单或批次变化。正文可以说“可选多种 factory/custom tip”，不能保证每个年代、每种树脂都同时有 EF、stub 或 italic。更换笔尖时应以对应单元、螺纹和密封状态为准，不能因为“都是 #6”就把任意历史部件无条件混装。

供墨有两条常用路径。第一条是短国际规格墨囊或转换器，官方产品页随笔提供一枚短国际墨囊和一枚 converter，具体随盒部件仍应以当前 SKU 为准。第二条是 eyedropper：官方示例页给出约 3.8 ml 的滴入容量。滴入容量是结构参考，不是对每种墨水、每支二手笔或任何密封状态的长期保证。第一次使用建议先用墨囊或转换器确认笔尖、笔舌和帽口状态，再在完全清洁、干燥、确认密封后尝试滴入；如果出现渗漏、气泡导致断墨、墨水沾到金属配件或帽内积墨，应排空并清水冲洗，不要用强溶剂或尖锐物扩大密封面。

## 版本、选购和维护

当前可核对的版本至少包括：官方页面的 Solid Black 稀少生产示例；通常黑色 02 可能带 maroon finial；以及其他硬质 acrylic 颜色或小批次。版本记录应保留颜色、端饰、商品页标题、笔尖和检索日期，而不要把 “Black”“Antique”“Jade” 直接做成与 Model 02 并列的实体。若卖家只写“Franklin-Christoph #6 大笔”，应要求补充中段收腰、帽深插状态、笔身长度与端饰照片，避免把 Model 20、Model 31 或旧材料版本混名。

选择时，喜欢大握位、套帽后仍希望平衡，并愿意在短国际墨囊、converter 与 eyedropper 之间取舍的人，可以把 Model 02 放在长握位 #6 钢笔候选中。若更看重全尺寸 slip-cap、无外露螺纹的日常开合，应比较 Model 20 Marietta；若需要更短的收纳尺寸，应看 pocket 20；若目标是 Omnis 的另一种结构，则跳转 Model 31，而不是套用 02 的尺寸。购买二手笔还应确认 #6 单元是否原装、converter 是否在、滴入密封是否完整，以及树脂是否有干裂。官方页面有 lifetime warranty 说明，但保修适用范围、跨境运送和人为损伤仍需向品牌确认。

日常维护以温和为主。换色时用室温清水吸排笔舌和握位，直到水基本清澈，再拆下转换器晾干；不使用时排空墨水并合帽，避免长时间把墨水留在滴入笔身内。硬质 acrylic 也不是不会损伤的材料，避免高温、酒精、丙酮和硬质研磨布。笔帽应沿轴线轻推、轻拉，套帽书写时确认没有偏斜；笔尖出现刮纸、断墨或偏缝，先停止用力调整，记录墨水、纸张和尖型后交由品牌或专业修理者判断。

## 与同品牌型号的导航边界

本页的“Model 02”只指 2011 年旗舰笔形及其可核实的材料／尖型版本。Model 20 Marietta 是独立的全尺寸 slip-cap；pocket 20 是更短且供墨配置不同的独立笔形；Model 31 Omnis 也有自己的产品线。它们不共享本页的中心收腰尺寸、Solid Black 图片、3.8 ml 容量或深插帽描述。品牌页可以把这些型号作为并列导航，但每个型号都应回到自己的官方页面、来源、图片和规格。这样做牺牲了把“Franklin-Christoph 大笔”写成一段泛介绍的速度，却能让读者从品牌页跳到一个具体、可复核的笔形。
