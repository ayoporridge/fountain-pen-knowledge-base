World Tree – Sandalwood 是 Wancher Sekai collection 中以天然檀木为识别核心的具体钢笔。官方商品页单独列出 `World Tree - Sandalwood`，当前页面同时显示价格快照和 `Sold out` 状态。本页记录的是这一具体商品，不把 World Tree Ebony、Teak、Verawood、Sekai Ai 或 Dream Pen 的材料、颜色和配置拼接进来。

### 檀木与天然色差

官方提醒天然木材的实物颜色可能与商品图片略有不同。对檀木而言，木纹、色调、局部光泽和气味都可能随木料、抛光、光线和保存条件变化；页面没有把这些差异定义成统一数值，也没有给每支笔提供单独净重或稳定的颜色代码。商品图可以帮助理解大致形状，不能作为收到实物的颜色校样，更不能以图片中某支笔的纹理判断另一支的等级。

天然木笔不适合被当作完全均质的塑料外壳。收纳时与钥匙、裸露金属和会掉色的皮件分开，避免车内高温、暖气、长期潮湿和突然温差。清洁使用柔软布和少量清水，避免酒精、强清洁剂、研磨膏和长时间浸泡。若木面出现裂线、异常发白、起皮或接缝松动，应先停止抛光和强拆，保存照片、订单和购买渠道信息后联系 Wancher 或经销商。

檀木的气味和颜色不能单独证明来源或真伪，也不能被当作质量等级。收到笔后先检查帽口、螺纹、握位和笔尖是否在运输中受损，再决定是否装墨；保存开箱照片有助于售后区分自然色差、运输损伤和使用后的变化。长期闲置时清空墨水，放在通风、避光的位置，定期检查帽盖螺纹和木面变化。

### 银夹与页面状态

官方当前选项包括 Without Clip、With 925 Matte Silver Clip 和 With 925 Silver Clip，页面显示该商品当前售罄。925 银夹在 Wancher 日本工作室制作，哑面版本与大分温泉蒸汽相关的处理工艺有关；夹子可拆下或装回。无夹版更简洁、少一个硬附件，但携带时少了固定点；有夹版方便夹在笔记本或口袋上，却不能因此当作防跌落保险。售罄是页面当前商业状态，不代表该型号历史上从未销售，也不保证未来补货。

页面图库中还出现 `World Tree with Keiryu Dragon Nib (Anniversary Edition)` 的图片。它应被视为周年或特殊配置的边界提示，而不是把龙尖自动写入基础 Sandalwood SKU；基础页面 Writing 部分明确列出的尖材才是本页默认证据。若未来商品页重新开放特殊尖选项，应按新的具体页面和订单记录更新，而不是回填当前历史快照。

### 供墨、尖材与包装

官方 Writing 部分写明 European International Standard cartridge 或 converter，基础页面列 #6 JoWo stainless steel 与 Wancher 18K gold，feed 则有 plastic、black ebonite、red ebonite。与 World Tree Ebony、Teak 和 Verawood 页不同，当前 Sandalwood 基础页面没有在文字规格中列 KEIRYU/Kodachi，因此不能仅凭同系列页面把该尖材写入基础商品。尖幅、feed、夹件和售罄状态都应按当前 SKU 核对。

包装包含传统日式木盒、墨胆、转换器和说明材料。木盒是包装与保护物，不证明檀木来源、笔身制造地或木材等级。首次装墨时将标准国际墨胆或转换器平直推入握位，确认连接牢固后再让笔尖朝下等待出墨。换色或久置前清空旧墨，用清水冲洗转换器和尖部，待自然干燥后再装回；木制部件不要用工具撬动。
