# Magna Carta：现代弹性尖与手工树脂路线

## 品牌边界

Magna Carta 的官方商店把自己描述为提供 craftsmanship、spiritual symbolism 和 writing instruments 的品牌，并在导航中分列 Mag 600、Mag 600 S、Mag 1000、Trilli 与 Lord Desk Set。当前可可靠核实的是产品目录与各商品配置；公开页面不足以承担一份完整公司年表，因此品牌页不补成立年份、工厂规模、每个部件的产地或未经证实的“全球第一”之类宣传。

Mag 600 是品牌中最适合作为入门导航的代表型号之一，但它不等于整个 Magna Carta。Mag 600 S 有独立的 S 命名和 stainless-steel flex 叙述，Mag 1000 使用不同尺寸与笔尖路线，Trilli 也有自己的造型和价位。颜色、树脂花纹、PVD 饰件和 nib width 应放在具体型号的 variants，不应把每一张商品图片创建成新品牌或新型号。

## 产品路线与证据

官方 Blue Opal 商品页明确列出 artisan resin、24K PVD gold plated trim、#6 14K True Flex nib、ebonite feed 和 cartridge/converter；这组事实足以建立 Mag 600 的主体页面。它不能证明所有 Mag 600 都是 Blue Opal、都配 14K True Flex，或所有颜色都使用同样饰件。品牌导航显示 Mag 600 与 Mag 600 S 分开，页面还列出 Mag 1000 的多种颜色，因此品牌页应让读者先按型号进入，再按颜色和尖选项比较。

专业评测对 Mag 600 的测量和 flex 体验适合作为 secondary evidence。送测样本的有帽长度、重量、section 感受和线条变化必须标成样本数据，不要覆盖官方商品页给出的 SKU 尺寸，也不能拿一个人的 railroading、硬软或对质量的评价概括全部生产批次。

## 维护与购买建议

Magna Carta 的弹性笔尖需要把尖、feed、墨水和纸张作为一个系统来调试。品牌页应建议先确认 converter、feed 和 nib 选择，再决定是否尝试 True Flex；用户不应仅凭“14K”期待自动得到 vintage flex 的反馈。清洁时使用室温清水，弹性尖不要干压，ebonite feed 和 PVD trim 避免热水、酒精与强溶剂。第三方 nib unit 的兼容性必须逐 SKU 询问，不能由“#6”这一尺寸标签推断。

价格、库存和颜色会随官方商店更新。Blue Opal 页面在检索时显示 sold out，这只说明该商品当时的供应状态；品牌页不把动态库存写成停产。购买页面要保留商品 SKU、尖材质、颜色、converter 是否随附和退换政策，让读者能区分基础型号、季节色、零售商 exclusive 与 Mag 600 S。

品牌导航还应帮助读者区分“同一型号的外观选择”和“真正不同的产品”。例如 Blue Opal 与 Sky Blush 可以作为 Mag 600 的颜色路线，而 Mag 600 S 的官方命名和 stainless flex 叙述则需要单独的型号入口。这样的层级既能保留手工树脂的视觉差异，也不会让每一批材料纹理都产生重复实体。
