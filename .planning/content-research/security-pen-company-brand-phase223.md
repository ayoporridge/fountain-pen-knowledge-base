## summary

Security Pen Corporation 源自 Kritikson 兄弟 1919 年创办的 Securograph 路线，后以 Security 品牌销售带支票保护器的钢笔。Richard’s Pens 与美国专利支持其芝加哥、芒特卡梅尔迁移和 1920 年代产品线；破产与重组不能简化成单一法人。

## body_md

### 从支票保护器到钢笔

Security Pen 的品牌身份必须从它解决的问题写起。20 世纪初支票大量流通，涂改和伪造让便携式支票保护器有实际市场。Richard’s Pens 记载，John H. Kritikson 与兄弟 George 于 1919 年在印第安纳州 Terre Haute 创立 Securograph Pen Company，随后迁到芝加哥并以 Kritikson Bros. Inc. 经营。他们取得 Stanley E. Peters 的支票保护器专利，将带滚轮、红色印台和保护帽的机构装进钢笔尾部。

品牌不能简单写成“美国第一支防伪钢笔”，也不能把 Securograph、Kritikson Bros.、Security Pen Corporation 和 1930 年代重组后的企业当成一张没有断点的公司登记。1923 年前后公司在芝加哥扩张并使用 Security 名称；1928 年又迁往伊利诺伊州 Mount Carmel；1929 年破产后，另一组投资者以早期 Securograph 名称重组，继续生产到 1930 年代初。页面把这些阶段分开，并把专利、广告和存世笔作为不同层次的证据。

### 机械结构与产品线

Security 钢笔把书写尖、支票保护器和上墨机构放在一支便携工具里。Peters 的 US1480690 描述了支票保护器的滚轮和切割／着色逻辑；Kritikson 的 US1339359 描述弹簧夹；US1482568 则涉及尾部旋钮驱动的机械上墨器。逆时针旋转尾钮会使杠杆压缩墨囊，反向操作帮助墨囊回弹吸墨，这不是普通的“旋钮活塞”或后来真空笔的同义词。

1923 年广告显示 200、300、400、500、600 等编号和短款、长款、女款 300A；同年后期阵容又出现 300、400、600 和 800 Giant。编号、价格和尖幅选项会随广告阶段变化，不能把它们当作现代固定 SKU。Fine、Medium、Coarse、Stub、Steno、Posting 以及软硬版本是当时可选笔尖语境，具体存世笔仍须看尖刻字和状态。

### 公司边界与保存

Security Pen、Securograph 和带有相似支票保护器的后配钢笔要分开。支票保护器帽可能缺失、卡死或被替换；一支没有保护器的 Security 仍可能保留 Kritikson 的旋转上墨机构，但不能因尾部有旋钮就自动归入本品牌。广告中的价格是历史销售语境，不是今天的估值或所有型号的统一售价。

保存老 Security 笔时尤其要注意腐蚀和干涸的红色印台墨水。保护器内部、旋钮连杆、墨囊和笔杆接缝可能互相牵制；强行旋转尾钮可能折断连杆或使硬橡胶开裂。品牌页只把 1929 年破产、Mount Carmel 迁移和 1930 年代重组作为时间节点，不推断后期每一支的生产地点、装配人员或零件来源。

### 选购建议

交易前要求笔帽、尾部保护器帽、滚轮、旋钮、夹子、笔尖刻字和笔杆材料的近照，确认是否能安全打开、是否换过墨囊、保护器是否仍有红色残留。不要把“带支票保护器”当作可立即使用的保证；现代书写者应先评估修复成本与不可逆风险。若只是研究支票防伪史，保存原状的故障样本也可能比抛光翻新更有价值。
