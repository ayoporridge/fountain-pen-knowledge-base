Vector XL 的 “XL” 是产品身份的一部分，而不是把历史 Vector 的尺寸随手放大后的宣传别名。Parker 当前官网把 Vector XL 单列为 collection，2159744 页面写明 Fountain Pen、Black Chrome Trim、Stainless Steel CT、Stainless Steel nib 和 Stainless Steel cap。页面还特别描述 satin metallic black finish、signature Parker arrow clip、large stainless-steel nib，以及可看到内部结构的 unique transparent shell。本站把这些字段绑定到当前 XL SKU，不回填给 1984 年起的经典 slim Vector。

### 2159744 的 exact SKU 事实

官方 Item # 是 2159744，Finish 为 Black Chrome Trim，Ink Color 为 Blue，Trims Metal 为 Stainless Steel CT，Nib Material 与 Cap Material 都写作 Stainless Steel。产品描述使用 satin metallic black，说明外观的金属感；不能据此断言整支笔是金属车削，也不能把当前页面的透明 shell 文字扩成每一支颜色和每一个批次都完全透明。不同颜色（Teal、Silver、Lilac、灰金等）各自可能有不同 finish、尖幅和包装，应以对应商品号为准。

当前页面选择器显示 Medium。Parker 的产品和目录资料还存在 F/M 的不同市场 SKU；正文可以说“XL 家族按 SKU 提供 F 或 M，2159744 当前页面显示 Medium”，不把 Teal 2159746、其他交通盒版本或 F 号的线宽转到黑色 2159744。Parker Nib Exchange 页面中的 Urban、Ingenuity 等尖号表也不是 Vector XL 的自动兼容清单；更换尖前应通过零售商确认同值和对应部件。

### 与经典 Vector 分叉

经典 Vector 的历史资料从 1984 年 RB-1／FP-1 路线开始，常见是较细的塑料笔身、不同年代和市场的帽盖／刻字、钢尖与 Parker 墨囊系统。Vector XL 是后来的独立产品线，官网用 larger diameter、large stainless-steel nib 等定位词；即使营销文案说它受 original Vector design 启发，也不能把两个实体合并。XL 页不能使用老 Vector Flighter、透明老壳、英国刻字或无年份电商照片作为主图；历史 Vector 页也不能借用 XL 的透明 shell 和 2159744 商品号。

照片识别先看笔帽比例、尖的大小、帽顶与 arrow clip，再查 Item #。黑色外观、Parker 箭夹和“Vector”字样都不足以独立确认 XL。卖家若只展示合帽正面，要求补充笔尖、笔尾、帽环、包装和尺寸照片；无法确认时保留“Vector 系列待定”，不要强行把历史款迁移到 XL。

### 墨囊、converter 与清洗

Parker 当前支持页对 fountain pen 的通用流程同样适用于 Vector XL：墨囊压入握位；converter 需让尖端浸入瓶墨、回滴三滴再回吸少量空气，最后用柔布擦干。当前 2159744 页面列出随 Parker gift box 的礼品定位和蓝色墨水关联，但没有承诺每个地区盒内都带 converter。因此购买前应核对包装清单；如果需要瓶墨，先确认 converter 的接口和是否单独购买，不要把旧 Vector 的转换器经验当作无条件兼容。

Parker 建议每次换墨清洗；若堵塞，将尖和握位浸在凉水中一夜，缓慢冲洗并排尽余水。不要用热水、肥皂、酒精或细针清理透明 shell 内部，也不要为了让大号尖“更湿”而用力压纸。透明结构是识别和视觉设计，不是允许拆解的观察窗。长时间不用时尖向上收纳，让墨水回到墨囊／converter；漏墨或出墨不均仍存在时联系维修。

### 书写定位和版本选择

Vector XL 官方将它定位为适合学生和年轻职场人士的现代、高质量日用笔；这是一种产品定位，不是对所有人的书写效果保证。大号不锈钢尖、较粗的笔身和黑色金属感外观，适合想要明显存在感而不必购买金尖的读者。Fine 更适合小字，Medium 更容易在普通纸上留下清楚线条；实际粗细会随纸张、墨水和角度变化。若你每天使用窄格中文本，优先寻找明确标 F 的 SKU；若你喜欢较宽的签字线，2159744 的 M 是更直接的起点。

不同 XL finish 的价格、库存和包装会变化，不能从 Black CT 估算 Teal、Lilac 或 Gold PVD 版本的材料。黑色 2159744 的规格页写 Stainless Steel cap；其他页面若写 lacquer 或不同 trim，应按独立 variant 记录。Parker 的两年材料／工艺保修从原始购买日起算，但地区条款、退换状态和当前库存随站点变化；保存订单和盒卡比依赖一张旧商品图更可靠。

“transparent shell”也要按页面语境读。它是 2159744 商品描述中的外观特征，帮助读者理解这款 XL 的视觉卖点；官网没有给出透明部件的厚度、耐溶剂等级或可拆卸结构。遇到不同颜色和不同年份的 XL，先核对该产品页是否仍使用相同描述，再决定是否作为 variant 继承。透明能看见墨迹不代表可以用硬物刮洗，亦不代表所有内部部件都能自行更换。

### 维护与选购检查表

收货先做四步：核对 Item #／finish，检查箭夹和帽口是否有运输擦痕，确认尖幅与包装，再用清水观察 feed 是否顺畅。第一箱墨不要用高沉淀或难清洗墨水；短写后检查帽内和握位是否有积墨。若透明 shell 内出现墨迹，先按正常清洗排查，不要把笔身拧到失去密封。漆面和镀铬饰件要避开钥匙与研磨布，擦拭后完全干燥再盖帽。

如果你想要的是轻细、可收集不同年代的经典 Vector，应跳转到历史 Vector；如果要的是现代较粗笔身、大号不锈钢尖和透明结构，才选 Vector XL。Ingenuity 的灰漆金饰与大号镀金不锈钢尖更偏礼品，Urban 的弧形笔身更显著；三者的 Parker 品牌关系相同，但 exact slug、主图和规格不能互换。正文中的版本差异、清洗动作和选择建议应保留这种颗粒度，避免把“Vector”三个字变成一个吞并所有历史和现行 SKU 的空壳节点。

若二手卖家把 2159744 写成“老 Vector XL”但没有商品号，先要求拍摄笔尖和帽顶。当前 XL 的大号尖与历史 Vector 的细尖比例差异明显；盒卡上如果只有 Rollerball 或 Ballpoint，也不能按外观直接改成 fountain pen。型号页宁可暂时保留待核对标签，也不应为了覆盖更多搜索词而把多个书写模式合并。
