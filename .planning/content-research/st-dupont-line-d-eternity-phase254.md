# S.T. Dupont Line D Eternity：品牌与代表型号资料包（Phase 254）

研究日期：2026-07-26。对象是 S.T. Dupont 品牌与现行 Line D Eternity 钢笔路线，不把 ballpoint、rollerball、Classique、D-Initial 或旧 Elysee/Olympio 资料混进同一型号。官方美国站的黑色 420216L 商品页是本包的 SKU 锚点；它把型号写作 Line D Eternity fountain pen，列出黑色 Dupont lacquer、缎面黑色饰件、articulated sword clip、黑色 14K solid-gold Wings nib、plunger，以及 Faverges（法国）工坊制造。

## 身份与粒度

- 新增品牌实体：`S.T. Dupont`，slug `st-dupont`。官方 heritage 页称 Simon Tissot Dupont 于 1872 年在巴黎开设皮具工坊，1924 年将工坊迁至 Faverges；这些是品牌沿革，不是 Line D 的首发年份。
- 新增型号实体：`S.T. Dupont Line D Eternity`，slug `st-dupont-line-d-eternity`。420216L 是黑色当前 SKU；颜色、金色/钯色饰件、Medium/Large、限量主题和书写模式都是版本或 sibling 边界，不为每种颜色建独立基础型号。
- 官方商品页将 fountain pen、ballpoint、rollerball 并列；本页只写钢笔。Line D Eternity 与 Classique、D-Initial 是不同产品线，不能互借供墨、尖型或图片。

## 可发布事实

1. 420216L 的官方页面写明黑色 Dupont lacquer 与 satin-finish black；剑形 articulated clip；黑色 14-carat solid-gold Wings nib；plunger included；在 Faverges, France workshops 制造。
2. 官方同页列相关墨囊颜色（040112 blue、040110 black、040362 red、040363 green、040364 turquoise）及墨水瓶，足以支持“品牌 C/C 用品路线”和购买时确认耗材；不把页面列出的 SKU 价格写进长期规格。
3. 官方欧洲页面将 Line D Eternity 分为 fountain pen 的 medium/large 路线；本包只锁定 420216L 的 Large 黑色款，不把 Medium 或限量材质的尺寸、重量、金属饰件移植进来。
4. SBRE Brown 对旧 Line D black/gold 样本测得合帽 146.6 mm、开帽 134.6 mm、后插 166.4 mm、总重 48 g；这是 2017 年一支黑金样本，正文将它放在“样本观察”而非 420216L 固定规格。
5. Fountain Pen Network 的使用讨论可以支持“Line D 有 snap-cap/clip-cap 维护与密封讨论”，但不承担全系耐用性保证。清洁建议采用保守编辑边界：换墨时温水吸排、自然干燥，避免溶剂、金属抛光剂和强拆剑形夹/帽内结构。

## 正文必须交代的版本边界

- “Eternity”是 Line D 的现代路线名，不等于所有历史 Line D；旧款 14K/18K、黑金/钯色和 Atelier/限量版本必须按具体参考号核对。
- 420216L 页面里的 black Wings nib 是该 SKU 的外观/规格描述；不要由此保证所有市场尖宽、所有年份尖面颜色或软弹写感。
- Plunger 与墨囊/瓶装墨水的关系应按随笔包装和官方售后说明确认；不要把“plunger included”改写为活塞钢笔或某个未经页面说明的独家容量。
- 官方图是版权商品摄影，本项目使用原创 factual SVG，明确“示意图，非产品照片”，不表现真实漆色、比例、Logo、刻字、库存或售价。
