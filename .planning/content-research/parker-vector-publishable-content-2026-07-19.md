# Parker Vector（经典款）：从 FP-1 到 Vector 的细杆入门线

## summary

经典 Parker Vector 源自 1984 年 FP-1，并在同年开始使用 Vector 名称；它是轻量细杆、钢尖、墨囊／上墨器的长期入门家族。Vector XL 是后来单列的另一条产品线，其粗杆、尺寸与 SKU 不再混入本页。

## 保留旧实体，但重写它的身份

本站过去把经典 Vector 与 Vector XL 写在同一页，连金属笔身、中字和 XL 尺寸也混了进来。现在这页只保留 **Parker Vector（经典款）** 的历史与版本；Vector XL 另设页面，不再借用经典款的资料。

“威雅”是中文市场常见称呼，可以作为搜索别名，但本页的边界始终是 classic slim Vector。任何带 `XL` 的商品代码、135/157 mm、11.5 mm、20 g 或“大直径大笔尖”描述都不属于这里。

## 1984：先叫 FP-1，随后改称 Vector

Parker Pens Penography 的 Vector 研究页记录：1984 年 2 月，Parker 在 RB-1 系列中加入 fountain pen，名为 **FP-1**；从 1984 年 3 月起，FP-1 开始使用 **Vector** 名称。页面还记录同年后续的笔杆、握位、笔帽与一体式笔夹调整。由此可以安全写出“FP-1 于 1984 年出现，之后在 1984 年使用 Vector 名称”。

其他资料有时把重新设计或更完整的产品线节点写成 1986。两者不必硬压成一个唯一年份：1984 是 FP-1 与 Vector 名称的早期证据，1986 可用于后续重整语境。本站时间线不把整个数十年家族写成“1984 一次定型”，也不因后续改款否定早期命名记录。

## 经典 Vector 的共同轮廓

早期 Vector 是细长、接近圆柱形的入门钢笔，钢尖、插帽与简单箭形笔夹构成基本识别点。塑料 Standard、金属 Flighter、后续图案版和不同市场生产版本之间存在材料、长度、笔夹与尖号变化。因此 family spec 只保留“细杆、钢尖、Parker 墨囊／兼容 converter”这类跨版本边界，不填统一尺寸和重量。

旧正文把它写成“塑料笔身轻飘飘、送礼凑数、写感一般”，既没有来源，也把价值判断当事实。新正文撤掉这些句子。轻量与细径可能是某些人长写的优点，也可能让大手用户疲劳；应以具体版本和实际试握判断。

## 与 Vector XL：名字相近，但不是同一型号

**Vector XL** 是更粗、更大的现代旁支，Parker 官网强调 larger diameter barrel 与 large stainless-steel nib。Teal 2159746 的 M、135/157 mm、11.5 mm、20 g 都只属于 XL 页。经典 Vector 不接受这些字段，XL 也不继承 1984 FP-1 的尺寸和版本表。

Parker 2022 trade catalogue 已把 Vector XL 与 2159746 单列，这是可核验的官方目录节点。现有证据不足以确认所有市场的统一首发日，因此本站只写“2022 官方目录已单列”，不把目录年份伪装成准确全球首发年。

拆开之后，查找也更清楚：想了解细杆、旧塑料或 Flighter 版本，看经典 Vector；想了解更粗握位、大型笔尖与 Teal 2159746，看 Vector XL。两者都归在 Parker 品牌下，并在各自页面互相指向。

## 上墨与版本检查

经典 Vector 钢笔通常使用 Parker 墨囊，并可搭配能装入该版本笔杆的 Parker converter。由于不同年代的细杆空间、包装和上墨器形制有差异，购买旧笔时不能只问“支持 converter 吗”，还要确认卖家实际使用哪一种、能否完整旋紧笔杆。

收到旧笔后先检查笔尖是否歪斜、握位是否开裂、笔帽是否能可靠闭合、笔杆螺纹是否受损。不要因为笔杆上有公司广告或图案就自动称为官方限量版；Vector 长期用于 promotional printing，图案来源和授权要另外举证。

## 书写与选购

Vector 的钢尖通常偏硬，但“硬”不等于粗糙或低质。尖铱状态、纸墨、握角与长期磨损比价格标签更能决定一支旧笔的写感。细杆用户应留意握位直径和台阶；需要插帽的人还要检查笔帽是否稳定、重心是否舒服。

买经典 Vector 时优先确认四件事：是否真为 fountain pen；是塑料 Standard、金属版本还是其他改款；尖号和笔尖状态；墨囊／converter 是否能正常安装。若商品标题写 Vector XL 或直径明显更大，应转到 XL 页面核对。

## 清洗和旧笔维护

现代墨囊版本可先拆下墨囊或 converter，以常温清水冲洗握位和供墨通道。旧墨干结时宁可多次温和浸洗可拆部件，也不要用热水、酒精或蛮力拧握位。塑料老化、裂纹和变形需要专业判断。

笔帽或笔夹松动不应靠瞬间胶随意固定；胶水可能雾化表面并让后续维修更困难。若钢尖明显错位，停止大力书写。长期不用时排空墨水、清洁、充分干燥后收纳。

## 媒体声明与事实边界

本页主图是本站原创 factual SVG，用一条文字时间线表示 `RB-1 → FP-1 → Vector → later revisions`，并画出与 Vector XL 分叉的资料关系。它不画任何具体钢笔，不复制或临摹历史广告、目录或产品照。**示意图，非产品照片**，不能用于辨认笔夹、颜色、长度或制造地。

当前可确认的是：经典 Vector 的钢笔前身 FP-1 于 1984 年加入 RB-1 路线，Vector 名称也在 1984 年开始使用；家族随后经历多次调整。Vector XL 已由 Parker 2022 官方目录单列，但精确全球首发日未核实，两者的尺寸、版本与商品代码应分别查阅。
