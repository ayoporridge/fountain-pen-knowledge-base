## 身份先落到 FCSE-3MR，而不是笼统的「大理石 Capless」

## 大理石纹理：官方说的是树脂外观，不是天然石材

exact page 把轴材质列为「ウレタン樹脂」，并形容表面是有光泽的大理石模样；官方还提醒每一支的纹理不会完全相同。这里有两个需要同时保留的事实：材料字段是氨基甲酸酯树脂，视觉字段是 marble finish。不能因为纹理像石头就写成天然大理石、矿物填充或石材笔身，也不能把每支纹路不同夸张成一个独立艺术编号。

五个颜色代码的日文和常用中文可以这样记录：MAB 是 marble black（大理石黑），MAL 是 marble blue（大理石蓝），MAG 是 marble green（大理石绿），MAR 是 marble red（大理石红），MAO 是 marble orange（大理石橙）。颜色翻译是便于导航的别名；代码和官方日文优先。强光、白平衡、压缩、表面反射会改变照片里的红、蓝或橙感，不能把卖家自行命名的「酒红」「墨蓝」「蜜糖」当成新原厂代码。

纹理变化的正确表达是「官方同一颜色也不会一模一样」，不是「每支都有独一无二的限量证书」。同色实物之间可能有深浅、云纹方向和斑块面积差异；这影响外观选择，但不改变 FCSE-3MR 的型号、笔尖或供墨关系。如果卖家声称某支是「纹理特别版」，需要额外的官方公告或产品号支持，不能从一张局部照片推断。

## Capless 按动结构与 SE 轴面的关系

Capless SE 和其他 Capless 一样采用按动收尖逻辑。按一次旋钮，笔尖从前端 head 伸出；再按一次，笔尖收回，shutter 闭合。Pilot 把这种按动式结构作为 Capless 的核心体验：随手书写前不需要拧开帽，收尖后又能减少笔尖暴露。使用完、放入口袋或放入笔袋前，应确认笔尖已经完整收入，不能停在中间位置。

SE 的大理石树脂只改变轴面 finish，不改变按键动作。试写时应把两层体验分开：先观察按键位置、前夹是否顶到虎口、shutter 是否能顺利闭合，再观察树脂轴面的重量和握感。某位评测者觉得前夹碍手或树脂表面「温润」，属于个人样本；官方 140 mm、14 mm、26 g 是产品卡数字，不能被一篇体验文替代。

拆装与换墨必须先收尖。旋开轴、取出笔记体时不要让笔尖外露；安装时把笔记体凸部对准 head 的导槽，再装回轴。若按键阻力突然增大、笔尖不能完全伸出或收回、shutter 有异物，不要反复急按或敲击轴面。急促连续按动和让按钮突然回弹可能导致内部墨水飞散、滴落或出墨过多，问题在精密机构，不是大理石纹理可以解决的表面问题。

## 与 Pilot 其他 Capless 和「SE」名称的边界

### 普通全尺寸 Capless FC-18SR

普通 Capless `FC-18SR` 也可能采用 18K、CON-40 和按动结构。区别在产品码、finish、尺寸、重量和具体 lineup。FCSE-3MR 的大理石树脂、14 mm、26 g、五色代码是自己的证据；普通黑色或金属色不能因为有反光就归入 SE。两个页面可以比较共同机构，但规格和图片不能互相覆盖。

### Capless Stripe FC-3MS

Stripe `FC-3MS` 是黄铜轴铑仕上げ条纹路线，官方给 13.3 mm、32 g；SE 是氨基甲酸酯树脂、大理石 finish、14 mm、26 g。两者都可能出现银光或复杂纹理，但材料、产品码和重量不同。读者想比较「金属条纹」和「树脂大理石」时，应通过两个独立页面跳转，而不是把 Stripe 的铑层或价格写进 SE。

### Capless 絣 FCN-2MR

絣 `FCN-2MR` 是絣黑 KB／絣蓝 KL 的独立 finish，当前官方给 13.4 mm、30 g。絣的纹样观感不能证明 SE 是织物、天然漆或木材；SE 的树脂也不能反向解释絣。颜色命名、SKU、价格和原创图都应单独维护。

### Custom Heritage SE FKVH-3MR

Pilot 国际保证清单把 Capless SE `FCSE-3MR` 与 CUSTOM HERITAGE SE `FKVH-3MR` 分列。两者共享「SE」字样，但不是同一系列：前者是按动、收尖、前端 shutter 的 Capless，后者属于带帽的 Custom Heritage。不能因为名称里有 SE，就把 Heritage 的笔尖、供墨、尺寸或树脂/树脂外观复制到本页。页面导航可以说明这是一对容易混淆的名称，但身份必须分开。

## 大理石树脂的使用、清洁与保存

树脂轴面的维护重点是避免溶剂、撞击和不必要的研磨。日常指纹可以用柔软、干净的布轻拭；不要用金属抛光膏、研磨布、丙酮、酒精或含磨料的清洁剂去「擦亮」纹理。不同光线下的亮暗变化是反光，不应通过粗糙抛光把所有纹路磨成同一亮度。Pilot 官方提醒，酒精等溶剂可能导致裂纹或变色，清洁剂也不能替代温和清水。

供墨系统要按官方边界处理。长时间不用先排空墨水，用清洁水多次吸入和排出，直到水色明显变淡；笔记体可以按说明清洗，head 与轴不能整体浸洗。残墨、墨渣或堵塞不能用强压气泵、针状工具或溶剂直接冲击。遇到流量异常，应先停止使用，记录墨水种类和颜色，必要时交给 Pilot 或专业维修方。

颜料墨、闪粉墨和高浓度染料墨会增加维护要求。Pilot 护理页建议使用 Pilot 万年笔墨水，并警告不要混合不同墨水或使用陈旧墨水；本页不把个人测试写成「所有非 Pilot 墨水都必然损坏」，而是明确官方建议与个人实践的层级。若已经使用了特殊墨水，清洗时要如实记录，不要在二手转让时隐瞒。

飞机、车辆和窗台是另一个常见风险。气压变化可能让墨水滴落或喷出，飞行中不要使用；高温、低温和直射日光可能影响树脂和墨水状态，长期存放应置于稳定、阴凉、干燥处。收纳前按键收尖、轴面擦净、converter 排空，笔袋里避免钥匙和硬质金属持续摩擦。

按键卡涩、shutter 不闭、笔尖不能完全收回、树脂轴出现深裂或 head 漏墨时，立即停止反复按动。不要自行拆开精密 head，不要涂未知润滑剂，也不要把整支笔泡进水里。保存产品码、照片、购买凭证和所用墨水，联系 Pilot 或专业维修方；后期维修或重涂应作为笔况记录，不能被写成新的原厂颜色。

## 试写与选购：纹理很重要，但不是唯一决定因素

选 Capless SE 时，先在常用纸张试写 F/M，再判断颜色和纹理。F 适合小字、表格和较窄行距，M 的视觉重量更明显；纸张吸墨和个人字幅会改变结论。试写还要记录夹子是否顶到虎口、按键是否能自然触及、笔尖是否每次完整伸缩，以及 26 g 的重量是否适合长时间书写。纹理照片只能帮助选外观，不能预测线条、干燥时间或出墨。

五色选择应按照代码而不是中文昵称验收。大理石红的 MAR、蓝色的 MAL、橙色的 MAO 可能因光源呈现不同色相；卖家若用「珊瑚」「海蓝」「奶油橙」命名，应要求原厂代码和尖幅。纹理每支不同是官方描述的一部分，但不能据此接纳颜色代码缺失的所谓「定制 SE」。如果颜色、代码和实物不一致，分别记录「外观相似」与「身份未证」两个问题。

## 常见误读的纠正

「SE」不等于 Custom Heritage SE：必须看 `FCSE-3MR` 或 `FKVH-3MR` 产品码。

「大理石」不等于天然石材：官方材质是氨基甲酸酯树脂，marble 是 finish 描述。

「每支纹理不同」不等于每支都有独立限量编号：这是外观差异，不是新的实体或 SKU。

「18K F/M」不等于每支笔线宽相同：改尖、纸张、墨水和调校会改变实际书写。

「¥44,000」不等于全球成交价：它是当前 exact 商品卡的日本建议价快照。

「同样按动」不等于同一型号：普通 Capless、Stripe、絣、Decimo、LS、Raden、Wood 和 FCS-1 各自有独立身份。

真人遍历页面时，应先读回 `FCSE-3MR-MAR-F`，再沿 lineup 检查五色 × F/M，最后核对 18K、CON-40、140 mm、14 mm、26 g 与来源定位。若页面只有「Marble VP」而缺少完整产品码和证据，应标为待补证，不用外观自动补全型号。

## 纹理、批次与实物照片的判断方法

官方说每一支大理石模样都不完全相同，意味着同一代码下的实物照片可以有合理差异，但差异必须停留在纹理层。颜色代码、尖幅和产品号仍应一致；如果一支 MAR 的卖家照片写成 MAB，或产品码最后的 F/M 与笔尖刻字不一致，那是身份冲突，不是「每支纹理不同」可以解释的范围。页面编辑时把纹理差异记录为外观描述，把代码冲突单独记录为待核验问题。
