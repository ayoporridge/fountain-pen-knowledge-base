# Pilot：Capless 的四条被普通入口遮住的公开路线

## summary

Pilot 官方目录与支持清单仍分别列有 Capless 絣（FCN-2MR）、Capless Stripe（FC-3MS）、Capless SE（FCSE-3MR）和特殊合金 Capless（FCS-1）。它们的饰面、尖材、颜色组合与价格不能继续藏在普通 Capless 的一个模糊 variant 里。

## body_md

## 为什么普通 Capless 入口仍不够

Pilot 的 Capless 是一个长期机构家族，但日本 Web Catalog 将不同材料、工艺和尖材的商品用独立品号列出。把所有 `Capless` 压成一个页面，会让读者误以为 FCN-2MR 的絣纹、FC-3MS 的铑饰条纹、FCSE-3MR 的大理石树脂和 FCS-1 的特殊合金尖只是普通 FC-18SR 的颜色。

本轮为 Pilot 品牌页补四个独立入口：**Capless 絣 FCN-2MR**、**Capless Stripe FC-3MS**、**Capless SE FCSE-3MR**、**特殊合金 Capless FCS-1**。它们都保留按键伸缩笔尖和前端 shutter 的 Capless 核心，却在饰面、材质、尖材、尺寸重量或市场代码上有可核对的边界。

## 四条路线的差异

- `FCN-2MR` 是絣（かすり）纹理路线，官方 lineup 为黑／蓝两色、F／M，18K、CON-40、140 mm、13.4 mm、30 g。
- `FC-3MS` 是黄铜铑饰条纹路线，F／M、18K、CON-40、140 mm、13.3 mm、32 g；它不是普通金色或黑色 Capless 的图片替换。
- `FCSE-3MR` 的 `SE` 来自法语 *Seul*，商品页强调每支大理石花纹不完全相同；它使用氨基甲酸酯树脂轴、18K、CON-40、140 mm、14 mm、26 g，黑／蓝／绿／红／橙五种设计各有 F／M。
- `FCS-1` 使用特殊合金尖和哑光金属色，银／铜／深绿／灰蓝四种颜色各有 F／M；官方规格为黄铜涂装轴、CON-40、140 mm、13.4 mm、30 g。不能把它写成 18K，也不能拿普通 Capless 的金尖书写感代替。

四条路线的共同机构历史都可以追溯到 Pilot 1963 年推出的 Capless，但“1963 年 Capless”不是这四个具体 finish 的上市日期。价格、库存、地区代码和包装是当前目录快照；正文会把官方数字、体验资料和未知范围拆开。

## 关系、维护和购买

品牌页将普通 Capless、Decimo、LS、Fermo、木轴、螺鈿、絣、Stripe、SE 与 FCS-1 分开链接。按动结构、CON-40 和收尖护理可作为家族背景，但各页不共享重量、材料、图片或尖材。特别是 FCS-1 的特殊合金必须保留在 `nib` 字段，不能沿用 18K 标签。

收货先看完整品号和尖幅，再检查按键、shutter、笔尖刻字、converter 与盒卡。换墨前收回尖端，用室温清水清洁笔舌和 converter；避免把水灌入 head，避免高低温、日晒、酒精溶剂和自行拆精密机构。絣纹、铑条纹、SE 大理石和哑光金属的外观差异都应归入各自 exact SKU，不能用同一张普通 Capless 图覆盖。

## 图片与来源边界

本轮每个型号使用一张独立原创 factual SVG，图内明确 `non-photo`、`non-logo`、`not-to-scale`、`non-colour-proof`。它只说明品号、材料／尖材、设计和供墨，不能替代官方商品照片，不证明每支笔的具体纹理、光泽、颜色或库存。

## 从品牌页进入型号页时应保留的判断顺序

先按品号分流，再按材料或尖材核对，最后才讨论颜色和书写体验。`FCN-2MR`、`FC-3MS`、`FCSE-3MR` 与 `FCS-1` 虽然都可以被海外零售商笼统称作 Vanishing Point 或 Capless，但 Pilot 日本目录的品号、尖材和尺寸已经给出更可靠的身份锚。品牌页只负责告诉读者“还有四条独立路线”，具体的 F／M、设计代码、盒卡、价格和护理应回到型号页。

普通 Capless 的专业评测可以支持按动便利、前夹位置和日常取放动作，却不能替代特殊合金的材质、SE 的大理石纹理、Stripe 的铑饰或絣的图案事实。官方 exact page 支持商品字段，支持清单支持独立入口，价格表只支持检索日期的商业快照。三类证据各有边界，不能因为同属 Pilot 就互相覆盖。

这四页也不宣称把 Pilot 全部历史 Capless 版本都列完。旧市场代码、停产色、限定套装或二手改装需要新的日期与来源证据；本轮只发布当前公开目录能够逐项核对的 FCN-2MR、FC-3MS、FCSE-3MR 与 FCS-1。这样品牌导航的“全部已公开型号”审计才有可追踪的 SKU 边界，而不是用一个宽泛的系列名掩盖空缺。

对于品牌页的读者，最实用的导航问题是“我正在看的到底是哪一种尖和表面”。沿着四个入口继续往下，页面会分别给出可复核的产品码、variant 清单与不应继承的字段；这比在普通 Capless 页增加一串没有来源的颜色名称更能减少误购和重复实体。
