# Pineider：十一条型号入口，Alba 也要拆成 Classic 与 Mini

Pineider 的品牌历史可以从 1774 年佛罗伦萨文具传统讲起，但品牌年龄不能替代具体产品证据。当前产品线上既有 UltraResin 日用笔、金属和碳纤维限量笔、piston、cartridge／converter，也有 2026 年重新使用 galalith 的 Alba。品牌页负责告诉读者有哪些路可以继续点；每个型号的材料、笔尖、上墨与版本仍由 exact product page 决定。

## 十一个公开型号节点

[[Pineider Avatar UR]] 是 UltraResin 日用路线。[[Pineider Arco Fountain Pen]] 以 current PP5901／617 为锚，2019 Oak 样本的 14K、活塞、重量与限量只属于那一代。[[Pineider Rock Fountain Pen]] 的 current PP4901／426 是钢尖活塞，旧礼赠文章的 converter 说法留在版本冲突。

[[Pineider Classic Palladium Fountain Pen]] 对应 PP5801／779，不能因为名称里也有 Classic 就和 Alba Classic 合并。[[Pineider Tempi Moderni Fountain Pen]] 对应 PP6001／614。[[Pineider Grande Bellezza Forged Carbon Fountain Pen]] 锚定 PP2401／206，888 与 88 的零售冲突已经隔离。[[Pineider Mystery Fast Filler Fountain Pen]] 锚定 SPP6901／943，Mystery／Mistery 是同一 current 产品的来源化拼写差异。

[[Pineider Millenium Fountain Pen]] 对应 PP4801／945，官网单 n 是 canonical，官方文章双 n `Millennium` 是 alias；Arman 的 PP4801G20 同码档案不授权 current 结构。[[Pineider Psycho Fountain Pen]] 对应 PP4301／468，三种饰面与 converter／piston 元数据冲突分层处理。

2026 年新增的 [[Pineider Alba Classic Fountain Pen]] 锚定 **PP7701／1120**，是 144 mm、No.6 steel、EF／F／M、converter or cartridge、palladium trims 和 Twist Magnetic Lock。[[Pineider Alba Mini Fountain Pen]] 锚定 **PP7601／1122**，是 120 mm、No.5 steel、F／M、cartridge、gold plating 与 Magnetic Lock。品牌导航把它们列成两个型号节点，而不是一个含糊的 `Alba` 或 `Mini`。

## Alba 共享材料，不共享整套规格

Pineider Alba 专页和 2026 年 6 月的官方文章把 galalith 作为家族共同材料。la Repubblica Firenze 也独立报道了由 milk casein 衍生的材料，以及 Classic／Mini 两条互补路线。共享来源足以证明家族关系，却不允许跨型号复制字段。

Classic 的 PP7701 child SKU 是 `SPP7701E010`、`SPP7701F010`、`SPP7701M010`；Mini 的 PP7601 child SKU 是 `SPP7601F010`、`SPP7601M010`。Classic 可用 converter 或 cartridge，Mini 官方只写 cartridge。Classic 使用 No.6 与 Twist Magnetic Lock，Mini 使用 No.5 与 Magnetic Lock。一个字段落错，实际操作就可能从“资料小误差”变成强装上墨器或错误拆帽。

`Classic` 和 `Mini` 也都是易混名。此前的 Pineider Classic Palladium PP5801／779 不是 Alba Classic；站内 generic Fountain Pen Mini SPP7201／1063 和 Avatar UR Mini 也不是 Alba Mini。识别时应把完整商品名、主代码、child SKU、材料、饰面与上墨方式放在一起，不只搜索一个尺寸词。

## 使用与维护的共同底线

所有型号先按 exact fill system 操作。Piston 不拆成 converter；cartridge／converter 要确认接口和密封；Alba Mini 在没有 PP7601 兼容证明前不强装 converter。磁吸帽沿轴线开合，Twist Magnetic Lock 与普通 Magnetic Lock 不互换描述。钢尖、14K、Quill、hyperflex 和 EF／F／M／B／S 都只属于明确型号与版本，不因品牌相同而自动继承。

Alba 的 galalith 需要额外注意长期浸泡与湿度骤变。维多利亚与阿尔伯特博物馆对历史 casein plastic 的保育研究指出，材料吸放水分可能导致收缩、脆化、龟裂或翘曲。本站不把博物馆条件当作 Pineider 的精确保修参数，但据此采用保守操作：笔杆和帽盖不泡水、不用热水或酒精，外部局部微湿擦拭后立即擦干，避免暴晒和持续高湿。

## 购买时的顺序

先问完整身份：fountain pen、model code 和 child SKU。再核对机构：piston、converter／cartridge 或 cartridge-only。第三步看笔尖与材料：steel 或 14K、尖幅、galalith／UltraResin／metal／forged carbon。最后才比较颜色、编号、包装与价格。网页价格、库存和选择器顺序会变化，不进入永久事实。

Alba 买家还应检查材料表面是否只是自然纹理，还是已有裂纹、翘曲或帽口损伤。二手卖家只写“Pineider Classic”“Pineider Mini”或“white Alba”时，不足以归类。要求看到主代码、完整 SKU、笔尖刻字、上墨接口、帽盖和盒证，再决定链接到哪个节点。
