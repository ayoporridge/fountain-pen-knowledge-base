# Wancher World Tree – Ebony：Sekai 系列的天然乌木基础款

## summary

Wancher World Tree – Ebony 是官方 Sekai collection 的天然乌木钢笔。系列页给出直径 13.2 mm、闭帽 140.1 mm、插帽 164.4 mm、27/21 g，兼容国际墨胆或转换器；925 银夹可选并可拆，尖材按 SKU 记录。

## body_md

World Tree – Ebony 是 Wancher 把天然木材和日本工艺放在同一支日用钢笔上的基础型号。官方产品页称它是 Sekai collection 的第一个 World Tree model：以世界各地的天然珍贵木材表达“连接世界”的概念，乌木、檀木、Verawood 等材料共享系列灵感，但并不共享同一个具体材料规格。本页只描述 `world-tree-ebony` 这一个官方商品，不把 Olive、Teak、Sandalwood、Verawood 或后来的 Aizu Urushi 版本合并成一支“世界树通用笔”。

### 木材、夹件与尺寸

乌木笔身和笔帽是这款的核心识别特征。木材天然纹理、颜色深浅和细小差异会使实物与商品图不完全一致，官方也明确提醒木制品存在颜色差异。产品可选择无夹、925 matte silver clip 或 925 silver clip；夹子由 Wancher 在日本工作室制作，部分哑面处理使用大分温泉蒸汽的工艺。夹子是可拆的附件，装上或拆下会改变重量与携带方式，不能把夹片当成笔身固定结构，更不能用其他系列夹子默认替换。

官方 World Tree collection 的系列尺寸为直径 13.2 mm、闭帽 140.1 mm、插帽 164.4 mm；重量为 27 g（含夹）和 21 g（不含夹）。这些数字是系列页面的参考值，最适合用来判断比例和夹件差异，不应反推每种木材的密度或未经说明的净重。插帽后的 164.4 mm 对手掌较小的人可能偏长，购买前可分别试用有夹与无夹状态。

### 尖材与供墨

官方产品页列出 converter 或 European International Standard cartridge 供墨；随包装包含墨胆、转换器和传统日式木盒。可选尖材包括 #6 Jowo stainless steel、Wancher 18K gold 与 Keiyu/Kodachi，feed 则有 plastic、black ebonite、red ebonite。尖材不是木材颜色的自动属性：购买时应明确选的是哪一种尖、是否需要 Kodachi，以及实际商品是否把蓝色或特殊尖作为额外选项。不要把 Dream Pen 的 Urushi、Sailor 合作尖或 Shizuku Glass Nib 的玻璃笔头写入 World Tree – Ebony。

首次装墨时，把标准国际墨胆或转换器平直推入握位，确认坐牢后再让笔尖朝下等待出墨。换色时清空旧墨，用清水冲洗转换器和尖部，待部件自然干燥再装回。木材表面不要使用酒精或强清洁剂；Wancher 对手工涂层和木面建议使用柔软布与清水，避免把夹件、木纹和表面涂层一起擦伤。夹子若松动、木面出现裂纹或供墨处渗漏，应停止自行拆解并联系卖家或维修渠道。

日常使用时，乌木笔身更适合被当作需要观察的天然材料，而不是完全均质的树脂外壳。装在笔袋里时让它与金属钥匙、裸露的笔尖和会掉色的皮件分开；长时间不用应洗净、阴干并松开帽盖的应力，不要把笔留在车内或暖气旁。木材表面出现发白、明显凹痕或裂线时，先记录照片和购买信息，再向 Wancher 或授权经销商询问处理方式。可拆夹的好处是无夹状态更轻、握持时少一个硬边；代价是携带时少了固定点，不能把夹子当作防滚或防跌落保证。

选择尖材时，先按书写幅度、纸张和维护习惯决定，而不是先按木纹颜色决定。JoWo 不锈钢尖通常是较易替换和日用的入口；18K 尖与 Keiyu-Kodachi 则属于不同预算和书写方向，实际供货、调校及等待时间需要在下单前确认。塑料、黑色 ebonite、红色 ebonite feed 也是选项边界，页面没有证明任一 feed 会让所有 Ebony 笔产生相同的出墨量。若购买的是无夹版本，应另外确认运输盒和日常收纳方式；包装中的木盒是配件与保护物，不应据此推断笔身产地或木材等级。

### 版本边界与选购建议

World Tree – Ebony 是 Sekai collection 的木材基础款；World Tree – Olive、Teak、Sandalwood、Verawood 是同系列的材料 SKU，不应各自建立成完全不同的品牌型号。Sekai Ai 则是在 Olive Wood 基础上做 Aizome 蓝染并有 Dove Zogan/夹件选项，属于另一个具体商品；Sekai Aizu Urushi、Saihi Urushi 和 Dream Pen 的漆艺也不能共用乌木页的规格或图片。若读者只想要可拆银夹和天然木材，Ebony 是清晰入口；若在意漆艺、贝雕或更复杂的限定版，应跳转相应 SKU。

专业零售商 Appelboom 的 World Tree Teak 页面可用于交叉核对 Sekai 家族的木材与 C/C 供墨语境，但它不是本页 Ebony 的重量或纹理主源。页面主图使用本站原创 factual SVG，是非产品照片，不是从官方商品页复制的产品照片；它只提示乌木、可拆 925 夹和官方系列尺寸，不证明实物木纹、颜色、Logo、库存或具体尖材。

## 深化记录：木种、夹件与系列尺寸要分层

Ebony 页最重要的不是“黑色”，而是 `World Tree – Ebony` 这个 exact product identity。Wancher global World Tree collection 把 Ebony、Teak、Verawood、Sandalwood 等列成材料入口；Wancher Japan 的 Sekai collection 又把它们放进同一品牌导航。集合页负责漫游，Ebony 商品页负责这一支笔的材质、夹件、尖、feed 和包装。不能因为几支笔都使用天然木材，就把颜色、密度和净重拼成一套通用规格。

乌木天然纹理和颜色深浅会随木料、切削方向、抛光和光线变化。深色外观不能单独证明是 Ebony，也不能由香味、重量或一张远景图证明木种。收货时要同时保存商品名、笔杆纵向纹理、帽口、尾钮、夹件和尖刻照片；若商品图与实物差异明显，先区分自然色差与运输损伤，再联系卖家，不要自行重磨表面。

## 系列数字的正确用法

World Tree collection 给出直径 13.2 mm、闭帽 140.1 mm、插帽 164.4 mm，以及含夹约 27 g、无夹约 21 g。它们是家族参考值，能帮助读者理解一支插帽笔为何显得较长、夹件为何改变重量；不能当成每一支 Ebony 的实测公差。测量时要说明是否含夹、是否套帽、是否装 converter 和墨水，不能把一支 Teak 的秤读数写回 Ebony。

如果二手笔明显偏离系列参考，先检查夹件、帽子、墨胆和是否有木材裂纹或后配零件，再考虑版本身份。数字可以排除明显错误，但不能单独证明木种；反过来，漂亮黑木纹和原装木盒也不能替代尖面、订单和品牌来源。页面保留“系列参考”和“具体实物读数”两栏，避免把约数伪装成制造公差。

## 夹件与携带

No Clip、925 Matte Silver Clip 和 925 Silver Clip 是 Ebony 商品页的选项。夹子由 Wancher 日本工作室制作，可拆意味着重量、携带点和视觉线条都会变化。无夹版适合放在柔软笔袋中，但桌面滚动风险要靠笔袋处理；有夹版可以固定在笔记本边缘，却不能当作防跌落保险。夹子松动时不要用普通胶水或钳子夹回，先记录夹孔、螺丝和木面状态。

含夹 27 g 与无夹 21 g 的差值也提醒使用者：书写时的重心可能随配置改变。不要把“有夹更重”直接翻译成舒适或不舒适；应分别记录不插帽、插帽和连续一页的感受。若夹件是后配或不是 925 版本，要在实物卡里标为改装，不把后配件当作型号固定特征。

## 尖材、feed 与 C/C 使用

Ebony exact page 列 #6 JoWo stainless、Wancher 18K 和 Keiyu/Kodachi，并提供 plastic、black ebonite、red ebonite feed。它们是选项边界，不是每支笔同时安装的固定组合。尖材不等于尖幅，也不等于供墨湿度；记录一支实物时，写清尖面刻字、EF/F/M/B 等实际幅宽、feed 颜色、converter 状态和是否调校。

国际墨胆或 converter 装入握位时要保持轴线平直，确认接口坐牢后再让尖端朝下等待出墨。换色先排空旧墨，再用接近室温的清水清洗转换器、feed 和尖部，让部件自然干燥。木制笔身不要浸水，清水也不应沿帽口或尾钮长时间停留；如果握位渗墨，先检查 C/C 接口和 feed，而不是拆木件。

Keiyu/Kodachi 是页面列出的尖材路线，不能把 Dream Pen 的漆艺尖、Shizuku Glass Nib 或其他合作款自动写入 Ebony。若订单只写“黑色 World Tree”，尖和夹件仍然待核；颜色不是配置代码。

## 木材维护与保存

天然木材不等于防水。汗液、墨水和潮气会进入接缝或改变光泽；高温、极端干燥、骤然温差、酒精、强清洁剂和研磨剂都可能损坏表面。外部灰尘用柔软干布轻拭，必要时短暂使用微湿布后立即自然干燥。不要用金属抛光膏、钢丝刷、吹风机或热源“恢复亮度”。

长期停用前排空 converter，清洗尖与 feed，自然干燥后再盖帽。笔身与钥匙、裸露金属和会掉色的皮件分开，木盒里不要放入湿布或未干的笔。每隔一段时间在散射光下检查木纹、帽口、螺纹和夹孔；出现裂线、发白、起皮、异味伴随表面变化或夹件松动时，先停止强拧和抛光，保留照片、订单和开箱记录，联系 Wancher 或有木笔经验的维修方。

## 与兄弟 SKU 的选购边界

Ebony 与 Teak、Sandalwood、Verawood 都是 World Tree 木材路线，但木种不同；Sekai Ai 还叠加 Olive Wood、Aizome 蓝染与 Dove Zogan。不同木种不能共享颜色校样、密度、重量和气味结论。若读者要最深色的天然木纹，可以把 Ebony 作为检索入口；若实际看到纵向深色纹理、蓝染或浅色木面，应回到对应商品页确认。

购买前保存 exact URL、订单中的夹件和尖材选择、包装照片及卖家实拍。官方宣传图只能说明 Wancher 展示过一种外观，不能证明二手笔未重涂、未换帽或没有后配夹；只有天冠和盒子照片时，证据不足。价格、库存和是否含木盒按交易日期记录，不能把“当前有货”写成长期生产状态。

本站 SVG 只是事实示意图，标出乌木、可拆 925 夹、C/C 和系列尺寸边界，明确不是产品照片、Logo、比例图或颜色校样。真实木纹、夹件磨损和尖材只能回到合法商品图、订单和实物。

## Ebony 证据卡

为一支具体 Ebony 建卡时固定记录：商品标题和 exact URL；检索日期；木纹、帽口、螺纹和尾钮照片；无夹/哑银夹/银夹状态；尖材、尖幅、feed、converter；空笔或含夹称重条件；盒标、发票和维修史。未知项写“未知”，不从 Teak、Verawood、Sandalwood 或 Sekai Ai 自动填入。

后续若官方更新尺寸、尖或夹件，新增带日期的来源并注明市场；若只是商品图、价格或库存变化，更新商业快照，不修改 Ebony 的木种身份。这样品牌页可以继续跳转到五个木材入口，而不会因为一张黑色照片把木种和配置重新混合。

## 现场读回清单

真正收到一支 Ebony 后，建议按固定顺序拍照和测量：先拍完整笔和包装，再拍木纹、帽口、螺纹、尾钮、夹孔和尖刻；随后拆下或保留夹件分别称重，记录是否套帽、是否装 converter。若卖家只给一张黑色远景图，以上字段都应标为未知，而不是用系列参考或兄弟木种补齐。照片要保留自然散射光和拍摄日期，避免用滤镜把天然色差变成“标准黑”。

如果实物出现细裂、发白、起皮或夹件晃动，先暂停装墨和强拧，隔离保存并联系售后。木材问题、供墨问题和后配零件需要分开记录；它们可能同时发生，却不应合并成“型号不符”。这套读回顺序让品牌页的 Ebony 入口既能承接日常维护问题，也能把真正不同的 Teak、Verawood、Sandalwood 和 Sekai Ai 留在各自页面。
