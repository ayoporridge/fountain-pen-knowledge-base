# Pilot Custom Heritage SE

## summary

`Custom Heritage SE / FKVH-3MR` 是 Pilot Custom Heritage 系列的大理石树脂型号。日本官方 SKU `FKVH-3MR-MABF` 列 14K No.5 F、135 mm、22 g、CON-40/CON-70N 和随附 CON-70N；五色各有 F/M。

## body_md

Pilot Custom Heritage SE 最容易被两个方向误读：一是把它缩成“Custom Heritage 的大理石颜色”，二是把它和 912、91、92 视为同一支笔的换壳。官方页面给出的型号平台是 `FKVH-3MR`，具体产品页以 `FKVH-3MR-MABF`（Marble Black、F）为例；这足以把它从普通 Heritage 页面中分离出来。`SE` 不是一个随意的营销后缀，Pilot Custom 英文页解释它取自法语 *seul*，即“唯一”。官方同时提醒大理石纹样每支不同，所以本页把颜色和尖宽放在 variant 层，保留一个可复用但有边界的 `FKVH-3MR` 主实体。

规格先锁定日本官方 exact SKU。页面列出 14K No.5 F、鞘螺纹嵌合式帽、樹脂轴与帽、最大直径 14.7 mm、全长 135 mm、22 g，并列出 CON-40、CON-70N；该具体页面还显示随附 CON-70N。Pilot Custom 英文系列页进一步确认 FKVH-3MR 采用 14K No.5，F/M 两种尖宽。这里的 22 g 是官方产品规格，不应和零售商是否含墨、包装或改尖后的称重混在一起；135 mm 也不是把 91、92 或 912 的尺寸平均出来的数字。

FKVH-3MR 的颜色 line-up 由大理石黑、红、蓝、橙、绿组成，每色提供 F/M。日本产品页列出的十个尾缀是 `MABF`、`MABM`、`MARF`、`MARM`、`MALF`、`MALM`、`MAOF`、`MAOM`、`MAGF`、`MAGM`。尾缀在这里很有用：它能把同一平台的颜色和线宽落到盒标、发票和二手照片；但它不意味着每一支笔都有完全相同的纹理。官方“没有两支纹样完全相同”的说明，正是为什么页面不放一张大理石照片去代表五种颜色。

与同系列型号比较时要保留结构差异。Custom Heritage 91 是 No.5、黑色树脂、日用路线；92 是透明笔身和尾栓活塞，能够观察墨量；912 是 No.10、银色饰件和多种特殊尖选项。SE 是 No.5、F/M、大理石树脂、c/c 平台。它们都可以写作 Heritage，但供墨、尖号、颜色和重量不能互抄。Custom 74 与 742/743 也不是 SE 的前身变体：742 使用不同的 No.10 路线，743 使用 No.15；823 更是固定真空／柱塞上墨。页面中的“相近”只用于帮助选购，不用于合并实体。

书写体验要从实际线宽和样本开始。官方只承诺 F/M 这一产品选项和 14K No.5，不承诺 flex、软弹或某种固定湿度。大理石树脂的视觉变化不会自动改变尖端的几何；F 尖适合较小字与日常笔记，M 尖更宽、墨色更饱满，但纸张、墨水和个人压力仍会影响结果。购买二手 SE 时应要求尖端刻字、完整尾缀、笔帽螺纹和出墨试写照片；卖家把 912 的 FA、PO 或 WA 写进 SE 商品标题时，应当视为型号错误而不是“特殊版本”。

上墨路线是 Pilot 的 cartridge/converter 平台。官方列 CON-40 与 CON-70N，且 exact SKU 随附 CON-70N；使用前确认 converter 密封与旋钮动作，墨囊则按 Pilot 接口直线推入，不要左右摇晃到撑裂握位。换色或长期停用时用常温清水吸排，直到水色明显变淡，再将笔尖朝下充分干燥。不要因为 92 使用尾栓活塞就去拧开 SE 的尾端，也不要把 823 的真空清洗步骤强行套用。

树脂与大理石纹样的维护同样需要克制。外部用柔软干布轻拭，避开酒精、香水、强溶剂、研磨膏和粗糙布料；高温车内、长期直晒和笔袋中与金属硬物摩擦，都可能让树脂和表面光泽发生变化。帽盖应顺着螺纹平稳旋合，遇到砂感、卡顿或偏斜就退回检查，不要用力把帽口“拧到底”。若出现裂纹、松帽、漏墨、尖片错位或持续断墨，保留 FKVH-3MR 尾缀与购买记录，先走 Pilot/授权维修流程。

购买时的优先级是身份、尖宽、纹样、状态。先确认商品标题是否真的写 `Custom Heritage SE` 或 `FKVH-3MR`，再核对颜色后缀和 F/M；不要只凭“Pilot 大理石笔”搜索图判定。日本官方目录可证明该型号存在，澳大利亚 Pilot 页面在 2026 年 7 月又说明当地不再由官方分销但合作零售商可能尚有库存，这提示地区可得性并不统一。价格、税费、包装和保修应按所在市场重新确认，不能把某个海外折扣价写成型号固定售价。

它适合想要 Heritage 平顶轮廓、14K No.5 日常书写和每支纹样有差异的使用者；如果你真正需要可见墨量、活塞或特殊尖，应转向 92 或 912。SE 的“唯一”更接近每支大理石纹理的个体差异，而不是编号限量或保证升值。页面把这种边界写清楚，读者才能从品牌导航进入实际选购，而不把漂亮照片误认为技术规格。

随页原创 SVG 只标记 `FKVH-3MR`、No.5 14K、F/M、十个颜色/尖宽 SKU 和 22 g / 135 mm 的官方字段。它明确是 factual diagram、非产品照片、非 Logo、非比例图、非颜色校样；真实大理石纹路仍需查看对应尾缀的官方或授权图片。
