## summary

Opus 88 Premium Opera 是台湾制造的高端装饰路线：树脂笔身、漆面 Dot 帽、Bock Type 250 钢尖和带止墨阀的日式滴入式上墨。Brown Dot 是一个可核对的颜色 SKU，不代表所有 Opera 版本。

## body_md

### 先把 Opera 与 Opus 88 的其它型号分开

Premium Opera 不是把 Demonstrator、Koloro 或 Jazz 换一顶帽子后的同一支笔。它是 Opus 88 的装饰性较强、采用 Bock Type 250 尖组的路线；本页以资料可核对的 **Premium Opera Brown Dot** 为规格锚点，再把 Blue Dot、Green Dot 和 Grey Dot 当作同系列颜色变体。另有 Opera Master 等名称，但目前没有足够一致的产品资料把它们并入本页，因此不把限量款的金尖、尺寸或上墨方式外推到 Premium Opera。

### 外观与材料

Stilo e Stile 的 Brown Dot 商品资料把笔身列为透明棕色树脂，笔帽为带 Dot 装饰的漆面结构，配银色／铑色饰件；页面还列出台湾制造、旋帽、闭合约 144 mm、笔杆约 130 mm、笔帽约 63 mm、笔杆直径约 15 mm、总重约 34 g。不同颜色在屏幕、光线和批次下会有差异，不能把零售图片当作统一色卡。JUSPIRIT 的 Opus 88 Premium 系列导航也把 Opera 放在 Bock #250 大尖组，并与使用 JoWo #5 或 JoWo #6 的其它路线分开。

这些数字是 Brown Dot 商品页的记录，不是每个 Opera 版本的制造公差。二手或停产颜色应优先核对帽顶、Dot 装饰、笔身透明度、笔尖刻字和包装型号；如果只有“Opus 88 高端款”而没有可辨识的外观或 SKU，页面只能记为待核实样本。

### Bock 250 尖与日式滴入式上墨

Premium Opera 的关键识别点是 Bock Type 250（常写作 Bock #6）钢尖单元。Brown Dot 资料列出 EF、F、M、B 和 2.3 mm Stub 选项；尖宽影响线条、墨流和握笔角度，不能把某支 Bock 尖的写感写成全系列保证。Opera 的 Bock 250 与 Opus 88 Demo、Jazz、Omar 常见的 JoWo 路线不是同一套完整尖组，替换时应核对 housing、螺纹和 feed，不能只看到“#6”就强行互换。

它使用 Opus 88 的日式滴入式结构：先旋下握位／尖组，把瓶装钢笔墨用附带滴管加入笔身，再装回尖组；尾部 blind cap 控制止墨杆。写字时要打开阀门，让墨水进入 feed；收纳、携带或乘飞机前应关紧阀门。Opus 88 的 Quick Start 说明明确写明这类钢笔不接受墨囊，灌墨与清洗都应使用滴管或 bulb syringe，而不是把转换器塞进笔身。止墨阀减少携带时的流动风险，却不等于可以忽略 O-ring、螺纹和温度变化。

### 维护与使用边界

换墨时先排空笔身，打开止墨阀，拆下尖组，用清水冲洗笔身与 feed；说明书建议让零件完全风干后再装回。只使用适用于钢笔的水性墨水，不使用 India ink、丙烯墨或其它会在 feed 中结块的介质。O-ring 若需保养，只能使用少量适合钢笔的硅脂；硅脂不能掩盖裂纹、错牙或已经磨损的密封件。拆装时把尖、feed 与 housing 的方向记下来，避免为了清洗而反复干拧。

Opera 适合喜欢较大的树脂笔、装饰性帽子、一次灌入较多墨水并愿意遵守阀门操作的人。它不适合只用墨囊、经常快速换色或偏好短小轻便笔身的场景。选择时先决定是否需要 Bock 250 的尖组选项，再核对具体 Dot 颜色、是否含滴管、笔身是否有裂纹、尾部阀杆是否顺畅，以及卖家能否提供可追溯的型号照片。不要因为同属 Opus 88 就把 Premium Opera 的 144 mm、34 g、Bock 250 或颜色图片复制到 Demo、Koloro、Jazz、Omar 或其它型号页。
