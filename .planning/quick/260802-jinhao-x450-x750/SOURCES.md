# Phase 346 sources — Jinhao X450 / X750

## X450

1. [Truphae — Jinhao X450 Review](https://www.truphaeinc.com/blogs/reviews/jinhao-x450-review)（2020-05-08）：中国制造语境、漆面金属、约 1.5 oz、不锈钢中号尖、卡扣盖、转换器、标准国际墨囊、颜色样本。
2. [Inks and Pens — Jinhao X450 Review (and fakes)](https://www.inksandpens.com/post/jinhao-x450-review-and-fakes/)（2015-06-20）：黄铜观感样本、未套盖／套盖重心、#6 尖与 feed 可换、颜色与仿品识别边界。
3. [The Gentleman Stationer — Pen Review: Jinhao x450](https://www.gentlemanstationer.com/blog/2014/6/9/pen-review-jinhao-x450)：早期样本、中号尖与 Goulet #6 替换尖观察。
4. [Goulet — Jinhao X450 Frosted Black](https://www.gouletpens.com/products/jinhao-x450-fountain-pen-frosted-black)：当前零售 SKU 的材料、供墨、尺寸和重量字段。
5. [Goulet — X450/X750 nib swapping](https://www.gouletpens.com/blogs/fountain-pen-blog/jinhao-x450x750-fountain-pen-nib)：#6 尖替换与两型号共通的改装语境，不承担两者身份合并。
6. [Fountain Pen Network — Jinhao X450 Review](https://www.fountainpennetwork.com/forum/topic/285607-jinhao-x450-review/)（2015-02-24）：玩家样本、三角握位、尺寸与尖片旁证。

## X750

1. [Goulet — Jinhao X750 Fountain Pen Review](https://www.gouletpens.com/blogs/fountain-pen-blog/jinhao-x750-fountain-pen-review)（2013-12-03）：all-metal、snap-cap、#6 钢尖、转换器、标准国际墨囊、可套盖和单支书写观察。
2. [Goulet — Jinhao X750 Silver](https://www.gouletpens.com/products/jinhao-x750-fountain-pen-silver)：当前银色 SKU 的材料、尺寸、重量、容量和商品代码 `JIN-X750-Silver-M`。
3. [JetPens — X750 Ice Flower Red](https://www.jetpens.com/Jinhao-X750-Fountain-Pen-Broad-Nib-Ice-Flower-Red/pd/14119)：X750-2 具体 SKU 的 141/163/125 mm、握位与卡水／转换器字段。
4. [Peninkcillin — Jinhao X750 review](https://peninkcillin.blogspot.com/2012/01/jinhao-x750-fountain-pen-review.html)（2012-01-23）：2011 购入样本、宽尖和多种墨水长期使用旁证。
5. [Stationery Wiki — Jinhao x750](https://stationery.wiki/Jinhao_x750)：社区维护的 141/126 mm、36 g、#6 钢尖摘要，权重低于零售与独立实物资料。
6. [Fountain Pen Network — Jinhao X750](https://www.fountainpennetwork.com/forum/topic/330659-jinhao-x750/)（2017-12-14）：玩家样本与早期零售来源旁证。
7. [Goulet — X450/X750 nib swapping](https://www.gouletpens.com/blogs/fountain-pen-blog/jinhao-x450x750-fountain-pen-nib)：#6 尖替换语境。
