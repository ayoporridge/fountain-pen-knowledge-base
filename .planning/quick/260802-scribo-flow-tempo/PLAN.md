# Phase 355 — SCRIBO FLOW Tempo

## 目标

在不触碰真实 `data/fpkg.db` 的前提下，为 SCRIBO FLOW Tempo 建立可回放的来源化内容包，修正其与 FEEL、Piuma 及 FLOW 兄弟型号的身份边界，并把品牌导航更新到三个已覆盖型号。

## 交付

- 官方与专业二级来源登记，正文包含身份、24 面材质、活塞、尖型、尺寸、版本、维护和选购边界。
- 仅使用本站原创 factual SVG 作为主媒体，不伪装成产品照片。
- 通过 `recordEntityContentReview`／`publishEntity` 所在的 `applyCuratedContentPacks` 发布路径。
- 在 owned checkpoint copy 完成首回放、二次幂等回放、SQL 关系／规格／媒体检查，并证明真实资料库 hash 不变。

## 非目标

- 不把官方页面当前的 Coming Soon 写成稳定现货。
- 不把 FLOW Armonia、Forma、Dimensione、Memoria、Origine、Evoluzione 合并进 Tempo。
- 不试写真实 `data/fpkg.db`，不新增通用验收或 Playwright 基础设施。
