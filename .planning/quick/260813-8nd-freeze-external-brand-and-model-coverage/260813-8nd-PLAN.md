# 最终外部品牌与代表型号覆盖冻结

## Goal

以多个大型专业钢笔零售商的现售品牌目录、品牌官网和可靠历史资料为外部参照，对当前公开品牌与代表型号做最后一次有边界的差异判定；合并补齐达到门槛的缺项，并形成明确的纳入、延后与排除清单。清单冻结后不再因单一商店、地区微型工作室、墨水／文具附属品牌或不稳定 SKU 无限扩张，转入最终资料库合并、全站验收、正式迁移和上线复查。

## Inclusion gate

新增品牌至少满足以下一项，并且存在可核实、当前或历史稳定的钢笔型号：

1. 同时出现在至少两家大型专业钢笔零售商的现售品牌／钢笔目录；
2. 有品牌官网的稳定钢笔产品线，并具备显著历史身份或跨市场代表性；
3. 是现有知识图谱明确缺失、且会造成主流钢笔市场认知断层的重要品牌。

地区微型工作室、主要经营墨水／文具且仅有边缘钢笔 SKU、单店短期上架、缺少稳定官方身份或仅有圆珠笔／蘸水笔的候选，记录为后续扩展或排除，不阻塞本轮正式迁移。

## Tasks

1. 保存外部目录证据快照，和当前 115 个公开品牌、734 个钢笔实体做差异表；逐项记录官网、零售商交集、代表型号与 disposition。
2. 对达到纳入门槛的最后一批品牌和代表型号，写自然中文正文、规格、历史／版本边界、使用维护、选购建议、来源和独立图片；使用既有 `CuratedEntityPack`、审核与发布链路一次合批实现。
3. 只在 caller-owned checkpoint 上验证 collision、remote selector 拒绝、首次 apply、replay no-op、既有实体 digest、媒体、关系、构建和页面 readback；冻结 manifest 后进入最终全量验收。

## Final deployment sequence

本地内容、最终 checkpoint、全量自动检查和真人全页遍历完成后，远端闭环严格按以下顺序执行：

1. 重新核对最终 checkpoint 与受保护 `data/fpkg.db` 的 SHA-256，并运行迁移器定向测试。
2. Turso 恢复 SQL read 后，先对最终 checkpoint 执行只读 dry-run；schema 不匹配、unique identity conflict 或 publication gate 异常时立即停止，不写远端。
3. dry-run 通过后，显式执行 append/upsert-only 正式同步；远端写入必须同时提供 `--apply --ack-remote-write`，publication 必须继续经过 `recordEntityContentReview` 与 `publishEntity`。
4. 对 Turso 做远端 readiness、entity quality、library、media、publication 与代表实体回读；未通过时不部署。
5. 使用当前本地 `master` 直接执行 Vercel production deploy。GitHub `origin/master` 落后本地 315 个提交，因此不能依赖旧 GitHub revision 触发本次部署。
6. 确认 production alias 指向新部署后，对全部 1130 个 authoritative public URL 做线上逐条复查，并补充图片代理的合理等待时间。
7. 只有远端迁移、生产部署、全页复查和最终逐项审计都有证据后，才结束 full-corpus goal。
