# Phase 14 Plan: 文章导入残留清理

**Goal:** 全部公开文章读起来像资料馆内容，不再暴露抓取、翻译和编辑中间产物。

## Tasks

- [x] 全量扫描 208 篇库内文章的标题、摘要和正文，建立导入残留、翻译指令、残缺 Markdown、原站操作语和异常标题清单。
- [x] 对可机械识别的残留做精确迁移修复；不改写原文事实，不把第三方经历改成站方亲历。
- [x] 规范文章标题层级：页面只保留一个 H1，正文从 H2 开始且不跨级；修复图片说明语义。
- [x] 清理相对链接、javascript 链接、错误站内路径和原站导航按钮；保留可验证的原始资料链接。
- [x] 来源卡只展示已审核、可理解的来源名称、标题、用途与原链接，不展示内部编辑备注。
- [x] 对 208 篇库内文章重建确定性摘要，并对 188 篇公开文章执行全量数据库与浏览器回归。

## Verification

- 每个文章页面恰好一个 H1，正文标题不跳级。
- 文章可见文字不包含翻译指令、导入提示、原站按钮、残缺 ref 或内部状态。
