# Phase 17 Plan: 全量回归与生产发布

**Goal:** 证明分类资料馆的本地数据、全部公开页面、媒体和生产站保持一致。

## Tasks

1. 运行数据契约、公开边界、Markdown、文章、图书馆和迁移安全检查。
2. 构建无远程数据库依赖的生产产物。
3. 在桌面与 390×844 手机项目运行完整 Playwright 套件。
4. 遍历 sitemap 中每个 URL、每页站内链接、内部字段泄漏和文章导入残留。
5. 检查全部公开媒体的加载、重复、尺寸、白边、比例和 alt。
6. 显式迁移远程 Turso，再部署 Vercel 生产站。
7. 对生产站重复 sitemap、链接、文章、媒体、分类、图谱和代表详情页检查。

## Verification

- 所有本地质量门禁和浏览器项目通过。
- 远程迁移只通过显式命令执行，构建和运行时不自动写数据库。
- 生产 URL 的 sitemap 数量、公开实体数量、路由行为和本地一致。
- 生产桌面与手机关键路径、全部公开链接和文章检查通过。
