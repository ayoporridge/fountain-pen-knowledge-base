# Phase 13 Plan: 图片资产全量修复

**Goal:** 所有公开图片稳定、对应且清晰；同一页面的每张图片都提供新的识别信息。

## Tasks

1. 建立统一的公开图片选择与展示边界：只输出 approved、可加载、非追踪像素且适合公开展示的资产。
2. 清理数据库与文章正文中的硬破图、HTML 伪图片、占位域名、无效代理和不稳定外链；无法安全替换时隐藏。
3. 详情页首图与画廊按 canonical 资产去重，禁止 hero 在同页再次作为 gallery 首图出现。
4. 对高白边、透明边、极端宽高比和低分辨率图片使用内容感知容器；小图不再被强行放大或裁掉主体。
5. 清理跨实体错配和品牌氛围图误用；保留能明确识别当前实体、结构或历史语境的图片。
6. 增加全量媒体边界检查与 Playwright 回归，覆盖所有 sitemap 页面上的图片加载、重复、alt 和尺寸风险。

## Verification

- 公开页面硬破图、HTML 响应伪图片、example.com 占位图与 1×1 追踪像素为 0。
- 公开实体详情页不存在同一 canonical 图片重复出现。
- 公开媒体选择器不输出 hidden、pending、needs_license 或被标记为不可用的资产。
- 每张公开图片都有非空、非文件名式 alt；低清图片不在大图容器中放大。
- 全量 sitemap 图片请求返回可识别图片，桌面和手机关键页面无 broken image。
