# Phase 16 Plan: 分类漫游与响应式体验

**Goal:** 在没有搜索和在线 AI 的版本中，让桌面和手机用户仍能通过类型、客观维度与关系网络持续浏览。

## Tasks

1. 把首页、导航、图书馆和浏览页统一到分类资料馆的信息架构。
2. 只公开笔尖类型、笔尖材质、上墨方式、产地和笔身材质等已有内容的可核实维度。
3. 让类型切换、筛选、计数和继续加载在桌面与手机上保持一致。
4. 退出依赖不完整规格的对比页，并为旧地址提供确定性跳转。
5. 修复关系图谱的手机宽度、起点选择、关系说明和继续漫游入口。
6. 检查菜单、标题、alt、焦点、对比度和 390px 视口横向溢出。

## Verification

- 桌面和 390×844 手机项目均通过分类、图谱、导航和无障碍回归。
- 主导航不出现搜索、聊天或对比入口。
- 主观/不稳定维度地址返回 404，旧对比地址跳转到钢笔分类页。
- 公开页面没有横向页面溢出。
