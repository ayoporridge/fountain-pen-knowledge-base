## Trust Boundaries

| Boundary | Description |
|---|---|
| CLI/env → database selection | 未可信路径和环境变量可能把 audit 指向真实/远程数据库。 |
| Checker → SQLite files | 测试进程可能误写 main/WAL/SHM 或删除已有 sidecar。 |

| Fixture lifecycle → child/temp resources | 异常或 signal 可能泄漏进程、client 和临时数据库。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-19-01 | Tampering | real catalog / remote env selection | high | mitigate | 显式 absolute local allow-contract、readonly/fileMustExist/query_only、拒绝 remote/Turso、main/WAL/SHM 前后快照；任一失败阻断计划。 |
