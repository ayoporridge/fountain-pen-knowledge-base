## Trust Boundaries

| Boundary | Description |
|---|---|
| Raw catalog → ledger universe | inner join、pagination或count-only可漏 identity。 |
| Pre-031 source → contract-2 audit | 直接查询030会缺views；普通文件复制会漏WAL或产生非一致快照。 |
| CLI limit/output → verdict | display参数可能篡改scan、artifact或exit。 |
| Untrusted DB text → CSV | spreadsheet formula与delimiter可造成执行/结构注入。 |
| CLI path/number input → filesystem | symlink、默认目标或非法limit可能覆盖数据库或绕过完整扫描。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-19-11 | Tampering | incomplete ledger / limit-dependent verdict | high | mitigate | raw universe + bidirectional identity equality + duplicate guard；limit只在write/verdict后slice，hash/exit invariance fixtures。 |
| T-19-12 | Injection | CSV serializer | high | mitigate | fixed columns、RFC4180 escaping、formula-prefix encoding、comma/quote/CRLF/formula fixtures。 |
| T-19-13 | Elevation of Privilege | duplicated public predicate | high | mitigate | audit诊断不授权；library owner过滤继续direct public_entities，parity checker独立。 |
| T-19-14 | Tampering | pre-031 real catalog audit | high | mitigate | explicit readonly source + SQLite online backup；只从 migrations(name,applied_at,checksum) 的name三位前缀推导并锁定030→031 provenance，canonical migrate owned copy至031后才算readiness，比较源main/WAL/SHM。 |
