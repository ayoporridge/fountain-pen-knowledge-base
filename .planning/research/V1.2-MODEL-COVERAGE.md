# V1.2 品牌与型号覆盖矩阵

## 结论

本轮对 **data/fpkg.db** 的全部品牌和钢笔实体做了枚举，并以品牌官网、官方目录、官方档案、博物馆资料及可靠专业参考站点进行 live source 核验。

当前数据库基线：

- 69 个品牌实体，236 个钢笔实体。
- 按当前公开规则约有 65 个公开品牌、231 个公开钢笔型号。
- 公开品牌中，Monteverde、Duke、Graphomatic 没有关联的公开型号。
- Aurora 只有一个泛称占位实体，没有合格的具体型号页。
- 本矩阵记录 109 个 canonical model / taxonomy 处理项：P0 13 项、P1 54 项、P2 40 项、P3 2 项。

本清单不把每个配色、镀层或限定版视为独立型号。颜色、地区限定、特殊表面处理优先记录为 variant；只有尺寸、笔尖系统、上墨机构或购买决策明显不同，才拆成独立实体。

## 状态与来源等级

### 数据库状态

- **M — Model missing**：品牌已有，canonical 型号缺失。
- **BM — Brand and model missing**：品牌与型号都缺失。
- **S — Split / correction**：现有实体混合了多个型号、名称错误或需要拆分。
- **A — Alias / normalization**：是已有产品的地区名、别名或错误品牌名；不应新建重复实体。
- **G — Identity gate**：品牌身份、生产方或型号归属尚未达到公开发布标准。
- 复合状态如 **S/M、BM/A、G/M** 表示同时涉及多个处理动作。

### 资料等级

- **S1**：品牌官网、品牌官方商店、官方现行产品页。
- **S2**：品牌官方历史档案、官方目录、博物馆、政府或贸易机构资料。
- **S3**：可靠专业零售商、专业参考数据库、长期经营的钢笔媒体。
- **S4**：论坛、社区、社交媒体，只能用作发现线索，不能单独支持公开内容。

### 优先级

- **P0**：先修结构、身份和全球核心产品空洞。
- **P1**：第一批扩充，建立主要品牌和产品梯级。
- **P2**：第二批扩充，补齐入门、中端、旗舰和地域多样性。
- **P3**：资料不足或身份复杂，完成来源门禁后再公开。

## 建页边界

### 建立独立型号页

满足以下任一条件时，才建立独立型号实体：

1. 上墨机构不同，例如 cartridge/converter、piston、vacuum、eyedropper。
2. 笔尖系统或尺寸明显不同，并会改变书写与购买决策。
3. 整体尺寸、定位或价位跨越明显，例如 Pro Gear 与 Pro Gear Slim。
4. 具备独立、稳定、官方认可的型号名称。
5. 历史上是重要的独立产品家族，而不是某个颜色或纪念版。

### 记录为 alias

- 同一产品在不同市场使用不同名称，例如 Pilot Elabo / Falcon、Metropolitan / Cocoon。
- 中文俗称、旧译名或历史拼法。
- 品牌更名，例如 Moonman / Majohn；应保留旧名供搜索，但不复制实体。

### 记录为 variant

- 颜色、镀层、笔夹颜色。
- 普通限定色或地区限定色。
- 不改变主体尺寸、笔尖系统和上墨机制的材料外观版本。
- 同一型号的常规 nib width 选择。

### 必须进入 identity gate

- 品牌官网找不到，且零售平台存在多个相互冲突的生产方。
- 商标名称相同但实际为不同地区、不同公司。
- 型号只出现在无品牌商品、论坛猜测或转售标题里。
- 无法确认是独立型号、OEM 公模还是换牌产品。

## 内容来源门禁

公开型号页至少满足以下一种来源组合：

1. 一份 S1 官方产品页。
2. 一份 S2 官方档案、官方目录或博物馆资料。
3. 两份相互独立的 S3 专业资料，且型号身份、核心规格一致。

S4 社区讨论只可支持“用户体验、常见问题和发现线索”，不能独立支持品牌归属、发布时间、材质、笔尖规格或上墨机构。

对于中国新品牌，不把带品牌关键词的 SEO 独立站自动认定为官网；需验证公司主体、商标、官方店铺或制造商关系。

## 每个型号页的最低内容标准

每个新建或重写的型号页至少包含：

1. 正式型号名、地区名、中文俗称与 aliases。
2. 品牌、原产地、生产状态、首次推出时间或时代范围。
3. 长度、最大直径、重量；如官方未提供，明确标记未知，不猜测。
4. 笔尖材质、笔尖尺寸、可选字宽、笔舌特征。
5. 上墨方式、容量、墨窗、密封与防漏结构。
6. 笔身材料、握位尺寸、配重、是否适合长时间书写。
7. 拆洗难度、可更换部件、墨囊 / 上墨器兼容性。
8. 常见问题、品控风险与二手购买检查点。
9. 在品牌内部的定位，以及与相邻型号的真实差别。
10. 适合谁、不适合谁；避免空泛的“经典、优雅、值得拥有”。
11. 至少一项 S1 / S2 来源，或满足两项独立 S3 来源门禁。
12. 来源 URL、访问日期和现行 / 历史状态，避免把旧目录当成当前在售事实。
